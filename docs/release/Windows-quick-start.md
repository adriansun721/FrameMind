# FrameMind Windows 首版候选安装包

适用 Windows 10/11 x64；目前实际验证机器为 Windows 11 x64。无需安装 Node.js、Python、Microsoft Word、LaTeX 或独立求解器。运行 NSIS Setup，按提示选择当前用户的安装目录，再从开始菜单打开 FrameMind。应用及安装包暂未进行代码签名，发布者身份不能通过签名验证。

## 手动本地流程

不配置 API 也可使用。依次创建节点、材料与截面、杆件、支座及荷载，再点击“运行分析”。在结果区查看位移、反力与杆端内力。Ctrl+S 保存 `.framemind`，Ctrl+O 重新打开。通过“工程计算书”核对分析来源，导出 Word 或 PDF。中文文件夹及文件名可用。

安装目录 `resources/交付资料` 含修改前/后的两层钢刚架、样例 Word/PDF、固定输入、数值与性能记录。通过 Ctrl+O 打开示例；建议将示例复制到自己的文档目录后编辑和保存。演示的尺寸、荷载、组合系数和加大柱截面均为教学假设；确切值见 `质量证据/t33-demo.json`，全部杆端刚接、底层四节点全固定。

## 联网 AI、保存和恢复

在设置中填写自己的 DeepSeek API Key，保存并测试连接。联网请求会产生相应 API 用量。参数卡片和预览必须由用户核对后确认；AI 不保证首次就正确分配对象、工况或参数。凭据通过 Windows DPAPI 加密，仅存于当前用户的应用数据目录，项目与报告不携带密钥。不要复制他人的加密凭据；在新的用户或机器上重新配置。

移除凭据、网络失败或取消 AI 不影响已确认的模型和本地计算。取消计算不生成成功结果，可修正模型后重算。关闭前保存项目；未保存的工作不会自动恢复。重新打开保留保存的模型和历史成功结果，对话、未确认草案、撤销/重做历史不保留。设置可切换深浅主题，重启后保持。

在 Windows 设置的“已安装的应用”中卸载。卸载保留当前用户配置与外部项目；如需移除凭据，请先在应用设置中执行“移除本机凭据”。

## 当前交付状态与限制

这是首版候选包，尚非完成所有验收的正式首版：T33 真人首次试用（AC-20）及无开发工具的干净 Windows 环境验收仍待实际执行。详见 `质量证据/T34-acceptance.md`。

完整交付 ZIP 另含安装回归记录和禁网沙箱脚本。在启用 Windows Sandbox 的机器解压后，从解压目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\复验脚本\new-t34-sandbox.ps1 -DeliveryPath .`，再打开生成的 `FrameMind-offline.wsb`。按沙箱 `C:\Evidence\验收清单.md` 实际操作并填写结果；主机 `sandbox-evidence` 保留项目、报告和记录。此脚本只准备验收环境，不代表验收通过。

求解使用小变形 Euler-Bernoulli 三维刚接杆单元、线弹性静力分析，不含杆端释放、半刚接、非线性、动力、屈曲或规范验算。用户自行定义荷载组合，结果不代表规范合规结论。性能数据仅代表 T32 指定机器与 58、399、1,120 杆模型；未承诺更大模型、其他机器或全部杆件矩阵报告的性能。数值和性能详情见质量证据文件，原始完整资料保留在源代码仓库 `docs/evidence`。
