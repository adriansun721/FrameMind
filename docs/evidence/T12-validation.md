# T12 验证记录

## 实现前登记的数值基准

公开入口：项目编辑命令、`captureAnalysisInput` / `solveFrame` / `getMemberSectionForces`、项目保存重开，以及真实 Electron 工作台。

沿全局 X 的 4 m 悬臂，起点六自由度固定，E = 200 GPa，ν = 0.3，ρ = 7850 kg/m³，A = 0.01 m²，Iy = 0.0002 m⁴，Iz = 0.0001 m⁴，J = 0.00015 m⁴。沿用 T03 Euler–Bernoulli 小变形线弹性假设与局部轴约定。

LC1 端力 (10,12,14) kN，端矩 (2,3,4) kN·m；LC2 端力 (-4,6,-8)，端矩 (-1,2,-3)，全局均布力 (1,-3,2) kN/m，自重重力 (0,0,-9.81) m/s²。用户组合 1.5 LC1 − 0.5 LC2，有效端力 (17,15,25)，端矩 (3.5,3.5,7.5)，均布力 (-0.5,1.5,-0.6149575)。另验零系数与全零组合。

独立参考来自悬臂轴向、扭转、端力/端矩/均布力弯曲解析式，不调用求解器生成期望值：端位移 (0.000032,0.0214,0.0121413673333333) m；端转角 (0.00121333333333333,-0.00448601133333333,0.0083) rad；固定端反力 (-15,-21,-22.54017) kN，反力矩 (-3.5,91.58034,-79.5) kN·m；局部起端内力等于这些反力，末端内力 (17,15,25,3.5,3.5,7.5)。中点截面 N/Vy/Vz/T/My/Mz = (16,18,23.770085,3.5,-45.270085,40.5)。

首轮测试发现中点 My 登记值手算错误，独立按截面平衡 `3.5 − 25 × 2 − (−0.6149575) × 2² / 2 = −45.270085` 更正；误差准则未改变。

预定误差：每分量绝对误差 ≤ 1e-9 + 1e-9 × |参考值|，近零分量绝对误差 ≤ 1e-9。持久化后应保留定义、原始工况荷载及冻结结构；工况局部修改与结构修改应正确使组合失效。

- `npm run build`：类型检查、Electron 主进程编译及前端构建通过。原有大包体积提示仍存在。
- `npm test`：16 个测试文件、94 项测试全部通过；T12 四项公开入口测试验证上列解析值、全零响应、零系数排除工况、负系数、完整来源持久化、工况/结构/组合变更失效、定义校验与溢出。
