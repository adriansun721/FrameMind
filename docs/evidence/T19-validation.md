# T19 验收记录：DeepSeek 设置与本机凭据

日期：2026-10-02。平台：Windows / Electron 44.5.1。实现基线：`f612435` 之后的 T19 变更。

## 验收输入与入口

默认模型为用户指定的 DeepSeek-V4.1-Flash，官方请求值为 `deepseek-flash`。初次离线自动化仅使用明确的假凭据；后续用户配置凭据并授权补充真实连接验收，见文末。

`electron/deepseek.test.ts` 通过连接服务的设置、保存、移除、测试公开入口验证 23 项行为：凭据往返、替换及模型更新、固定请求、401/403/402/429/500/503/422/302、损坏的成功响应、网络异常、响应正文挂起超时、保存/移除/新测试使旧请求失效、加密不可用、非法 IPC 输入、加密替换失败保留原文件及损坏凭据恢复。服务测试使用可逆假加密器；真实 DPAPI 由桌面测试验证，不将假加密当作安全证据。

`e2e/t19-deepseek-settings.spec.ts` 从真实 Electron 设置入口验证：

- 首次显示未配置、默认 Flash、密码输入；保存清空草稿且配置状态更新。
- 仅替换主进程网络响应为固定样本，实际执行请求/反馈路径；成功、认证、限流和网络失败可辨认，服务正文和异常中出现假密钥时界面不会回显。
- 模型或 Key 尚未保存时禁止测试，避免测试旧配置冒充当前草稿。
- 更新 Key/模型并重启，配置保留；读取真实 DPAPI 密文核对假密钥已更新，但不把解密内容输出为证据。
- 保存并重新打开工程，原节点不变；工程内容没有 Key 或 DeepSeek 配置，凭据文件没有明文 Key；移除后凭据文件不存在。
- 移除凭据后继续创建杆件、材料截面、支座和节点荷载，运行本地分析成功。
- 关闭尚未返回的测试后继续创建节点，重新打开并移除凭据，旧返回不覆盖当前设置反馈。
