日期：2026-10-02。平台：Windows / Electron。实施基线：`55e7eec`。

## 正文与来源

项目树“工程计算书”可选择一份已完成分析，导出原生可编辑 Word 标题、段落与表格。正文包含模型概况、理论假设与适用边界、材料截面及资源来源、节点与杆件几何、六自由度支座、节点力和力矩、均布荷载坐标系、自重、工况组合、关键位移、完整节点响应和杆端内力。单位逐项给出，分析 ID、项目 ID、输入修订及分析时间可复核。

`captureEngineeringReport` 复制指定结果并复用项目文件结果解码，拒绝不存在、非完成、跨项目、非有限结果、对象不匹配以及杆件结果几何不对应的来源。历史报告仍使用其冻结模型与荷载；图表由同一报告对象生成，并标注来源、输入版本、分析 ID、全局方向或分量说明及图例。导出不调用 AI，不重算，也不读取凭据。

## 独立数值基线与样本

轴向参考模型：4 m 单杆悬臂，E = 200 GPa，A = 0.01 m²，末端全局 X 方向 10 kN。独立公式 PL/(EA) 给出 UX = 0.00002 m；固定端反力 FX = −10 kN，两个局部端部轴向作用分量分别为 −10 和 +10 kN。导出表格逐项核对该参考。

组合参考保持同一结构：Iy = 0.0002 m⁴，Iz = 0.0001 m⁴，ρ = 7850 kg/m³。LC1 含 10 kN 轴力及 gZ = −9.81 m/s² 自重；LC2 含全局 qY = −3 kN/m。组合为 1.5 × LC1 − 0.5 × LC2。独立质量 ρAL = 314 kg，LC1 重力 3.08034 kN，组合竖向合力为 −4.62051 kN，等效 qY = +1.5 kN/m。悬臂均布荷载公式 qL⁴/(8EI) 给出 UY = 0.0024 m，UZ = −0.000924102 m；组合 UX = 0.00003 m。固定端反力 FX = −15、FY = −6、FZ = +4.62051 kN。报告保留原工况 qY = −3、系数 −0.5 和加权 qY = +1.5，不用等效荷载冒充原始工况。

## 桌面流程

`e2e/t28-engineering-report.spec.ts` 通过真实 Electron 和预加载桥覆盖：

1. 没有完成结果时禁用导出；打开有两次分析的中文路径项目，选择第一份历史结果并显示历史来源。
2. 暂停浏览器 PNG 编码，在导出开始后关闭报告窗口，将当前截面面积从 0.02 改为 0.04 m²，再继续导出。Word 仍含第一份分析的 A = 0.01 m²、UX = 0.00002 m 及第一份分析 ID，包含两张真实 PNG，没有混入第二份分析 ID 或新面积。
3. 切换第二份历史分析重新导出，UX = 0.00001 m；同一中文 Word 路径替换完成，没有临时文件或备份残留。
4. 导出到不存在的目录时显示失败，未报成功。主进程对文件写入使用既有原子保存及回滚契约。
5. 主进程网络接口注入断网，Word 仍成功导出；组合报告保留来源、原始工况、系数、自重和加权结果。

对两主题和两尺寸 1440×900、1080×680 的入口及导出按钮检查通过，截图：[深色 1440](T28-dark-1440.png)、[深色 1080](T28-dark-1080.png)、[浅色 1440](T28-light-1440.png)、[浅色 1080](T28-light-1080.png)。

## 原生 Word 与页面检查

两份最终样本以本机 Microsoft Word 只读打开，分页分别为 4 页和 5 页；生成开发检查用 PDF 后，使用 documents 技能的 `render_docx.py` 栅格化接口输出每页 PNG。转换入口接入已经由 Word 生成的 PDF；未使用用户安装的 LibreOffice。Python 工具仅位于本任务临时目录，不是应用导出依赖。所有 9 页均逐页查看。

首轮检查发现章节强制换页及位移图过多留白，改为自然分页并让图高随展示节点数变化；随后增加图中文字尺寸、移动节点标签避开杆件、使表题跟随表格分页。最终中文字体 Microsoft YaHei、基础可编辑公式、上标单位、正负号、全局/局部标识和图例可读；表格未截断、未重叠，表头可重复，表格行不拆分。保存最终 Word 与逐页概览，供 T29—T30 复用。
