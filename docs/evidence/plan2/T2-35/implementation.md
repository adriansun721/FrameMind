# T2-35 实现与验收

日期：2026-10-07（Asia/Taipei）。已完成实现及确定性验证。

整体基底空间作用 `base-translation` 使用全局单位方向及有符号无量纲系数，绑定单边 Hz 加速度 PSD。全部支承必须约束各非零平移分量，并共享每个源的运动。共享工程工况校验、工具 schema 和 C++ 均拒绝差动目标、转动输入、同源力／加速度混用、未支持相关关系及错误谱量纲。

原生和冻结结果校验均按 `−φᵀ M r` 计算惯性参与：实际单元 EB 形函数精确积分包含释放端独立转角，覆盖结构密度、附加线质量及点质量；受约束端的一致质量耦合保留。基底与外力只能独立并用；同源有符号作用先相加传递函数，独立源先相加 PSD，再积分求 RMS。

仅输出所选工程节点平移 PSD、方差和 RMS，明确是全局 XYZ 相对整体平动基底的响应；保存结果强制参考系标记，工具摘要、PSD 点、RMS 引用与引用标签保留参考系。旧纯外力历史格式保持兼容。技术约定和支持矩阵见 [ADR-0068](../../../decisions/0068-whole-base-random-excitation.md)。
