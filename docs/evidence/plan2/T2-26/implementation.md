- 结果持久化先验证每轮继承输入、原生恢复、组装系数、映射与收敛声明，拒绝篡改。旧 `/1`—`/3` 历史记录继续读取。
- 工作台、杆件过程与计算书说明未收敛状态；Word／PDF 正文包含同源规模与误差表，选中工程杆的附录输出对应实际内部单元贡献。
