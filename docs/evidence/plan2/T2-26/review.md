# T2-26 双轴审查

固定基线：`d8c7d4ba55499a55d855a58a203a4bbc6fe3ddfe`；首轮实现提交：`45bd212`。按 implement 与 code-review 技能分别委派 Standards、Spec 两个独立审查代理，复查后续工作区修复。

## Standards

发现 1 项 P1 契约违例：`decodeOptionalArray` 直接传递带有第二个 internal 参数的 decoder，数组索引使第二行及之后的工程杆件／均布荷载跳过编号规则。已改为显式 `decoder(item)`，补充第二行内部 ID 注入拒绝测试。审查代理独立运行两项注入回归通过，确认 P1 已关闭。内部命名空间只在校验继承的计算轮次中开放。

另有 1 项可维护性判断：若干消费者重复读取最终内部过程和选定网格。现有访问点很少且已有回归覆盖，本次保留；这不是标准违例或验收阻塞项。原生与 TS 的映射重建重复是 ADR-0059 独立校验边界所需。

## Spec

发现 1 项 P1：内部单元从舍入端点重新构造局部轴，接近 `abs(localX.z)=0.9` 时参考轴可能变化，造成各轮局部均布力方向改变。已将工程完整轴组冻结于 `meshPlan.frames`，原生独立校验后继承；内部 `calculationFrames` 同时供实际求解和冻结系数核验。TS 与 C++ 统一参考轴边界容差，补充临界角两侧、四种坐标偏移和非等惯性截面的解析回归。

审查代理独立复测坐标偏移 1／10／100／1000、强制 1／2／4／8／16 网格，轴组一致、全局荷载合量不变，解码成功；极严精度正确保留预算耗尽状态。P1 已关闭，无剩余需求阻塞项。

合计：Standards 1 项硬违例已修复、1 项可维护性判断保留；Spec 1 项 P1 已修复。两轴无剩余硬违例。
