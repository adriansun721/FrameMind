真实联测使用应用原有 `deepseek-v4-pro` 加密配置，覆盖 state、confirmation、diagnostic 三类各两次；state 另含手动与重开两次询问。确认与诊断采用完整非目标字段比较，解析位移绝对容差1e-10 m。真实模型请求无需在用户提示中指定工具名，执行的工具名、参数和回执均归档。

桌面回放不替代真实模型选择工具；真实六个流程也不等于逐个 AC 的真实故障注入。AC 的竞态／中断／文件系统故障由确定性契约和真实 Electron 故障入口验证。三种流程各两次为固定小样本，不宣称总体 Agent 成功率、后续高级分析工具或整轮综合验收已通过。

初始 v1 回放保留测试失配失败；真实 v1 首轮的两项失败完整保留，修复后另开目录复跑。v2 增加候选完整输入和确认后完整工程核查，没有放宽通过门槛或删去失败分母。最终结果和各次目录见 [verification.md](verification.md)。
