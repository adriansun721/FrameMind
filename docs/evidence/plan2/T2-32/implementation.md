# T2-32 实现与技术决定

日期：2026-10-06（Asia/Taipei）。实现提交：`c93b2da`，审查修正：`e45932f`。

入口：左侧“管理分析工况” → “管理随机输入谱”。用户可新建/选取谱、编辑频率/密度点表、设置有效频段、应用带限白噪声模板、导入 CSV，检查输入曲线和面积后保存。CSV 文件和粘贴文本使用同一入口；导入元数据初始为空，缺少单位/频段会失败，失败不替换当前表格。点表每页最多 50 行，总预算 10000 点。

[ADR-0065](../../../decisions/0065-psd-input-conventions.md) 在实现前固定规范单位、连续单边谱、双边偶谱正频半轴、线性插值、梯形积分和频段外零值。`psd.ts` 统一校验、CSV、模板、转换、积分和插值；所有密度转换包含频率雅可比和激励量平方倍率，面积在规范物理单位下独立核对。拒绝非有限值、负密度、顺序/重复点、元数据缺失/冲突、无效频段和精度范围错误。零谱有效，离散 DC 线谱不在表格能力内。

规范化谱是 `FrameProject.psdSpectra` 中的可复用资源（PSD1、PSD2…），含全部单位、谱约定、有效频段、点表、插值和频段外规则。旧 v2 项目缺字段恢复为空列表；非法已保存谱拒绝打开，不静默丢弃。共享 `applyProjectEdits` 负责创建/更新/删除及原子回执，历史操作覆盖谱编辑；已有静力/模态输入依赖不引用未绑定谱。

工具 `prepare_psd_input` 支持 table/csv/white-noise，返回预览输入、规范谱和输入均方值；只准备数据。`propose_model_edits` 的 create/update/delete_psd_spectrum 经真实用户确认应用，回执可读回对象，冲突和重启状态沿用共享机制。`read_model` 的 psd-spectra 集合支持字段、过滤和分页，数据携带谱自身规范单位。PSD 元数据独立于普通 inputUnits。新增谱相关措辞会公开准备和草案工具。

预览绘制同一已校验点表，不生成另一份平滑/拟合谱；规范化保存后立即显示规范谱。均方值与 RMS 明确标成输入激励统计量，保存不会创建分析或伪装响应。随机工况绑定及结构响应是后续 T2-33；真实 AI 联测和整轮 AC2-18 仍由后续任务验收。

编辑器按项目/会话隔离，打开另一项目或重新打开当前项目会销毁旧编辑器。已选谱的更新/删除比对载入基础内容，撤销或后台修改后阻止旧表格回写；重新选择当前资源方可继续。CSV 和手动字段共用严格十进制解析，非零文字下溢成 0/-0 会明确失败。准备工具接受并验证公布的通用单位偏好，但谱自身元数据始终决定数值含义。
