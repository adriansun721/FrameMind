# T2-32 双轴审查

固定起点：`87ba893824964f1fc929e903fca21a2b2a384b4d`。实现：`c93b2da`。修正：`e45932f`。依据 implement 技能调用 code-review，两名独立子代理分别只读审查 Standards 和 Spec；修正后各自复核关闭。

## Standards

初次发现 3 项硬违规，未报告判断性代码味道：

1. **P1：旧谱草稿可覆盖新工程对象。** App 未按项目/会话重新初始化管理器；打开另一含 PSD1 的工程后旧 editingId/draft 配合新 project 会覆盖新谱。同一工程撤销或后台修改后也缺少基础核对。违反 ADR-0038 稳定目标和 ADR-0065 冲突约定。
2. **P2：CSV 非零小值被静默归零。** `Number('-1e-400')` 得到 -0，非负检查放过非法负密度。违反 ADR-0065 禁止裁剪负值和非零下溢拒绝。
3. **P2：工具公布参数与执行不一致。** 准备工具 schema 公布 inputUnits/outputUnitPreset，而准备器把这些通用参数当作未知字段。违反 ADR-0050 工具单位偏好契约。

修正后复核：原 3 项均关闭。新会话关闭并按项目/会话重建管理器，更新/删除比对谱基础内容；CSV/手动共用十进制下溢检查；准备工具先剥离并验证通用偏好，谱自己的明确单位仍决定数值含义。新增修正无硬违规或值得报告的代码味道。

## Spec

初次发现 2 项问题：

1. **P1：跨项目保留 PSD 编辑目标。** 与 PLAN2.0 工程事实身份分明、提交时绑定对象身份要求不符。Ctrl+O/Ctrl+N 可在管理器打开时切换会话，旧表格可能进入另一项目。
2. **P2：非零三角谱下溢被当作零谱。** `(0,0),(1,Number.MIN_VALUE)` 的梯形平均高度先归零，积分返回 0，违反 ADR-0065 精度拒绝及 T2-32 独立积分要求。

修正后复核：原 2 项均关闭。项目切换及同项目修改/撤销的旧表格覆盖被阻断，无关编辑可继续；原三角谱复现现抛出精度错误，正负十进制下溢拒绝，真实零和可表示的极小矩形仍有效。通用单位参数验证/剥离与谱单位权威一致。未发现新增缺陷、缺失需求或范围扩展。

Standards：初次 3 项，全部关闭，当前 0 项；Spec：初次 2 项，全部关闭，当前 0 项。原最严重问题分别都是跨项目旧表格覆盖谱。确认回放不作为真实 AI 联测证据。
