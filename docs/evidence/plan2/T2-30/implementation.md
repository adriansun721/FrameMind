# T2-30 实现

日期：2026-10-06（Asia/Taipei）；数值与验收门槛见 [ADR-0063](../../../decisions/0063-fixed-preload-eigenvalue-buckling.md)。

- 统一分析工况入口新增屈曲方法。固定／参考部分各由 LC 来源及系数组成，固定可为空；手动与工具草案使用相同原子工程操作，参考不得缺失或全部零系数。
- 冻结两部分的荷载方向、节点力／矩、均布荷载、自重和来源系数，服务依赖标明 fixed/reference 角色；两次实际静力预应力运行随结果保存。
- C++ `/6` 在细分结构上取得轴力，三点积分构造横向 Hermite 几何刚度，稳定基态 Cholesky 倒数特征值法筛选正因子。释放采用独立梁端转角，沿用工程映射。
- 因子、原始形态、沿杆样本、计算坐标、实际预应力及加密过程独立保存。结果面板支持选阶、显示幅值、节点／杆件定位、单位换算和冻结来源核查，视窗明确标识非实际位移。
- 保存解码验证预应力运行的输入、系数、恢复端力和全局平衡，小矩阵核对物理组装与特征残差／正交性，所有规模拒绝重复向量与非有限衍生值。
- 不稳定固定基态、机构、无正因子、初始方程预算不足及因子未收敛均失败；失败保留已完成历史，不发布预算内未收敛的成功结果。
- 两部分实际依赖自动过期；零系数荷载与附加质量不影响当前性。删除荷载来源清理工况和活动身份，历史保留自身冻结条件。
- 工具 summary/modes/mesh 与计算回执包含屈曲身份、λ 含义及核查数据；拒绝静力位移／内力／质量读取、响应叠加、静力数值比较及计算书入口。

边界：未变形、材料弹性、死荷载、轴力导致的杆系弯曲稳定。不包含随动力、扭转预应力、局部屈曲、塑性或后屈曲；λ 不能解释为极限承载力、统一安全系数或规范合格。屈曲计算书由 T2-37，真实 AI 联测、目标规模性能、干净安装由后续任务承接。
