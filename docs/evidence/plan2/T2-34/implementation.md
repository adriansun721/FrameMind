# T2-34 实现与验收

日期：2026-10-07（Asia/Taipei）。已完成实现与确定性验证。

## 交付

- 整杆全局均布随机力，方向为单位向量，空间系数为有符号 1/m；节点系数无量纲。每个源显式绑定 PSD 表和空间作用。
- 同源节点／杆件作用共享随机过程，先相加有符号广义力，再相加模态复传递函数、取模平方。不同源相互独立，先相加响应 PSD，再积分求 RMS；相同 PSD 表不会令两个源变为同源。
- 杆件作用按冻结模态实际细分单元的 EB 形函数精确积分，包含转角和杆端释放独立坐标，映射回工程杆件。旧单节点设置和项目保持兼容。
- 手动编辑和工具确认草案复用工况校验；最多 16 个源、128 项作用。拒绝部分相关、互谱、相位、局部方向和部分杆段。本轮各源须使用相同的完整频段。
- 三维视图显示源身份及空间系数箭头，注明非瞬时力。结果来源列出每个源、输入谱、对象、方向和系数，可定位节点／杆件。
- 保存冻结全部源、作用和各自输入谱。作用、任一源谱、模态／阻尼／结构／质量变化正确标记过期，保留历史；无关静力荷载不影响随机结果。agent 的 summary 和 input-psd 可读取全部冻结源，分页谱点附带源及谱身份。
- 新增 1/m ↔ 1/mm 单位维度，界面和工具输入转换都保持工程量等价。源身份与方向不转换。

技术约定见 [ADR-0067](../../../decisions/0067-distributed-random-sources.md)，频率／积分沿用 ADR-0066。

## 验证

- 原生构建、类型检查、生产构建通过。
- 完整单元测试：83 文件、649 测试通过；专项单元测试 31 项通过。
- [数值证据](numerics.json)：13 个通过场景、10 个拒绝／篡改场景。连续悬臂五阶解析弯曲模态，不使用产品 FE 振型或积分器作为参考。所有非零曲线与 RMS 误差低于登记的 0.5% 限；独立 Simpson 100000／200000 区间积分先通过收敛检查。
- [桌面证据](desktop.json)：多源及同源有符号作用、重复身份拒绝、输入数值下溢拒绝、标记、杆件定位、1/mm 输入、作用变更过期、撤销和重开均通过。
