# T2-31 实现

日期：2026-10-06（Asia/Taipei）；方法、边界及验证门槛在编码前登记于 [ADR-0064](../../../decisions/0064-initial-stress-elastic-second-order.md)。

- 分析工况管理与原子工程工具新增弹性二阶方法，共用加载步数、每步校正上限、残差／增量容差、细分与方程预算校验；输入组合实际形成完整荷载后计算。
- C++ `framemind-native/7` 对每个内部网格执行同输入原生线性运行，取真实轴力构造两个横向平面的 Hermite 初应力几何刚度，再按比例加载求平衡响应。独立释放坐标、自重、节点荷载、均布荷载与工程对象映射沿用既有流程。
- 保存每一步实际校正前后残差、校正向量、位移、比例因子、选定内部网格和全部细分记录。位移、反力、17 个沿杆站点截面力同时满足绝对加相对细分门槛才发布成功。
- 结果面板提供同输入线性／二阶沿杆曲线、节点位移差值与比值、杆端力差值、加载记录、网格误差、冻结输入及方法边界。节点／杆件定位、单位换算、双主题及保存重开保持一致。
- AI 工具可配置和执行工况，读取真实响应、过程、网格、线性身份与节点比较。跨方法比较核对冻结结构、荷载、约束、释放与内部网格；修订号仅为元数据。输入变化不能归因于二阶效应，二阶响应拒绝静力叠加。
- 迭代耗尽、非正定、范围超限、方程资源不足及细分未收敛返回失败；诊断展示失败前实际加载记录，保留原成功历史，不发布最后一轮响应。
- 保存解码复核单元系数、加载校正方程、残差／增量、实际向量、截面恢复、线性参考与细分误差。稀疏 Cholesky 在所有规模核查加载路径两个切线端点，包括整体矩阵未捕获的规模，拒绝未激发失稳模态的伪造成功。

适用范围：小位移、材料弹性、死荷载、未变形参考轴的初应力二阶近似，涵盖杆系 P-Δ／P-δ。每步矩阵固定，通常两次平衡校正；不更新轴力或参考轴。全杆横向斜率保守上界 ≤ .05 rad，轴向应变 ≤ .01；这些是方法适用范围门槛，不是材料强度或规范判据。一般大转动、轴力再分配、塑性、随动力、扭转预应力、局部屈曲与后屈曲不在本轮范围；二阶计算书由 T2-37 接入，真实 AI、目标规模性能及安装验证由后续任务承接。
