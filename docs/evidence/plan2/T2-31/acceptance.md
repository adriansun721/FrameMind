# T2-31 逐项验收

| PLAN2.0 要求 | 实现与证据 | 结论 |
| --- | --- | --- |
| 实现前登记几何效应、刚度、控制、迭代、残差和异常退出 | ADR-0064 明确初应力 Hermite 能量模型、比例加载、固定步内矩阵、双收敛指标及失稳／预算／范围失败；与实现一同保留方法限制 | 通过 |
| 手动与工具配置、执行并返回真实过程、状态、边界及冻结输入 | Electron 手动工况、确认后的工程工具编辑与运行、summary／mesh／截面读取；原生 `/7`、实际逐轮向量、来源快照、保存重开与失败过程显示 | 通过 |
| 对应线性条件可核对，图表与数值准确归因 | 每网格真实 `/3` 同输入线性参考；两条沿杆曲线、节点差值／比值、端力差值；不同修订同基础输入可比，基础荷载改变被拒绝；工具归因为方法差异 | 通过 |
| 迭代、失稳、预算和未收敛不能发布成功 | 五类原生失败及保存篡改回归；桌面迭代／细分失败保留成功历史，展示失败过程但不替代结果；全部规模切线稳定复核 | 通过 |
| 独立梁柱／框架响应、平衡、细分及迭代验证，禁止线性叠加 | 连续悬臂压／拉梁柱、两柱释放框架、独立 RK4 变轴力参考；反力、弯矩、网格收敛、加载步数、固定预荷载横力缩放与整荷载非叠加；能力声明禁止响应叠加 | 通过 |

数据见 [独立数值](numerics.json)、[桌面验证](desktop.json)；验证命令与限度见 [verification.md](verification.md)。
