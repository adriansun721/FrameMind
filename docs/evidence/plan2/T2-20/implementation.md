# T2-20 实现与验收范围

日期：2026-10-05（Asia/Taipei）。需求：PLAN2.0 T2-20；US2-004、US2-037、US2-039；AC2-13 的显式拓扑子集。

建模工具栏新增“连接／分割”。单杆内部点分割、两根或更多杆件在指定点共享节点均先准备预览，列出新共享节点、旧杆到子段的稳定身份及归一化范围、均布荷载替换、保留支座／节点荷载、旧结果和任务目标的处理。确认重新核对工程身份、修订、实际输入与预览，通过 `applyProjectEdits` 原子提交一次修订；一次撤销恢复整组几何、条件和计数器。未确认／取消／失败保留正式模型。

Agent 提供 `split_member`、`connect_members`，并支持 `propose_model_edits.operations` 中同名操作。工具和手动入口共用领域校验、确认及回执；XYZ 支持规范 m、显式 `inputUnits.length` 和显示单位转换，范围参数仍为无量纲。确认回执有 `topology` 映射和正式对象 readback，保存在 `confirmedOperations` 中，重开后仍可核查。待确认任务显式绑定目标杆件和共享节点；旧杆件删除后目标校验要求重读新身份，不能把旧编号当作新对象。

技术决定见 [ADR-0053](../../../decisions/0053-explicit-engineering-topology.md)：固定垂距和朝向门槛，精确已有节点身份，无隐式合并；材料、截面、截面转角继承；全杆均布力按不重叠子段保持工况／坐标系／强度；自重按实际长度；外端边界与节点集中力矩保留，新内端刚接。未登记端部／荷载字段、零长、端点分割、失效目标或不同节点身份的端点冲突均阻止提交。材料、截面及边界条件编辑也参与草案冲突检查。

原历史结果保持原冻结输入和对象含义，当前结果依据输入依赖过期。工程分割产生正式可编辑对象；内部求解细分不创建工程对象，工具、界面及几何契约明确区分。普通交叉、浏览、拾取和缩放仍不连接。

没有引入新数值方法或依赖，没有实现 T2-21 节点成组合并与端点冲突解决。真实 AI 联测、整轮综合验收和干净 Windows 安装不在本任务验证声明中。
