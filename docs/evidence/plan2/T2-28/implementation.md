# T2-28 实现

日期：2026-10-06（Asia/Taipei）。契约与独立参考见 [ADR-0061](../../../decisions/0061-explicit-point-and-line-mass.md)。

节点可编辑各向同性平移点质量 kg，杆件可编辑整杆均布线质量 kg/m；附加惯性独立于结构密度，不自动生成自重。0 表示移除，不支持附加转动惯性、偏心或方向分量。手动属性与工具确认均通过 `applyProjectEdits`，工具使用 `set_node_mass` 和 `update_member`，支持显式 kg/t 与 kg/m、kg/mm、t/m、t/mm 输入单位。质量字段参与节点/杆件查询，模态质量来源可分页读取冻结工程身份。

C++ `/5` 在原工程节点平移自由度加入点质量，在内部梁单元线性/Hermite 平移一致质量加入线质量；扭转极惯性仍只来自密度和截面。保存记录分别列出结构质量、附加质量、总质量以及点/线来源，解码核对冻结输入和来源数值。静力自重只使用结构密度，新增质量不改变静力位移、内力或反力，也不令静力结果过期。

内部细分不复制点质量；每个子单元继承线密度，物理总量不变。工程分割保持线密度和原端点质量，新节点为无附加质量；复制继承附着设置，复制杆件不复制端节点质量，删除移除附着质量。节点合并预览点质量，确认后相加；回执保留前后对象及分割映射，操作可整体撤销。

质量编辑令模态结果过期，恢复原设置可恢复其当前性。新增点质量命令在草案协调器明确绑定节点；独立的人工坐标修改可以合并，同一质量字段冲突须重新确认。撤销保留修改后新算出的模态历史及其冻结质量，不以旧逻辑把该历史过滤掉。

入口 `npm run evidence:plan2:t228` 重建原生核心、生产构建、定向单元、独立数值和 Electron 证据。本轮不实现随机求解器、阻尼或模态计算书；后续随机工况应复用冻结模态质量依赖。
