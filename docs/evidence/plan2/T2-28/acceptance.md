# T2-28 逐项验收

| PLAN2.0 要求 | 实现与证据 |
| --- | --- |
| 分量、方向、单位；手动/草案/来源/保存 | ADR-0061 登记各向同性平移标量、kg/kg/m 和排除的转动/偏心分量；节点及杆件属性编辑；相同事务的工具草案确认；read_model 和 read_results mass；单位切换、保存重开桌面与公共接口回归 |
| 结构与附加质量分别展示；自重不重复；拒绝无效输入 | 界面、summary、质量来源及保存记录分别列出结构/附加/总量；独立原生自重开关对照；负值、非标量、无效数值/单位/对象、冻结来源篡改和派生溢出拒绝 |
| 线质量映射；细分守恒；工程操作继承 | 每个候选网格公开映射核查总量及点质量数量；显式 1+2 m 分割后实际原生模态与连续解核对；复制节点/杆件、删除和成组节点合并接口回归；端释放惯性坐标继承 |
| 过期依赖；静力荷载/自重保持 | 点/线质量参与模态依赖，不参与静力数值依赖；真实原生静力前后位移/内力/反力相同，含自重亦同；撤销/重做及保存后历史保持冻结质量。随机能力尚未开放，依赖扩展契约登记于 ADR-0061 |
| 独立频率/形态/总量；单位、撤销、重开 | 连续梁端质量边界特征方程、均布惯性连续公式、简支释放梁、旋转轴和固定节点质量；实际 K/M 残差、归一化、正交性及网格收敛；kg/t、kg/mm 转换；Electron 双主题 1080/1440、手动保存重开、确定性工具确认 |

端释放梁请求 6 阶在现有细分上限内明确保留未收敛状态；另外请求 3 阶验证低阶连续参考，未改变误差门槛。真实 AI 联测、模态充分性、随机响应、性能和干净 Windows 安装由后续任务负责。
