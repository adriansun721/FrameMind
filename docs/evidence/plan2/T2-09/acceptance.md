# T2-09 项目迁移、任务保存与重启续作

日期：2026-10-05（Asia/Taipei）。环境：本机 Windows、Node/Electron 项目依赖；确定性工具回放，无真实 AI 联测。

## 已交付

- v1 → v2 只读迁移；节点／杆件稳定身份、资源、荷载、自重及历史分析输入保留。缺少新增信息明确登记，不创建截面几何或旧确认回执。未来版本／损坏／跨项目任务数据拒绝激活。
- 草案、基础工程、目标、参数来源、成功回执、诊断工具证据、计算意图和调度状态随正式项目保存。全部聊天轮次在本机独立保存，凭据不进入普通工程或聊天记录。
- 恢复需要用户操作，未确认草案保持未确认；核对项目／目标／基础／回执，兼容编辑协调、冲突暂停。回执跨重开去重，撤销后保存并重开不会被旧重试重新应用。
- 保存计算中的不可变输入，用户继续后从冻结输入重启本地求解；不依赖 AI 凭据。保存失败的原文件保护沿用并验证现有原子存储入口。
