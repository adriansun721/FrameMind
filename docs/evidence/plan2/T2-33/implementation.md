# T2-33 实现与验收

日期：2026-10-07（Asia/Taipei）。审查基线：`9ea855637c230b4ac95d6542cdcd624c532fb823`。

分析工况管理现支持“单节点随机力”。用户绑定当前有效且已核对阻尼的模态结果、节点力自谱、一个全局单位方向和有符号空间系数，选取响应节点的 x/y/z 平移分量，并设置频段、初始频点、积分与精度预算。界面和确认后的工具草案调用相同项目操作和输入捕获边界；输入条件不成立时不创建无效工况。

C++ 原生 `/8` 服务重建并核对冻结模态及细分收敛来源。单位广义质量下先相加所有模态的复频响，再取模平方乘输入谱，保留同一输入源的模态相干项。规范输入为单边 Hz、kN²/Hz，输出为 m²/Hz 和 m RMS。细节见 [ADR-0066](../../../decisions/0066-single-node-random-response.md)。TypeScript 只复验响应与保存数据，不承担生产求解。

频点含输入谱折点和共振附近种子；逐轮二分、梯形积分，分别检查曲线中点误差、积分和 RMS 变化。冻结基底中全阶与减阶响应单独核查模态截断。频段必须完整等于输入谱有效频段，阻尼登记和模态频段覆盖不足、无参与、零能模态、不收敛、溢出、预算不足均明确失败。频率／积分／截断失败返回实际检查记录和预算，不发布部分成功结果。

响应面板展示曲线、分页数值、RMS、坐标系、谱单位、冻结模态与逐阶阻尼来源、三个精度检查；曲线超过 1000 点时显示保留极值的分桶图，原始数据完整保存。可以定位响应节点。RMS 明确为零均值平稳响应的统计均方根，不能作为瞬时峰值、确定性位移或受载变形。随机响应报告暂由 T2-38 承接。

结果依赖结构、质量、边界、模态结果身份、阻尼、绑定谱及随机设置。相关变化后保留历史数据并标记过期；无关静力荷载不会使随机结果过期。项目重开严格复算并核对响应数字、频点、模态来源和收敛记录，拒绝篡改。工具支持概要、冻结输入谱与响应 PSD 的有界分页，以及 RMS 数值引用；单位切换换算平方量，输入谱保留自身明确单位。
