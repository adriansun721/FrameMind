# T2-39 工作台文字、控件与窄面板修正

日期：2026-10-07（Asia/Taipei）。需求：PLAN2.0.md T2-39；US2-079、US2-082；AC2-21 的工作台文字与控件子集。

## 实际审计与修正

在实际 Electron 窗口中，按 1440×900、1080×680 CSS px、深浅主题、两侧面板最小／最大宽度审计。最小侧栏为 220 px；最大侧栏保留中间模型区至少 360 px。Windows 显示缩放为 150%，截图像素分别为 2160×1350、1620×1020；[audit.json](audit.json) 与 [desktop.json](desktop.json) 记录实际 CSS 尺寸。

| 审计发现 | 修正 | 证据 |
| --- | --- | --- |
| 普通名称／选择器与数字共用等宽字体；未统一正文行高 | 正文沿用 Segoe UI／微软雅黑字体栈及既有 12 px 字号、1.5 行高；名称、select、textarea 继承界面字体，number／单位输入用等宽数字 | 设置模型选择器及资源库名称／数值字体检查 |
| 深色单位文字 `#8a8a8a` 在 `#2b2b2b` 控件上对比度 4.10 | 深色次要文字改为 `#a4a4a4`；单位文字对比度 5.68，选中背景上也达到 4.5 | 桌面测量 8 类实际控件文字，对比度均至少 4.5 |
| 1080 窗口、最小侧栏时，科学计数坐标占用 119 px，而原读数宽度不足，发生省略 | 属性读数允许完整换行；坐标标签独立分配 20 px，给数值与单位更多空间；保留数值与单位含义 | audit.json 的坐标溢出与 after 截图 |
| 面板宽度较大时内部属性分组仍窄，固定 78 px 字段标签挤占输入宽度 | 属性表单及参数分组分别建立 inline-size 容器，窄分组将标签置于输入上方；无需切换工作台布局 | 所有窗口组合的 Y 坐标输入宽度至少 100 px |
| 固定单行卡片操作、完整任务长标签不适应窄聊天面板 | 操作按钮允许折行，确认仍为主操作；完整任务标签用 72 px 列，聊天面板不超过 300 px 时标签和值上下排布 | 完整任务与建模卡片的窄面板截图、键盘确认 |
| 部分裸表单控件缺少统一焦点；减少动态效果只涵盖时间线、未涵盖连接旋转图标 | 统一键盘焦点；减少动态效果时停用所有 CSS 动画、保留实际处理文字与时间线 | Escape 返回焦点、减少动态效果截图 |

变更集中在 `src/styles.css`，未增加运行依赖。现有底部属性栏、共享编辑与确认入口、真实时间线、停靠输入框、面板持续挂载与草稿状态沿用原实现。

## 后续控件沿用规则

- 沿用已有主题、字号、间距、行高、圆角与表面变量；普通文字、单位、错误和主操作在实际背景上至少 4.5。
- 中文名称及选择器采用界面字体；数值采用等宽数字。单位不得被省略为无法辨认的尾部。
- 面板和分组设置最小宽度与局部滚动；响应式规则按实际分组宽度生效，不能仅依据整个窗口。
- 长读数／说明可换行；表格保留局部横向滚动。长单行输入使用原生横向编辑，不裁改保存值。
- 卡片保持摘要、详情／编辑／确认的交互与顺序；按钮在窄面板折行仍须可达。输入框继续停靠。
- 键盘可操作并显示焦点；收起、拖动、主题切换不卸载编辑状态。减少动态效果偏好覆盖新增动画，处理状态仍有文字。
- 新页面进入 T2-43 时追加两窗口、双主题、窄面板的真实桌面截图与视觉检查；本任务不替代后续全部新增页面验收。
