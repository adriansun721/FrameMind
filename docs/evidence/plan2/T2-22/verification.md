# T2-22 实现与验证

日期：2026-10-06（Asia/Taipei）。需求：US2-043、US2-044、US2-047；AC2-14 的参数截面子集。

## 交付行为

建模工具栏的“参数截面”提供五类尺寸创建、共享编辑、复制、明确范围的批量指派和可选转角。确认前显示几何、A/Iy/Iz/J、公式近似、全部影响杆件及实际局部轴。改变草案后须重新预览；项目变化阻止旧确认；确认形成一个可撤销事务。旧截面属性编辑也通过影响预览再确认。

Agent 用 `read_section_contract` 读取支持范围；`propose_model_edits` 的 `create_section`、`update_section`、`duplicate_section`、`assign_section` 共用同一领域操作、预览和确认。既有选柱 `propose_section_change` 也接收尺寸。工具可显式声明毫米输入，读取返回几何、来源及显示单位。草案、确认回执、几何及冻结分析输入可保存重开。共用资源库支持五类尺寸并保留几何；计算书保留尺寸和公式依据，历史对比显示几何尺寸变化。

## 决策及公式验证

见 [ADR-0055](../../../decisions/0055-parametric-sections.md)。SCI P385 附录 B.2 的来源在实现前核查；固定五组独立参数见 `SECTION_REFERENCES`。圆形精确解，矩形 J 近似，矩形管和 I/H 使用明确的薄壁范围并拒绝超范围尺寸。数值正确性针对理想化模型，不宣称制造截面、圆角或约束翘曲已经验证。
