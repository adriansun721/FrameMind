## 输入身份

用 `node scripts/register-p25-01.mjs --input=<本机 STEP 路径>` 登记原始文件。工具流式计算原始字节 SHA-256、字节数和前 512 字节文件头；不复制 STEP、不把本机路径写入 manifest。输出按内容哈希命名，已有同名输出不会被覆盖。文件名仅用于定位输入，不参与身份判定。每次登记使用新的 run ID。

正式登记后核对 STEP 文件头标记与长度，检查哈希在不同文件名的副本上保持一致；若文件字节改变，必须产生新基准记录。不得将原始 STEP、BREP 或含路径的文件属性放入仓库。

## 独立 CAD 采集

参考必须由目标解析器之外的 CAD 工具读取，记录产品、实体定义、装配实例、候选杆件、切分工程杆件五种独立计数。另记录 CAD 工具名称、精确版本/build 或源码提交、读取设置、单位、坐标系和人工复核人。逐实例记录定义引用、父装配、局部/全局变换、端点、主轴方向、长度、截面参考和去向；逐实体标记杆件候选、忽略候选或不支持/待判定，并写出理由。候选杆件与切分工程杆件分别计数；一个实体切为多段时保留来源和分段范围。CAD 自身读取目标内核生成的解析结果不构成独立参考。

采集时保存独立 CAD 的原始测量导出或可审阅截图及其 SHA-256。人工测量需记录 CAD 中选取的对象、测量命令/读数、单位和截图；不得只抄目标解析器输出。当前指定文件已经登记为 `54d793bcf649d1e89d315c108e7e7faa61bd62cddf9737c1e56fda7b13c8fdca`、960432 字节，文件头为 ISO 10303-21 / AP203 / CONFIG_CONTROL_DESIGN，应用标记为 SolidWorks 2025。环境未发现 FreeCAD、CAD Assistant 或 gmsh；OpenCascade 8.0.1.1 的隔离读取尝试对该文件返回 `IFSelect_RetError`，因此没有虚构 CAD 参考数据。可复核的 Part 21 词法诊断保存在 `text-reference-54d793bcf649d1e8.json`，明确标为 partial-reference-only，不构成独立 CAD 基准。

## 预登记比较口径

| 比较项 | 归一化与比较 | 预登记门槛 |
| --- | --- | --- |
| 装配实例 / 定义 / 产品 / 候选杆件 / 工程杆件计数 | 分类后逐类整数精确相等；实例数不得由定义数代替 | 精确相等 |
| 实例位姿 | 右手坐标系；平移统一为 m；旋转比较相对旋转角 | 平移绝对差 ≤ 0.01 mm；旋转角 ≤ 0.001° |
| 长度 | 统一为 m，按对应实例与来源实体比较 | 绝对差 ≤ max(0.01 mm, 1e-6 × 参考长度) |
| 截面面积 A | 统一为 m²；需有 CAD 面积或独立人工/CAD 截面测量 | 相对差 ≤ 1e-5 |
| Iy、Iz、J | 统一为 m⁴，记录局部轴方向；J 需独立 CAD 截面属性或经记录的独立截面算法 | 相对差 ≤ 1e-4；未能独立测得的量标为未验证，不推导 J = Iy + Iz |
| 连接候选 | 记录接触/端点实体对和 CAD 中的几何关系；连接拓扑另行人工判断 | 0.5 mm 仅作为提出连接候选的端点距离阈值，不是位置、长度或截面精度 |
| 忽略候选 | 每个产品/实体定义/实例均有明确去向与理由 | 清单完整；去向分类精确对照 |

上述容差是 P25-01 解析结果比较的预登记门槛，不表示 CAD 内核绝对精度或工程验收容差。若指定模型的源几何精度不足以支撑该门槛，应在运行目标解析器之前修订本表并保留变更记录；比较之后不得追溯放宽。
