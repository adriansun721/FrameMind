- LC／CB 保存可复用荷载，AC 保存方法、来源、已验证的数值预设；结果独立冻结 AC 和完整荷载输入。

- 旧工况和组合迁移为稳定 AC 映射；原结果无改写。定义删除保留历史，原生、引用与计算书使用冻结来源。
- 能力注册表阻止未交付方法、未经支持的设置、组合和比较进入计算。

沿用现有原子文件替换与失败恢复。未新增数值算法、外部库或网络依赖。
