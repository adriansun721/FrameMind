# T2-42 实现记录

日期：2026-10-07（Asia/Taipei）。需求：US2-050、054、083、084；AC2-22；PLAN2.0 T2-42。

交付了独立登记、完整规模测量和报告汇总入口；同时修复静力详细过程多次深拷贝、超过方程预算仍先构造不可用网格，以及未变更恢复快照反复序列化的成本。求解方法、独立数值参考和性能门槛未放宽。方程预算不足给出所需及可用方程的中文诊断，错误不发布部分结果。

固定模型由共享领域 API 生成：`src/validation/plan2-performance-models.ts`。1,000 节点／3,000 杆与 1,440 节点／4,392 杆均使用真实参数矩形管，含自然基底约束、各层重力荷载、梁均布力及 LC1 顶层力；没有删除结构或为减少自由度增加上部支座。实际配置和初始方程分别写入登记文件，细分每级计算节点／单元／自由度／方程写入每个请求的报告。

`src/validation/t242-protocol.json` 固定三次重复、1440×900 深色桌面、实体及分析线、五类分析与资源失败场景、逐操作耗时／帧／内存门槛。登记保留硬件、Windows、GPU/驱动、电源方案、Node 和全部源／构建字节哈希。登记使用独占写入，正式运行对照协议、环境、模型哈希及构建，结束再次校验。现有版本不覆写；每轮使用独立输出目录。

登记已存在时直接使用后两步。重新构建或修改任何被冻结文件后，旧登记不能继续使用；保留旧轮次，另立有说明的新协议版本。`--smoke` 仅开发试运行，不计正式通过。正式测量的性能不达标、资源拒绝、缺失随机依赖与未测项目均返回失败；不能用成功包或预算内初始静力结果填补收敛和桌面证据。

桌面实测走生产 Electron、IPC、原生核心和项目保存入口，记录旋转帧、20 ms 主线程回调探针及 100 ms Electron 进程工作集。核心记录 Windows Job 峰值提交内存。取消必须先观察实际原生阶段、核实真实进程 close、等待迟到消息并保存检查没有增加结果。16 MiB 原生故障验证已有模型及结果保护和之后的旋转／保存；三种高级预算拒绝也分别走正式 UI 入口。测量脚本的 300 s 看门狗是整轮截止，不是无响应检测，不把缺失操作算完成。v1 误终止启动包装进程，已中止保留；v2 缓存真正的 Electron 主进程 PID，结束专属进程树并核实实际主进程及已观察的原生 PID 退出，关闭也有限等待。退出核查失败停止总采集，禁止继续被遗留进程污染的样本。

Word／PDF 通过真实导出入口测量，保留实际文件和字节数；结果保存项目和原生请求使用 gzip 压缩保留完整内容。源码仪器只观察该应用启动的真实子进程，不替换结果、降低实体细节、关闭恢复或强制 GC。原生资源遥测不含凭据、工程输入或用户数据，独立输出到 stderr，不进入工程成功协议。

取消口径使用实际点击到界面确认与子进程退出的较晚时刻；Playwright 往返耗时独立记录，避免把自动化轮询成本混入用户响应。Electron 内存是采样最大观测值，可能漏瞬时峰值和重复共享页；原生 Job 内存独立报告，不能混为一个精确全应用峰值。建模成本是领域构造耗时、选择是项目树公开入口，不代表逐节点人工输入或画布拾取专项验收。

试运行失败保留在 `pilot/`：默认候选每杆最多八单元产生了超方程预算的未使用映射；正式登记前明确候选 1／2 单元。两种配置都不能把初始静力结果叫网格收敛。后续试运行还发现大结果进入正式状态后主进程 V8 OOM；这一可操作性缺陷须由正式实测如实记录，未宣称恢复去重已经解决全部大结果开销。
