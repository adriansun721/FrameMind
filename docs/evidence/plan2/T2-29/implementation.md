# T2-29 实现

日期：2026-10-06（Asia/Taipei）；方法见 [ADR-0062](../../../decisions/0062-modal-damping-and-truncation.md)。

- 工况独立保存统一模态阻尼、指定阶次覆盖、来源与依据，绑定最新有效模态身份。阻尼从无阻尼模态输入剥离，频率/振型保持不变。
- 模态结果面板提供手动输入、覆盖增删、实际有效值表、身份失效提示、频段覆盖、增阶准备和预算反馈；没有隐式阻尼默认值。
- 工具 set_modal_damping 走现有 propose_model_edits 草案确认事务；read_results summary/modes 返回相同有效值、来源、绑定身份和截断记录。缺失/待核对配置的有效阻尼为 null。
- 保存解码核对模态身份与频率，旧项目没有阻尼字段仍可打开。设置可整组撤销/重做，重算或排序/依赖变化须重新核对。
- 登记参与质量、频率覆盖、频率加密、逐次响应误差和频点/积分收敛之间的区别；实现同结构历史增阶频率记录，响应误差尚未验证明确标记。

边界：接受有限 0 < 阻尼比 < 1，拒绝零/临界/过阻尼及 Rayleigh。此次仅准备后续随机条件，不计算 PSD/RMS，不以频段覆盖或返回数量宣称充分；阻尼响应作用由 T2-33 数值验证。
