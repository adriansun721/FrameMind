# T2-29 逐项验收

| PLAN2.0 要求 | 实现与证据 |
| --- | --- |
| 统一/逐模态阻尼，手动/工具，来源明确 | 统一值与逐阶覆盖共用校验与事务；source/basis 保存展示，建议不改标为用户值；Electron 手动覆盖及公共工具确认回归 |
| 模态身份、编号与覆盖失效核对 | 绑定 analysisId/createdAt/有序频率，仅最新有效结果应用；同频重算、增阶、依赖改变后为 needs-review，所有有效值 null；旧覆盖不自动预填 |
| 查询/预览有效阻尼及来源，反馈，重开 | 有效值表、read_results summary/modes、草案回执同源；非法/缺失值、重复/越界阶次、来源缺失及篡改绑定拒绝；项目撤销/重做与 Electron 保存重开 |
| 截断、充分性、逐次增阶与预算登记 | ADR-0062 登记 PSD/RMS、参与度、频点/积分与网格收敛要求；频段覆盖仅筛查，记录请求/返回/最高频率/零能模态；3→5 历史频率检查与预算上限，原生网格停止明确保留 |
| 频率、覆盖、有效参数；响应作用后续验证 | 独立连续悬臂首频对照；2% 统一与第二阶 4% 建议覆盖；重算频率/振型完全相同但绑定失效；数值报告只声明条件核查，PSD/RMS 作用由 T2-33 完成 |

响应精度、参与质量未评估、真实 AI 在线联测、性能和安装验收均未宣称完成。
