# T2-21 实现与范围

日期：2026-10-05（Asia/Taipei）。需求：PLAN2.0 T2-21；US2-039、US2-040；AC2-13 的节点合并部分。

建模工具栏增加“节点合并”。先按固定长度检查重复／近重合节点，展示距离与单位，再明确合并目标。影响预览列出杆件端点、材料截面、杆长、局部朝向、支座六自由度、节点力／力矩及工况、均布荷载、重复杆、零长杆和已保存任务引用。所有冲突选择初始未决；选择保留／移除方式，逐条确认删除杆件的均布荷载，接受目标坐标引起的几何变化后才能生成成组确认草案。

Agent 新增 `inspect_near_nodes`、`inspect_node_merge`、`merge_nodes`；批量 `propose_model_edits` 也接受 `merge_nodes`。只读工具始终可用，合并中英文意图可获得修改工具。规范 m、显式 `inputUnits.length` 和显示单位预设使用现有单位转换契约，距离和容差不会因显示单位改变判据。

手动与工具共用领域检查、事务、确认、回执和 readback。确认重新核对项目身份、修订、输入及预览，失败无部分变更；一次修订和一次撤销恢复完整拓扑与条件。回执持久保存并幂等，撤销后的旧重试不会重做。相关任务显式绑定节点目标，源节点被删除后要求重读；原历史结果和进行中分析保留冻结输入，当前结果按依赖过期。待确认草案可保存重开并重建预览，不变成已确认。

技术规则及选择边界见 [ADR-0054](../../../decisions/0054-reviewed-node-merge.md)。没有引入新依赖、数值算法或项目格式版本；支座冲突支持选一个保留或全部移除，新约束组合继续由既有支座编辑能力处理。重复杆可以明确保留为并联；荷载不自动跨杆转移或跨工况累加。

独立原生参考：E=200 GPa，ν=.3，A=.01 m²，Iy=Iz=J=1e-4 m⁴，3 m 悬臂，基部六自由度固定，近重合节点分别加载 −4 和 −6 kN。合并后的端位移 −0.0045 m，转角 Y=0.00225 rad，基部 Z 反力 10 kN、Y 反力矩 −30 kN·m。冲突模型明确删除重复杆、零长杆及其均布荷载后相同；明确保留两根并联杆且其中一根保留 −2 kN/m 均布力时，端位移 −0.00275625 m，总反力 16 kN、基部反力矩 −39 kN·m。参考由 PL³/(3EI)、PL²/(2EI)、qL⁴/(8EI) 与总平衡独立给出，并联用 2EI；每项容差 max(1e-12, |参考|×1e-9)，任一超限即失败。
