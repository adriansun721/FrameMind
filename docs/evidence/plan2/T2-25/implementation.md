# T2-25 实现与技术决定

日期：2026-10-06（Asia/Taipei）。需求 PLAN2.0 T2-25，PRD2.0 US2-041／042／051，AC2-15 的端部释放子集。

详细方法、支持矩阵、独立参考和预登记误差／奇异判据见 [ADR-0058](../../../decisions/0058-local-member-end-releases.md)。

- 两端分别提供刚接、My、Mz、My+Mz，沿局部轴解释。新建、手动属性和共享事务贯通，独立于节点全局支座。
- create/update_member(s)、propose_model_edits、整体任务 operations 支持释放；read_model fields 和对象读回包含释放。未确认草案不修改工程，非法或额外释放字段拒绝。
- 项目和冻结历史保存释放，旧文件仍为刚接；复制保留，工程分割只把释放移到原起终点，人工更改、撤销重做参与现有依赖过期判断。
- 有实际释放的正式分析选择 C++ `/3`。刚度和节点一致荷载共同凝聚，恢复原始梁端转角、端力和沿杆响应。局部／全局均布、自重、正负组合使用同一路径。
- 仅消去显式释放导致的完全脱开节点转动，记录节点、方向和参考坐标。未抵抗节点力矩和真实机构明确失败，不加隐式刚度。实际恢复矩阵与向量可供过程／报告查询。
- 空心环共用于实体和中心线；选中时按起终点解释分量。过程／计算书说明脱开节点转角不可确定，梁端转角由恢复给出。

实现边界：没有新增扭转／轴向／剪切释放、半刚性连接或内部计算细分；未宣称 T2-26 的收敛能力、真实 AI 联测、目标规模性能或干净 Windows 安装验收完成。
