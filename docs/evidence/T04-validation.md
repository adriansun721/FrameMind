## 输入来源与记录

先 `captureAnalysisInput`，再修改原模型的节点、截面、支座和荷载；使用已捕获快照求解仍得到登记的原始空间悬臂响应。保存修改后的模型及原结果再重开，计算输入、求解配置及各对象结果均保留；原模型与旧计算输入可以不同。内存中的新输入与重开的输入均禁止嵌套修改。

指定杆件的受控记录最多产生三份 12×12 矩阵及关联向量，无整体矩阵序列化。M3 的自由度映射、EA/L=1e6 kN/m、来源 ID 和杆端力均已核对。缺失对象、缺失版本、未来版本或不匹配配置不能冒用当前实现重建。旧结果不含求解配置时仍可打开；无效容差配置被拒绝。

## 桌面验收

`e2e/t04-analysis.spec.ts` 从真实 Electron 页面完成：创建四个节点及自定义材料/截面 → 连成三杆 → 创建 N1 固定支座及 N4 六分量荷载 → 本地计算 → 查看 N4 位移 (0.028,0.009,-0.024) m、N1 反力矩 (17,-29.5,5.25) kN·m 和 M3 杆端力 → 修改 N4.z → 从项目树查看过期结果 → 保存中文路径 → 关闭重开 → 保留旧响应及过期标识 → 重算获得当前版本的新响应。
