# T10 验收记录

- 范围：`PLAN.md` T10；实现契约见 [ADR-0010](../decisions/0010-t10-self-weight.md)。
- 参考模型：4 m 水平悬臂，`E=200 GPa`、`ν=0.3`、`ρ=7850 kg/m³`、`A=0.01 m²`、`Iy=0.0002 m⁴`，固定根节点，`g=(0,0,-9.81) m/s²`。
- 独立基准：总质量 `314 kg`，总重量 `3.08034 kN`，竖向总力 `-3.08034 kN`；根部竖向反力为 `+3.08034 kN`；端部位移按 `qL⁴/(8EIy)` 核对。

## 已验证行为

1. 自重设置明确展示启用状态、LC1、重力三分量与单位；密度和面积沿用材料/截面属性。
2. 自重不写入均布荷载列表，而是以冻结的项目分析输入参与同一等效荷载和结果恢复链路。
3. 修改截面面积为 `0.02 m²` 后新分析总重量为 `6.16068 kN`；旧结果仍显示 `3.08034 kN`，保存重开后新结果与自重设置均保留。
4. 重复求解不会累加自重，反力与输入快照可重建。
