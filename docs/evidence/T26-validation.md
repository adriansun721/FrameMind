## 桌面固定回放

`e2e/t26-section-comparison.spec.ts` 的三个真实 Electron 场景已通过：

1. 无选择时补齐信息，选中M1后列出原/新截面参数和一根柱的独立三维预览；确认前保存模型及结果不变。确认后自动本地重算并解释实际差值，引用点击打开明确的同一分析对。
2. 改变分析对的选择使在途解释取消，迟到回复不覆盖新上下文。
3. 更改柱选择使旧确认失效，重新生成显示新范围；卡片修改自定义A后暂停旧预览，更新后显示实际参数；拒绝不修改模型或结果。

整组撤销直接恢复原sectionId而非撤销一次计算，保留两次结果；点击旧对比引用仍使用原前后分析ID，重做及保存重开后结果来源仍可复核。

## 真实 DeepSeek

`node scripts/verify-t26-online.cjs` 复用用户已有本机加密连接的隔离副本，以真实 `deepseek-flash` 完成五个对话步骤：读取选中柱并预览、用户阶段确认、实际本地重算、自动解释，以及指定 N2 全局x位移 / N1 全局z反力 / M1 起点杆端N的数值核对。没有替换 fetch，没有保存或打印凭据。

三项前值、后值及差值均与上述独立参考一致，两个分析ID、LC1来源和冻结输入版本完整保留。模型只有 M1 改用 S2，M2 与共享原截面不变，自重总量正确更新。三项对比按钮可打开同一前后分析对；回复区分计算事实与原因推断，说明面积、自重和刚度同时变化，没有安全或规范符合性断言。问答和实际工具输出见 [T26-online.json](T26-online.json)，截图见 [真实预览](T26-online-preview.png)、[真实问答](T26-online.png)、[真实对比表](T26-online-comparison.png)。`npm run evidence:t26:online` 可重验，会产生 DeepSeek API 用量。

真实复查发现并修复两处接口问题：摘要原先缺少节点标签到稳定ID的映射，模型用标签作为id时被工具拒绝；对比输出原先嵌套了单值引用标记，模型可能与差值标记混用。最终摘要提供受分页约束的对象映射，每次对比仅提供一个可点击标记，保留完整前后数值和来源。修复后两轮真实完整流程均通过。
