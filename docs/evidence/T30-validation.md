# T30 验收记录 PDF 导出与版面核验

日期：2026-10-02。平台：Windows / Electron。实施基线：`f403d59`；实现提交：`36407db`。需求：PLAN.md T30、PRD US-054/US-055 与 AC-18。用户确认报告导出接口、Electron 文件写入接口和桌面 Word/PDF 导出流程作为测试边界。

## 同源与历史结果

工程计算书对话框提供 Word 和 PDF 两个入口，共用分析、杆件对象和步骤选择。正文与附录由同一 `ReportBlock[]` 内容入口组织；图片由同一冻结来源生成。每次开始导出即捕获来源，之后排版、打印和写入均不访问当前编辑值，不调用 AI 或网络。

桌面组合样本为 E=200 GPa、A=0.01 m²、L=4 m 的悬臂，1.5×LC1−0.5×LC2，保留自重、原工况均布力和加权输入；独立轴向 EA/L=500000 kN/m、UX=0.00003 m。先把当前模型面积改为0.04 m²并重算，再选择原组合分析，报告仍输出原面积、刚度、响应与来源 ID，不混入新分析。附录只选择 M1 的杆件过程和整体约束步骤，不输出未选的映射、组装贡献或完整矩阵。

公开导出测试将相同报告同时转为 HTML 和 DOCX，逐项对照全部标题、正文和单元格；输出选定组合、单位、公式、教材引用和过程标记。真实文件核验脚本则提取产品 PDF 的实际文本，与 Word OOXML 每个段落及表格单元格对照，三组样本均为零缺失。独立点击导出的报告生成时间和页数可以不同，原分析时间、计算输入、响应、图片来源及附录选择一致。

## 导出失败与文件保护

真实桌面入口验证中文项目/报告文件名、重复覆盖、取消文件选择、无效图表及不存在目录。正常导出返回保存路径；取消提示已取消；图表解码或写入失败提示错误，不返回成功。失败后原 PDF 逐字节保持，目录没有临时 `.tmp` 或 `.bak` 输出，隐藏排版窗口被清理，应用主窗口仍可用。

文件公开接口另注入替换时目标锁定：新 PDF 完成临时写入后替换失败，原文件从备份恢复，最终字节和最初内容相同，仅保留原中文文件名。产品排版仅在字体与图表准备完成且取得有效 PDF 字节后写入；60秒超时同样清理窗口。
