# AI 对话交互修改验收

日期：2026-10-03。需求来源：本次用户会话及两张参考截图；后续明确缩小输入框的竖向高度。实现约定见 [ADR-0036](../decisions/0036-ai-conversation-home-and-pause.md)。

## 验证

- 类型检查与生产构建通过。
- 全套 Vitest：38 个文件、276 项测试通过。
- 全套桌面回归首轮：70 项通过、9 项失败、4 项安装版测试按配置跳过。失败中五项源于新增按钮名称与旧文件菜单定位冲突，两项仍断言已按需求删除的首次使用引导，另两项在节点输入与打开项目时出现瞬时失败。
- 修正按钮的可访问名称及演示脚本的首页断言后，使用最新构建复验失败路径，并复验面板布局和新交互，共 18 项全部通过。全套已执行测试的 79 个独立用例最终均验证通过；安装版四项不属于本次开发构建验证。
- 新增桌面测试覆盖最近三条历史、展开全部、历史续聊、输入区域在按钮上方、紧凑高度、文件实际发送、插件连接入口以及发送/暂停/继续/完成状态。任务测试验证重复暂停、保留已执行工具、忽略迟到响应和上下文失效取消。
- 用户澄清缩小方向后，输入框默认文字区改为一行、整体约 70 px 高；横向宽度恢复原有桌面 260 px、紧凑窗口 220 px。全套 276 项单元测试及构建再次通过；7 项输入框与面板布局桌面测试通过，已查看最新截图。

## Standards

无实质问题。取消与失效请求仍不能执行工具或发布草案；暂停保留完成的工具消息，恢复使用独立网络请求身份。历史恢复保留原模型引用，现有确认和重试检查仍使过期草案失效。附件沿用消息长度与主进程校验边界；默认宽度仍在原拖动范围内。未发现可操作的代码异味。

## Spec

无具体缺陷。历史首页与展开、发送后进入现有对话、移除引导、文字在上与按钮在下、文件和插件入口，以及箭头、方块、三角形的状态切换符合要求。最新竖向高度要求通过一行文字区和减少上下留白落实，横向默认宽度已恢复。

现有供应商接口返回完整回答，恢复时重新请求当前未完成轮次，无法恢复供应商内部生成位置；本地仍为同一聊天条目，并保留已完成工具。历史仅保留在当前应用会话内；插件入口使用现有 DeepSeek 连接设置。

审查汇总：Standards 0 项，Spec 0 项。

## 后续验证：对话留白与逐步显示

- 消息区、历史区和输入框的左右留白改为随面板宽度变化的 20–40 px，实际桌面回放验证宽面板留白至少 24 px、最窄面板两侧各 20 px，并检查消息区无横向溢出。
- 完整回复校验后逐步显示；已验证 Unicode 表情不拆分、结果引用标记完整、无法核对的引用不发布、渐进显示阶段暂停/继续不重复请求，以及取消或上下文变化停止输出。
- 类型检查和生产构建通过；全套 Vitest 38 个文件、280 项测试通过。AI 对话与 T27 恢复桌面回归 9 项全部通过，覆盖渐进显示、暂停/继续、完成后恢复发送箭头、历史回复直接恢复及原有恢复路径。
- T25 实际结果引用与上下文失效桌面回归通过；此次共验证 10 个独立桌面用例。清理已完成回复的渐进显示临时状态后，重新构建并复验留白/渐进显示用例通过。
- 已查看 `test-results/ai-progressive-wide.png` 与 `test-results/ai-progressive-compact.png` 的实际桌面截图，确认两种宽度下消息和输入框留白正常。

### Standards

0 项发现。渐进显示在校验完成后发布，Unicode 字符和引用标记保持完整；本地暂停/继续、取消、上下文失效及草案回滚符合 ADR-0028 和 ADR-0036。未发现可操作的代码异味。

### Spec

0 项发现。加大的响应式左右留白和完整接收后逐步显示回复符合用户要求；暂停/继续、历史直接恢复及引用展示保持正常。

此次审查汇总：Standards 0 项，Spec 0 项。
