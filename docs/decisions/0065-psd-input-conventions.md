# ADR-0065：随机输入 PSD 约定

日期：2026-10-06（Asia/Taipei）。范围：PLAN2.0 T2-32。实现前登记。

内部使用实信号连续自功率谱：单边、非负 Hz、激励量为力（kN）或平动加速度（m/s²），密度分别为 kN²/Hz、(m/s²)²/Hz。零均值随机部分的均方值为谱面积；平方根为输入激励 RMS，均值和离散 DC 线谱不在此表格能力内。本任务只准备输入，不求解结构响应。

频率点必须严格递增、有限、非负；密度有限且非负；至少两个点、最多 10000 点。有效频段显式提供，必须与首末点一致且宽度为正。段内线性插值，以各段梯形精确积分；有效频段外为零。端点的跳变不形成额外面积，禁止自动补点、排序、合并重复点或裁剪负值。全零谱允许。

外部表格必须明确 frequencyUnit（Hz / rad/s）、excitationUnit、densityUnit、sidedness 和 band。双边仅支持实信号偶谱正频半轴，标识 two-sided-even-positive；负频率、一般互谱、非对称双边谱及离散线谱拒绝。其完整双边面积是正半轴面积的两倍，包括零频端点按连续函数极限加倍；不是 FFT 离散 bin 的特殊 DC/Nyquist 规则。

由外部到内部：f = ω/(2π)，S_f = 2π S_ω；激励量换算倍率 a 对密度乘 a²；双边正半轴转单边密度乘 2。有效频段和全部点同步转换。反转换采用逆倍率，转换前后以物理规范单位比较面积，容差 max(1e-12 相对面积, Number.MIN_VALUE)，溢出或非零下溢拒绝。单位倍率来自既有 units.ts；新增 rad/s 分母的 PSD 单位，不以单纯轴标签替换代替密度换算。

CSV 为 UTF-8、严格两列 frequency,density；可接受两字段双引号包装及 CRLF/BOM，拒绝多列、空字段、非十进制数值、重复点、错误顺序、空数据与未知表头。单位和谱约定通过导入面板显式选择（初始为空），有效频段同样明确输入；文件内容不隐式覆盖面板元数据。导入完成后表格、预览、积分和保存复用同一领域函数。CSV 不猜测单位或修复数据。

谱是可复用工程输入资源，保存规范化数据与确定的插值/频段外约定。create/update/delete_psd_spectrum 经共享 applyProjectEdits、原子草案、确认、冲突核对、回执、撤销和项目保存重开；read_model 的 psd-spectra 集合读取正式谱。已有 v2 文件缺字段恢复为空资源，不影响静力/模态等已有依赖；后续 T2-33 负责随机工况绑定和响应依赖。

独立验收：矩形 10–20 Hz、2 kN²/Hz 面积 20 kN²；三角形 (0,0),(5,4),(10,0) 面积 20 kN²；N²、rad/s、双边正半轴往返物理面积不变。界面验证模板、手动点、导入失败不提交、图形与保存一致、确认前后读取、撤销和保存重开；双主题 1080/1440 宽度。

依据：[SciPy periodogram 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)说明密度单位为幅值平方/Hz，以及实信号单边与双边的功率关系；[SciPy 信号处理指南](https://docs.scipy.org/doc/scipy/tutorial/signal.html)说明 ω=2πf。雅可比换算和连续偶谱端点规则是本产品显式定义。
