# ADR-0026：T25 AI 解释与实际结果引用

- 日期：2026-10-02
- 状态：已接受
- 范围：所选成功分析的只读结果、来源、引用与定位；不增加求解理论、模型修改或规范验算

## 冻结分析与工具

每次聊天捕获已应用模型、稳定选择和当前所选成功分析。分析快照只保留实际输入、节点和杆件结果，不复制大型过程矩阵。上下文增加 analysisId；模型、项目、选择或所选分析变化都会取消旧任务。没有所选工况/组合的成功结果时返回 missing-input，不能借用其他来源的成功结果。

`read_results` 提供 summary/nodes/members，默认50项、最多100项；摘要提供节点各平移分量的绝对值极值，不宣称连续全结构最大位移。`read_result` 核对一个稳定对象、结果类型、分量及可选沿杆位置，输出可追溯引用。指定 analysisId 必须等于所选分析；身份、类型、分量、位置、分页和未知字段均独立校验。

摘要还提供本次冻结输入的有效支座、节点荷载、均布荷载与自重，各类最多limit项并报告总数；原组合工况荷载另列并限制各类最多limit项。组合有效条件已加权，禁止再次乘系数。原因说明只定性描述已核查的方向与边界，不自行计算新数值，不拿当前编辑条件解释旧数值；全局Z向上、X/Y水平。条件截断时明确不完整，不能推断未读取部分。

节点量使用全局 XYZ，位移 m、转角 rad、反力 kN、反力矩 kN·m。杆件分量 N/Vy/Vz/T/My/Mz 使用冻结局部轴，前三项 kN、后三项 kN·m。杆端节点作用力与正局部 x 面截面内力分别命名，沿杆内力复用 T09/T14 的真实恢复入口，不另写物理计算公式。

引用保留完整分析 ID、冻结输入版本、求解时间、来源工况或用户自定义组合及系数、稳定对象与冻结坐标、分量、单位、数值、符号与沿杆位置。current 判定复用完整输入内容比较，不仅比较 revision。

## 引用呈现与定位

工具产生 `[[result:<本轮调用身份>]]` 标记；最终答复只允许使用本次实际工具输出中的标记。读取结果却不给可核对引用、或引用不存在的标记，会失败并隐藏该答复。按钮中的数值由本地引用生成，不使用 AI 自写的数值。

点击引用展开“引用结果项”，显示原始精度数值及冻结位置，定位仍存在的节点/杆件；杆件切换相应内力分量和位置。历史引用保留原分析，模型删除对象时仍显示冻结输入。关闭引用恢复当前来源最近分析。原说明中的推断不会因此升级为计算事实。

提示要求“计算事实”和“原因推断”分开，推断陈述依据与不确定性；历史输入明确需要重算。界面说明线弹性结果不提供安全或规范结论。引用校验保证引用身份和按钮数值一致，不声称对自由文本中的每个因果句进行自动证明。

## 上下文与边界

引用对话不作为后续消息的历史输入，避免旧标记进入新回合；同一模型、选择、所选分析下的普通对话继续使用原历史策略。原问答留在会话中，可点击核查，不写入项目文件。重新计算、选中不同分析或编辑模型后重新捕获快照，迟到答复不能覆盖当前状态。

沿用既有 DeepSeek HTTPS 工具调用协议和本机加密凭据；新增两个本地工具定义，无新服务或接口版本。真实调用复用用户已有凭据的临时隔离副本。验证见 [T25 验收记录](../evidence/T25-validation.md)。
