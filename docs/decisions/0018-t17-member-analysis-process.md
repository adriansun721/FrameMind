# ADR-0018：T17 杆件真实计算过程

- 日期：2026-10-02
- 状态：已接受
- 范围：已完成分析中的指定杆件过程查看、旧结果补算和教材关联

## 决策

过程面板使用用户指定的分析结果及其冻结输入。`getMemberAnalysisRecord(result, memberId)` 只为选定杆件按该输入重建局部刚度、坐标转换、整体单元刚度、自由度映射、局部/整体位移、等效荷载和已保存的杆端力；它不读取当前编辑模型，也不保存或伪造整体消元轨迹。记录的来源分析 ID、项目修订号、求解器配置和 `reconstructed-from-frozen-input` 标记在面板中可见。

矩阵默认折叠，展开后使用稳定节点 ID、六自由度顺序和 0 起始整体索引显示行列；向量显示分量顺序与单位。过程入口位于选中杆件的属性面板，因此选择状态和分析来源是同一对象关系的一部分。当前结果过期时仍可查看，但明确标注过期。

旧结果若缺少求解器配置或使用不支持的配置，仍可查看已保存的杆长、局部轴和杆端力，但不能把重建结果冒充原运行的记录。面板提供“基于冻结输入补算过程”入口，先复制原冻结输入并强制使用当前已验证求解器，生成新的分析 ID，记录 `supplemental-reconstruction` 和原来源分析 ID；补算只用于过程查看，不修改原结果来源。

## 教材核查与实现约定

参考扫描版《计算结构力学》（阎军、杨春秋，科学出版社，2014）按书内印刷页核对：第 5 章起始页 117；5.2 页 118 及页 126 的式 (5-28)—(5-30) 涉及局部到总体坐标转换；5.3 页 122—125 的式 (5-14)—(5-27) 涉及空间刚架单元局部刚度和六分量向量；5.4 页 127 说明端部自由度对号；5.5 页 127 起说明总刚度阵集合；5.6 页 129 说明载荷向量形成；附录 IV 页 180 作为程序组织线索。PDF 页序与书内页码不同，证据记录使用渲染页脚核对的书内页码。

教材在 5.2 节把 `[T]` 写成从总体到局部的另一转置方向。实现把局部轴作为转换矩阵的行向量，所以使用 `u_local = T · u_global`，并以 `K_global = Tᵀ · K_local · T` 组装。两者是同一正交变换的转置表示；这是矩阵存储约定的修正，不是单元理论或符号的变更。教材的 5.3 节项 `EA/l`、`12EJ/l³`、`6EJ/l²`、`4EJ/l`、`2EJ/l` 和 `GJ/l` 与实现矩阵逐项对应；教材的六分量顺序与实现的 `[ux, uy, uz, rx, ry, rz]` 及 `[Fx, Fy, Fz, Mx, My, Mz]` 对照。教材使用 1 起始的程序位置说明，界面同时显示稳定对象 ID，并把内部整体索引明确标为从 0 起。

## 替代方案

不把 12×12 矩阵全部写入项目文件，避免历史文件膨胀及矩阵与输入脱节；不从当前模型重算历史结果；不在没有教材原文核对时显示虚构的公式编号。整体自由度组装、约束消元和大矩阵过程由 T18 负责。

验证见 [T17 验收记录](../evidence/T17-validation.md)。
