# ADR-0067：杆件随机力与空间随机源

日期：2026-10-07（Asia/Taipei）；范围：T2-34。

每个 sourceId 唯一标识一个零均值平稳随机过程，绑定规范单边 Hz 力自谱（kN²/Hz）。节点作用为全局单位方向乘有符号无量纲 scale；整根工程杆件均布作用为全局单位方向乘有符号 scalePerM（1/m），实际线力为该随机过程乘系数（kN/m）。首批仅支持整杆恒定系数，不支持局部方向、部分杆段、随机力矩、频变相位或移动作用。

同源所有空间作用的广义力先有符号相加，模态复传递函数亦相加，最后取模平方乘源自谱。不同 sourceId 显式声明 independent，响应自谱相加，积分得总均方值后开方。即 S_y=Σ_s |Σ_r φ_y,r Q_s,r/(ω_r²−ω²+i2ζ_rω_rω)|² S_s，RMS=√∫S_y df。即使两个源绑定同一 PSD 表，其随机过程仍独立。不接受部分相关、互谱或其他源间关系。

整杆分布的 Q 由冻结模态实际细分单元上的 EB 形函数精确积分获得，使用节点平移、转角以及杆端释放独立坐标。横向积分包含 L²/12 的端转角项，不能以杆端等分点力代替。内部细分不改变源身份、方向或每米系数。保留旧单节点设置和 spectrum 冻结格式；新增 sources 和 spectra 格式，禁止混用。最多 16 个源、128 项作用，沿用 T2-33 频点与原生资源预算。

各源本轮使用相同完整频段，各自可有不同 PSD 表和折点；频段不一致明确拒绝。总响应沿用 T2-33 的曲线、积分与模态截断检查；零空间合力允许相干抵消，但每项非零作用的模态方向需有覆盖。结果冻结所有源、空间作用、各输入谱、模态及阻尼。任一依赖修改使结果过期；无关静力荷载仍不影响随机结果。

单位存储：节点系数无量纲；杆件系数 1/m。界面及工具可显式转换 1/mm；方向、源身份不转换。均布作用在视图以空间系数箭头标记，不把随机力标为瞬时确定力；结果展示冻结来源及定位工程对象。

理论来源：[Altair 随机响应](https://help.altair.com/hwsolvers/os/topics/solvers/os/analysis_random_response_r.htm)、[COMSOL 随机振动理论](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_theory.06.055.html)。首批作用范围、同频段限制和预算为产品决策。
