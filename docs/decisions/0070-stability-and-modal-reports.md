# ADR-0070 稳定性与模态计算书

日期：2026-10-07（Asia/Taipei）。状态：已接受。范围：PLAN2.0 T2-37。

## 来源与内容

沿用 T28—T30 的单次来源捕获和同源 ReportBlock：Word 与 Electron PDF 使用相同输入、文本、七位有效数字、公式、表格和图形。允许线性静力、初应力弹性二阶、特征值屈曲及模态；随机响应仍由 T2-38 接入，不用静力正文替代 PSD/RMS。

报告捕获所选结果的冻结输入和原输出，递归冻结新增方法记录；同时捕获当前有效性，正文显示工程 ID、分析 ID、工况、输入修订、完成与收敛状态、历史过期状态、求解器、实际阶段、生成时间和单位。异步包装使用导出开始时克隆的工程来源，后续编辑不能更换输入。报告标题使用导出时项目名称，历史条件与对象身份始终来自分析快照，不把标题名称当成历史工程条件。

静力正文与既有可选过程附录保留。二阶输出原荷载、设置、加载因子、校正残差和增量、网格比较、同次实际线性基准的工程节点 XYZ 位移以及二阶完整节点、反力与端力。组合系数用于加权输入，二阶输出不作线性叠加。理论明确为冻结线性轴力构造几何刚度的初应力小位移近似，不更新参考轴或轴力再分配。

屈曲分别列固定与参考的原工况、系数、原始荷载和等效荷载／自重，λ 只放大参考部分。列因子、残差、实际网格收敛及原记录形态。模态列密度形成的结构质量、附加节点质量、附加线质量、总质量、频率、特征值、零能模态、正交误差和收敛记录。质量与静力自重分开，不重复生成荷载。

特征结果不填静力位移、反力或端力槽。每阶图使用原工程杆件的已存沿杆样本，虚线显示冻结分析线，归一化形态单独缩放到模型跨度的 12%，图中文字说明全局投影和缩放。模态为单位广义质量，屈曲为计算向量欧氏范数归一化；系数不随显示长度单位转换，不能解释成实际位移或安全系数。脱开方向的节点转角明确为参考值。任何方法均不生成安全、极限承载力或规范合格结论。

新增附录复用 readRecordedProcess，只读取原运行保存记录；选定轮次的矩阵和校正不借其他轮次替代。矩阵门槛仍为原算法的 144 阶，超过上限或缺少阶段时输出 not-recorded 和缺失说明，不能以零矩阵替代。高级分析禁止补算附录，API 和界面同时约束。静力原有显式补算仍以独立过程 ID 和补算来源标识保留，不冒充原运行。

正文按显示单位换算；新附录保持 m、rad、kN、kN·m、kg、s 的内部单位，显式列刚度／质量混合单位。行列从零开始，最多六列分块；选择已保存矩阵或校正向量时自动附带坐标及工程节点／原杆件区间映射，完整特征向量仍由单独选项控制。完整样本只在用户选择附录时加入，不无声截断。

Word 在相邻表格间加入小间距段落，避免原生排版合并表格并误用首表重复表头；普通正文段落保持行组，最后表格的必需尾段落使用小行高，避免孤立尾句及空白尾页。PDF 排版继续独立消费同源内容。

## 验证与边界

报告公开入口、Word/PDF 包装和 Electron 出口沿用 T30 已确认的测试边界。原生样本包含静力、组合、非零固定屈曲、二阶、附加点／线质量模态及超矩阵门槛且预算停止的模态；修改当前几何后实际导出历史输入。验证递归冻结、结果数值、真实过程、缺失提示、单位语义和格式同源；逐页使用原 Word 排版及产品 PDF 栅格化，检查正文／表格文本、字体嵌入、页面边界和布局。

开发 QA 复用既有只读 Word COM 和 documents render_docx.py 的 PDF 栅格化入口，不增加产品依赖。没有修改求解算法，原数值方法独立基准仍由对应任务和 T2-40 承担。真实 AI 联测、随机计算书和目标规模成本分别归 T2-41、T2-38、T2-42。
