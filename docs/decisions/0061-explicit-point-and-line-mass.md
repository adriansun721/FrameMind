# ADR-0061：显式附加点质量与线质量

- 日期：2026-10-06（Asia/Taipei）；状态：Accepted。
- 范围：PLAN2.0 T2-28；US2-060、061；AC2-17 的附加质量部分。

## 输入与边界

节点 `additionalMassKg` 是各向同性平移点质量 kg，同一个标量作用于全局 UX/UY/UZ，并非三个物理质量之和。杆件 `additionalLineMassKgM` 是沿整根参考轴均匀分布的各向同性平移线质量 kg/m。二者是独立于材料密度的显式用户输入；省略和 0 均表示无附加质量。数值须非负、有限。没有附加转动惯性、偏心、方向分量、分段或中间集中质量输入；要在杆中设点质量需先显式工程分割建立节点。工具未登记字段、对象值代替标量、失效对象和非法数值明确拒绝。

手动属性和确认后的工具调用使用同一事务：`set_node_mass {id,massKg}`；`update_member {id,changes:{additionalLineMassKgM}}`。查询节点、杆件可读取设置，`read_results mass` 分页返回冻结的结构、点与线质量来源。工具单位 `inputUnits.mass` 支持 kg/t，`inputUnits.lineMass` 支持 kg/m、kg/mm、t/m、t/mm。mm 显示预设将线质量显示为 kg/mm，存储仍为 kg/m。项目版本 2 使用可选字段兼容旧项目；保存解码校验数值，旧模态结果无附加质量记录仍可读取。

## 数值与映射

沿用 ADR-0060 原生 `/5` 求解。点质量在原工程节点的三个平移自由度对角项分别加入 `massKg/1000`；约束消元后约束方向不参与特征方程，但物理来源总量仍记录一次。点质量不复制到内部节点。

线质量加入每个计算单元的轴向线性一致质量与两个弯曲 Hermite 一致质量，使用 `(rho*A + additionalLineMassKgM)*elementLength/1000`。扭转极惯性保持为 `rho*(Iy+Iz)*elementLength/1000`，附加质量位于参考轴不产生扭转惯性。矩阵质量单位与 kN 刚度配套，仍为 kN·s²/m。端释放的独立梁端转角继续参加 Hermite 平移一致质量，不能静力凝聚抹去其惯性。[OpenSees 官方梁文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/elements/elasticBeamColumn.html) 登记线质量和一致质量入口；此处截面极惯性与附加惯性范围以本 ADR 为准。

冻结记录分别包含 `structuralMassKg`、`additionalMassKg`、`totalMassKg` 和 `additionalSources`；总量是结构质量加一次点质量与 `lineMass*engineeringLength`。来源保留工程对象 ID，解码独立核对冻结输入；有限性、质量正定、残差、正交性与预算沿用 ADR-0060。

工程分割给两个子杆相同线密度，长度分区保证总量守恒；端节点点质量保留原身份，新节点质量为 0。复制节点继承点质量、复制杆件继承线密度且不复制端点质量；删除对象移除其附着质量。节点合并预览明确列出点质量，确认后相加至目标；保留杆线密度不变，移除杆删除其线质量，杆长改变时总量随新长度改变。事务回执保存前后字段与拓扑身份，可整组撤销。

质量变化只纳入模态数值依赖，不令静力结果过期，不更改一般荷载或自重。自重仍只取结构密度；开关自重不会清空、增加或重复附加质量。后续随机工况须在引入该能力时复用模态质量依赖，本任务不宣称随机分析已实现。

## 预登记独立验证

1. 梁 L=3 m、E=200 GPa、rho*A=157 kg/m、Iz=1/60000 m⁴，结构质量 471 kg。附加线质量 157 kg/m 后总质量 942 kg；弯曲和轴向频率为原值 /sqrt(2)，扭转频率不变。独立连续体频率公式沿用 ADR-0060，误差 ≤5e-4。
2. 悬臂端点附加质量 M=471 kg，mu=M/(rho*A*L)=1。从连续梁方程与根部位移/转角为 0、端部弯矩为 0、端部剪力与惯性力平衡独立得：`1+cosh(b)*cos(b)+mu*b*(sinh(b)*cos(b)-cosh(b)*sin(b))=0`。二分求首根于 (0,1.875104068711961)，`f=b²/(2*pi*L²)*sqrt(E*Iz/(rho*A))`；频率误差 ≤5e-4。形态 `cosh(bt)-cos(bt)-sigma*(sinh(bt)-sin(bt))`，sigma=(cosh(b)+cos(b))/(sinh(b)+sin(b))，17 站绝对相关系数 ≥1-1e-6。参考脚本不调用产品质量矩阵或产品特征求解器计算参考。
3. 组合点/线质量、约束节点质量、两段工程分割、内部细分、旋转局部轴、端释放、复制删除、单位、工具确认去重、撤销和保存重开。总量相对误差 ≤1e-12；实际 K/M 残差与质量正交误差 ≤1e-8；至少两网格满足既有频率收敛条件才宣称收敛。
4. 负值、非有限值、非标量与超范围单位、失效身份、输入/来源篡改及派生总量溢出拒绝；静力输出和自重开关独立核对。保留旧结果冻结输入，不能以质量变化重写历史来源。

释放简支梁分别核查请求 6 阶与 3 阶。6 阶在现有 16 单元上限内未满足全部频率精度时明确保留预算停止记录；3 阶验证低阶连续体参考。没有放宽原误差门槛，也不以低阶通过宣称高阶充分性。
