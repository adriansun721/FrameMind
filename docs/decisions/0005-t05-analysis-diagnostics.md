# ADR-0005：T05 分析失败诊断与定位

- 日期：2026-10-01
- 状态：已接受
- 范围：PLAN.md T05；保留 T03/T04 的理论、单位、求解算法及数值阈值

## 诊断契约

公开入口 `solveFrame(projectOrSnapshot)` 在失败时抛出 `AnalysisFailure`。`stage` 区分模型检查、刚度组装、方程求解、结果恢复；`diagnostics` 包含稳定问题码、说明、可选对象身份、字段、自由度与数值证据。它仍继承 `Error`，现有文本错误调用者保持兼容。`checkAnalysisInput(projectOrSnapshot)` 可只读检查输入并一次返回模型问题，不组装或改变模型。检查在快照复制前完成；整个坐标、支座约束或荷载向量字段缺失时仍生成模型诊断，不让复制或几何检查抛出类型错误。

检查覆盖节点和杆件缺失、对象身份重复、缺失/非有限/不合适的材料截面参数、坐标与朝向、失效引用、无效几何、支座六布尔自由度、荷载六分量、孤立节点及没有有效约束的连接分量。零长度沿用几何模块的 `1e-12 m` 下限，不静默修正。

孤立节点必须连接杆件才能分析，包括完全约束的孤立节点，以避免把未参与结构的草稿节点默认为已分析。无约束的断开部分明确失败；多个各自有支座的断开结构允许进入求解。存在某个约束不代表空间结构稳定，剩余机构交由约化矩阵检查。六个约束均关闭的支座作为无效分析条件定位到该支座，用户可直接编辑修正。

## 数值失败的已知证据

沿用部分主元消元及 `max(abs(Kff)) * 1e-12` 主元阈值，不新增未经验证的条件数、特征模态或机构识别算法。主元不超过阈值时记录实际主元绝对值、阈值、矩阵尺度、原自由度列对应的节点/分量及从 0 起的全局索引。行交换不改变原变量列映射。

对应自由度只是排查线索，不声称它是唯一原因。说明列出约束不足、机构和数值病态的可能性。单元刚度/转换、整体刚度累加、荷载累加、消元主元及回代、反力和杆端恢复各自检查有限性，失败不能生成 `status: complete`。

## 验证模型与预期

基础模型沿用已登记的 T03 悬臂：L=4 m、E=200 GPa、ν=0.3、A=0.01 m²、Iy=0.0002 m⁴、Iz=0.0001 m⁴、J=0.00015 m⁴。缺失或无效参数的预期是模型检查失败并引用所属对象及字段。固定端只约束三个平移时存在刚体转动，预期方程求解阶段失败并提供主元线索；不指定唯一致因节点。

额外 N3=(8,0,0) 作为孤立节点应失败，连接 N2→N3 后可重算。另一条平行悬臂位于 y=4 m，没有支座时应定位其连接分量；补上独立固定支座后可成功。既有 T03/T04 解析/虚功参考及误差阈值保持不变。

有限输入的表示范围故障用 E=1e308 GPa 检查单元组装、同一节点两份 Fx=1e308 kN 检查荷载累加、悬臂端 Fy=1e308 kN 检查回代；端部 Fy=1e307 kN 加固定端 Mz=1.6e308 kN·m 检查反力恢复溢出。这些是浮点异常输入，不作为物理模型或性能证据。

## 工作台与持久化

计算按钮允许先检查不完整模型；没有荷载的稳定模型可得到零响应。诊断绑定失败时的修订号，随后编辑标记为待重新检查；重新运行或切换项目清理诊断。诊断定位选择统一对象并主动适合模型，材料/截面定位至属性，支座/荷载定位至其属性并高亮所属节点。普通模型编辑沿用原相机行为。

补齐支座与节点荷载属性编辑，复用公共变更入口及创建时的字段组件。创建弹窗取消恢复所选对象草稿，避免新建输入覆盖正在编辑的支座或荷载。拒绝的编辑不进入模型。

失败不修改项目、不删除 `latestAnalysis`，旧成功结果继续引用冻结输入，修改后的版本标记为过期。诊断是当前会话反馈，不加入项目格式；保存重开保留模型及此前成功分析，再计算可重新检查模型。项目解码仍拒绝结构损坏文件，不把失效文件强行载入编辑器。

执行隔离、持续响应与取消仍由 T06 验收，本任务不作此类完成声明。
