# ADR-0052：工作平面绘制与可控节点捕捉

日期：2026-10-05（Asia/Taipei）。范围：PLAN2.0 T2-19；基于 ADR-0051。

## 工作平面和坐标

建模工具栏新增“绘杆”模式。XY 固定 Z、XZ 固定 Y、YZ 固定 X；平面偏移和 XYZ 输入使用项目显示单位，草稿内部保存规范单位 m 的完整双精度字符串。固定轴由平面位置决定，不能在端点输入中独立修改。可用数值或左键设置起点和终点，鼠标移动产生虚线及端点预览；“正对平面”是可选视图操作，斜视图仍能绘制。左键用于绘制，右键平移和滚轮缩放保留；退出后恢复旋转。

鼠标射线在局部显示坐标中与无限工作平面求交，再加回世界原点；法向坐标直接设为平面偏移。射线法向分量绝对值小于 1e-10、负交点距离、非有限输入或结果均不能提交；提示旋转视图或使用数值。可见 30 m 网格仅作平面参考，既不限制坐标，也不提供自动网格吸附。不增加几何或求解容差，不引入外部库。

## 捕捉规则

捕捉默认开启，可随时关闭。鼠标捕捉使用 **12 CSS px** 的节点投影中心距离，与既有视觉拾取球／柱半径分开；只考虑处于相机裁剪深度内、固定轴规范坐标与平面偏移精确相同的节点。候选按屏幕距离、深度、稳定身份排序。同坐标候选确定性选择一个身份，不合并其他节点。数值输入只在精确 XYZ 匹配时捕捉；附近坐标不会被改写。

捕捉会直接复用已有 nodeId 和正式坐标；未捕捉端点生成新节点。关闭捕捉不撤回此前已经明确选定的起点身份，仅影响后续端点。已提交段的终点始终作为下一段的共享起点，包括捕捉关闭的情况。提交前检查被捕捉节点仍存在且坐标未改变；失败保留未提交段，让用户取消或重新选择。

屏幕捕捉范围随投影提供交互便利，模型连接始终取决于被明确选定的身份。缩放、视觉拾取、单位切换和几何交叉均不触发自动合并、分割或连接。

## 提交与恢复边界

起点、候选端点及虚线均为会话 UI 状态，不进入 FrameProject、分析冻结输入、保存文件和 agent 快照。一次终点点击或“提交当前段”通过 `prepareDrawnMemberEdits` 转为普通 create_node/create_member 操作，经 `applyProjectEdits` 整组提交：一根杆、零至两个新端点、一次修订、一次撤销。失败不留下孤立节点。

Esc／“取消当前段”清除起点与候选点，不影响已提交段；换平面、改平面位置、退出绘制、项目切换和撤销／重做也清除临时段。单位切换只转换显示，保留规范坐标和当前段。新开／重开项目从选择模式进入，恢复已提交工程对象，临时段不恢复。浏览结果退出绘制模式。

材料、截面在绘杆面板选择；沿用现有资源、有限坐标和有效杆长校验，截面转角默认 0°，提交后可通过既有属性编辑修改。

## 手动／工具契约

新增 `draw_member` 工具，端点参数为 `{position, nodeId?}`，材料／截面为稳定身份，可声明 inputUnits，转角可选且默认为 0°。该工具使用同一个 `prepareDrawnMemberEdits` 边界，返回标准基础编辑草案、预览和回执；确认前不改工程，确认后可成组撤销并回读正式身份。已有 create/update 工具继续可用。`read_geometry_contract` 返回新的捕捉规则，始终采用规范单位或明示 CSS px。

工具不模拟相机点击，不以坐标邻近猜测 nodeId，不持久化工作平面 UI。参数、确认、幂等、人工编辑协调和存储继续使用已有基础编辑协议。

## 验证

复现入口：`npm run evidence:plan2:t219`。领域测试覆盖三平面斜射线、大坐标小间距、平行／背向射线、屏幕半径和精确平面成员、数值捕捉、原子提交、连续身份、失败回滚、交叉不连通、存储、手动／工具一致和历史。组件测试验证数值预览、单位切换、错误、取消与平面切换。Electron 验证三平面、斜视图、开关捕捉、正对平面后的缩放、网格外数值、取消、撤销／重做、保存重开及 agent 读取；深浅主题 1440／1080 截图仅作为视觉证据。

真实 AI 联测和干净 Windows 安装未在本任务执行，分别由 T2-41、T2-44 承接。
