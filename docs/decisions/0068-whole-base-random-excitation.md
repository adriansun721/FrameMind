# T2-35：整体一致平动基底加速度

日期：2026-10-07（Asia/Taipei）。承接 ADR 0065—0067。

## 输入与支持矩阵

空间作用新增 `{kind:"base-translation",direction:{x,y,z},scale}`。方向为全局单位向量，scale 为有限有符号无量纲系数。没有节点／支座子集字段：全部支承共享每个源的整体运动；本轮要求每个支承约束输入方向的每个非零平移分量。多支座差动、转动基底、局部坐标、相位、互谱和部分相关均在共享校验和 C++ 中拒绝。

同一源的基底作用共享加速度过程，先相加有符号传递函数；不同身份的源相互独立，先相加响应 PSD。一个源只能是力或加速度过程，禁止同源混用不同量纲。多个基底源、基底源与节点／整杆均布力源可独立并用。不同源必须使用同一完整有效频段，预算沿用 T2-34。

输入规范单位为单边 Hz 加速度 PSD `(m/s²)²/Hz`；沿用 PSD 资源的 mm/s²、rad/s 和双边偶谱转换。不会由静力荷载或自重重复构造质量。

| 输出 | 参考系 | 本轮支持 |
| --- | --- | --- |
| 所选节点平移 PSD、方差、RMS | 全局 XYZ，相对整体平动基底；不含基底位移 | 是 |
| 所选支承节点的相对平移 | 同上；输入方向约束分量为零 | 是 |
| 绝对位移、速度、相对／绝对加速度、内力 | 未登记 | 否 |
| 纯外力工况原有节点平移 | 固定全局参考系 | 保持兼容 |

基底结果必须保存 `referenceFrame:"relative-to-base"`，解码不接受缺失或伪造参考系；纯外力历史格式不增加强制字段。界面、工具 summary / PSD 页及 RMS 引用均明确参考系。统计 RMS 不表示瞬时峰值或受载变形。

## 数值实现

相对坐标运动方程 `M ü + C u̇ + K u = F − M r a_base`。单位广义质量模态中的基底广义荷载为 `−φᵀ M r`。一致 EB 质量下，刚体平移对应每个实际单元的位移形函数精确积分；使用冻结内部特征向量，包含释放端独立转角。结构密度 × 截面面积及附加线质量均乘该积分，附加点质量乘工程节点振型。kg 转为 kN·s²/m 时除以 1000。受约束端的质量耦合保留；不能仅对删约束后的质量矩阵乘剩余全一向量。

沿用已核对阻尼、实际频点加密、梯形积分、模态截断比较和资源失败规则。另检查基底方向的振型覆盖，避免缺失方向被误判为零响应收敛。零同源运动可相干抵消。结果冻结所有作用、谱、质量、支承、模态和阻尼；编辑依赖使其过期，冻结历史仍可重开。

理论依据：[COMSOL Random Vibration Theory](https://doc.comsol.com/6.4/doc/com.comsol.help.sme/sme_ug_theory.06.055.html) 的一致基底惯性转换与模态叠加；[COMSOL Response Spectrum Analysis Theory](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_theory.06.056.html) 的相对坐标、质量归一化及参与系数。支承限制、单源量纲限制和输出范围为本轮产品决策。

独立验证采用连续 EB 悬臂解析振型和空间积分，以及点质量占优悬臂的单自由度极限；参考使用复合 Simpson 积分，登记误差阈值 0.5%，同时核查 100000 / 200000 区间积分变化小于 1e-8。有限梁质量造成的单自由度近似误差明确包含在阈值内。
