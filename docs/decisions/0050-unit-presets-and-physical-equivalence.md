# ADR-0050：单位预设与物理等价

日期：2026-10-05（Asia/Taipei）。范围：PLAN2.0 T2-17。

## 内部规范单位

继续沿用已有 v2 项目及原生静力协议：坐标、长度、位移 m；力 kN；力矩 kN·m；均布力 kN/m；弹性模量 GPa；密度 kg/m³；面积 m²；Iy、Iz、J m⁴；截面朝向 °；响应转角 rad；重力 m/s²。泊松比、组合系数、方向余弦、变形放大倍数无量纲。求解组装在原有边界把 E 转为 kN/m²；本项不改变原生数值算法、容差或刚度尺度。

`src/domain/units.ts` 是单位及换算的唯一登记点。转换按同量纲固定倍率进行，不按数值大小判断。未登记量纲、缺源单位、不兼容量纲、非有限数值、溢出和下溢到零均拒绝。

`displayUnitPreset` 是项目 v2 的可选显示偏好。旧文件缺省 m-kN，未知预设拒绝。保存、自动快照和重开沿用现有文件保护；偏好不参与分析依赖，不增加模型修订，不作为模型撤销项。模型撤销保留当前显示偏好。切换仍可成为待保存的项目偏好修改。

React 上下文统一输入框、草案卡片、资源库、结果表、查询、视图标签、比较及引用显示。草稿数值保留规范单位字符串；仅真正编辑字段时转换新输入，切换不触发 onChange。输出采用有效数字，保留非零小值，完整模型和结果不按显示精度回写。

刚度显示按 K'ij = sFi / sUj · Kij 转换；位移／力向量按每节点六分量的平移、转动位置转换。T 是无量纲方向余弦，不换算。图形坐标及相对缩放仍使用规范数值，换单位不改变结构连接或几何形状。

## 工具与外部数据

现有工具默认遵循其明确声明的规范单位契约；`inputUnits` 可按量纲覆盖为混合单位，例如 `{length: "mm", force: "N", moment: "N·mm"}`。字段名中的 M2/GPa 仍表示内部存储字段；覆盖只作用于本次输入，不修改契约。建议、假设及用户值都通过相同转换，保留来源标签与确认机制。未声明的其他量纲使用工具契约的规范单位。

`read_unit_contract` 提供全部契约；`convert_quantity` 必须明确 value、dimension、fromUnit、toUnit。外部数据没有单位且不具备已声明工具契约时，Agent 必须向用户澄清。项目文件必须包含规范单位字段，缺失／不匹配继续拒绝。

读取数据按所选显示偏好或显式 `outputUnitPreset` 输出，同时提供 quantityUnits、storageContract。数值筛选在规范化后执行；返回筛选范围也显示为所选单位。确认草案、引用 token 对应的数值以及定位坐标继续保存规范单位，显示时再转换，避免历史文本或显示偏好改变引用含义。理论、求解器、服务、来源说明、过程原始快照保留其明确的原单位。

## 报告与后续动态量纲

报告独立冻结显示偏好，同时冻结所选分析输入与输出。正文、图表、Word 图像预生成、后台打包及 PDF 复用同一偏好；导出过程不能因用户随后切换而混用单位。附录混合向量和刚度矩阵按行列量纲转换，原始结果不改写。

新增量纲已登记接入规则：质量 kg（可换 t）；频率 Hz 为周频率，rad/s = 2π Hz；PSD 是单边、按 Hz 的谱密度，位移 m²/Hz、加速度 (m/s²)²/Hz、力 kN²/Hz。幅值换算因子需平方，不能只改变单位标签。PSD 的频率变量 Jacobian、单双边谱、RMS 积分约定及实际输入／输出验证由 T2-27—T2-38 完成，本项不开放动态计算，也不把 Hz↔rad/s 的横轴换算当成谱密度换算。

## 精度和验收

IEEE-754 双精度倍率转换允许浮点末位误差；独立基准按相对误差 ≤4ε 检查长度往返，不以显示舍入代替物理等价验证。重复显示切换与保存重开要求模型和冻结结果完全一致。静力 FL/EA 基准、显式混合工具输入、非法单位拒绝、大坐标、小间距和近零数值分别覆盖；原生桌面流程验证手动 N 输入、历史保留、保存重开和 Word/PDF。
