# ADR-0006：T06 分析任务隔离、状态与取消

- 日期：2026-10-01
- 状态：已接受
- 范围：PLAN.md T06；沿用 T03/T04 的分析输入、求解器和结果契约

## 执行边界

渲染进程通过 `startAnalysisTask` 将冻结的 `AnalysisInputSnapshot` 复制到独立的模块 Worker。Worker 内调用公开的 `solveFrame`，不共享 React 状态，也不把稠密矩阵或中间结果发送回界面。`solveFrame` 在模型检查、刚度组装、方程求解和结果恢复的真实边界调用阶段回调，Worker 和回退路径转发这些可证明阶段；不显示百分比或虚假剩余时间。没有 Worker 的测试或受限运行时使用同一异步接口的回退路径，保持错误和取消契约一致。

## 任务状态与取消

界面只允许一个活动分析任务。启动后显示中性状态和阶段文字，计算按钮变为“取消计算”。完成状态只在结果通过当前项目身份、会话和精确修订检查后附加到模型；失败恢复 `AnalysisFailure` 的阶段和诊断；取消终止 Worker、拒绝任务 Promise，并保留当前模型和此前有效结果。取消、失败和过期响应都不能创建 `status: complete` 的部分结果。

## 竞态规则

任务捕获项目身份、修订号和会话号。编辑模型会使精确修订检查失败，创建或打开项目会递增会话并终止活动任务；迟到的阶段、成功或错误消息均不能覆盖新项目、新修订或新任务的界面状态。任务编号还防止旧任务的 `finally` 清理新任务的忙碌状态。模型查看、选择和三维相机操作不依赖求解 Promise，因此在 Worker 计算期间继续响应。

## 边界

Worker 终止只保证本任务的输出不会提交；操作系统已经开始执行的线程不会被强行中断。回退路径在没有 Worker 的环境下用于测试和受限运行时，生产 Electron 构建使用独立 Worker。稠密求解器的规模上限和性能指标由 T32 测量，不在 T06 虚构承诺。
