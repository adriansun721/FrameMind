# ADR-0076：P25-05 CAD 资源核验边界与在线失败状态

- 状态：已接受
- 日期：2026-10-09
- 范围：P25-05 截面、材料、刚接假设与只读 AI 核验

## 决策

1. 矩形端截面使用 `planar-polygon-v1` 计算 A、Iy、Iz，并使用 SCI P385 记载的矩形 Saint-Venant 近似计算 J；J 永远不由 `Iy + Iz` 替代。
2. 非矩形、空洞、曲线或端截面不一致的几何保持阻塞，除非用户提供全部 A/Iy/Iz/J、独立参考并明确确认。该人工值保存为 correction，包含原始值、替换值、参考和记录时间。
3. 资源归组同时比较归一化截面顶点和四个截面属性，并使用已登记的几何容差；实例来源实体可以一对多映射，不因共享零件定义被错误拆开。
4. 本地检查先于 AI，包括 schema、有限值、零长度、重复中心线/拓扑 ID、节点引用、截面完整性、材料参数、拓扑阻塞项和刚接确认。
5. AI 只读取脱敏结构化证据。在线请求有明确超时、取消、网络失败和 JSON 格式错误状态；任何失败、未完成、拒绝或程序阻塞都不能产生 accepted 回执。

## 影响

复杂截面的 J 不会被未经验证的通用公式冒充为精确值。后续若引入独立验证的复杂截面算法，必须新增方法标识、参考值和收敛证据，不得改变现有矩形或人工补齐记录的含义。

## 验证

`src/workspace/cad-resources.test.ts` 覆盖矩形 J、复杂截面阻塞、人工修正历史、重复拓扑、证据引用、在线格式错误和超时；`npm run typecheck` 与该单元测试作为 P25-05 的本地复验入口。
