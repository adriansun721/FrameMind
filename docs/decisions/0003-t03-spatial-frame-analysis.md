# ADR-0003：T03 三维悬臂端荷载计算

- 状态：已接受
- 日期：2026-10-01
- 适用范围：T03 单杆空间刚架静力分析

## 决策

首版采用三维 Euler-Bernoulli 刚接梁柱单元。每个节点按 `[ux, uy, uz, rx, ry, rz]` 排列六个自由度；杆件局部 `x` 轴沿起点指向终点，局部 `y/z` 轴复用 T02 的局部轴构造并按截面转角旋转。材料弹性模量由 GPa 转为 `10^6 kN/m²`，剪切模量按 `G = E / (2(1+ν))` 计算。

教材核查使用项目中的《计算结构力学》（阎军、杨春秋，科学出版社，2014）扫描版：第 2 章第 2.1 节（印刷页 29）给出 `[K]{U}={F}` 的刚度方程；第 2.2.1—2.2.2 节（印刷页 30—31）定义杆端局部坐标、全局节点荷载顺序 `{Fx,Fy,Fz,mx,my,mz}` 和正号方向；第 2.3 节（印刷页 31—32）给出局部/整体转换矩阵；第 2.4 节（印刷页 34）给出 `EA/l`、`12EI/l³`、`6EI/l²`、`4EI/l` 和 `2EI/l` 的单元刚度项。PDF 为图像扫描，页码通过渲染页脚核对；实现中的 12 自由度顺序和局部端力符号与这些定义一致。

局部刚度使用轴向、扭转及两个平面弯曲项，忽略剪切变形、杆端释放、非线性和自重。局部刚度通过 12×12 正交变换组装到整体矩阵；支座直接约束节点自由度，节点荷载按全局方向施加。线性方程使用带部分主元的高斯消元，主元不足时报告结构约束不足或矩阵奇异。

## 符号与验证

位移单位为 m、转角为 rad、反力为 kN、反力矩和杆端内力矩为 kN·m。局部杆端力按教材 `{s}` 的起点到终点顺序记录，固定端反力使用整体平衡的外力相反号。结果保存本次项目修订号、完整模型输入快照、自由度顺序、局部轴和理论假设；模型修改后旧结果仍可追溯但标记为过期。

基准为一根 4 m 水平悬臂，固定端六自由度约束，自由端同时施加轴力、两个横向力、扭矩和两个弯矩。自由端位移与转角分别按 `PL/EA`、`PL³/(3EI)`、`PL²/(2EI)` 和 `TL/GJ` 解析式核对；固定端反力与反力矩按整体平衡核对，起点和终点六分量杆端内力也逐项核对。非零参考值使用 `|actual-reference| <= max(1e-9, 1e-8*|reference|)`，近零量使用 `1e-9` 绝对阈值；测试中的参考值独立于求解器实现。

## 持久化与任务边界

支座和节点集中荷载使用稳定 ID 写入项目文件。分析在应用层通过异步任务边界运行，提交结果前检查项目身份与修订号；若期间切换项目或修改模型，迟到结果被丢弃。分析结果附加到项目形成新的项目修订，保存和重开保留输入及结果来源。
