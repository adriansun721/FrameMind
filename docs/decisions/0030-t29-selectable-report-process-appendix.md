# T29 可选择的真实过程附录

本决策覆盖 PLAN.md T29、US-053、US-055、AC-11 和 AC-18 的过程附录部分，依赖 T17、T18 与 T28 的既有过程记录和报告来源。产品 PDF 导出仍属于 T30。

## 选择与来源

工程计算书默认只输出完整正文。用户可以分别勾选杆件过程、整体自由度映射、所选杆件组装贡献、整体约束与荷载向量、完整 K、完整 Kff。杆件过程与组装贡献使用所选分析冻结输入内的稳定杆件 ID；整体步骤明确使用全部模型。没有选择杆件时保留选择说明与缺失提示，不能把全部杆件当作默认选择。切换分析清空步骤、对象与补算记录。

`captureEngineeringReport(project, analysisId, selection)` 在异步生成图片、加载 Word 模块之前复制分析、对象选择和步骤，并递归冻结过程记录。正文和附录使用同一分析 ID、修订、工况或组合、单位和原始输入。历史对象标签及数值不读取当前编辑模型。沿用正文的完整结果解码与几何核对，额外验证整体记录的节点编号、杆件对号、约束与自由索引和求解配置是否对应冻结输入；不对应的过程显示缺少记录，不污染正文。

## 缺失与补算

杆件过程沿用 T17 的 `getMemberAnalysisRecord`，能够从受支持的冻结求解输入重建时，明确标记“冻结输入重建”，不冒充运行时采集。整体过程仅读取该分析已有快照；缺少快照时明确提示未采集，不调用 T18 的隐式整体重建。超过既有 72 阶采集上限的矩阵输出缺失说明，不拼凑矩阵。

缺少可补算记录时提供显式“基于冻结输入补算过程”。复用独立 Worker 和取消入口，以当前求解器处理原报告的冻结输入，不处理当前模型。补算结果必须通过完整解码并对应原始输入（仅允许求解配置不同），且拥有新的分析 ID。附录标记“补算重建”、原分析 ID、补算分析 ID 及求解配置。正文仍使用原始分析响应；补算不覆盖历史结果、不进入正式分析历史，只保留在本次报告对话框。取消、关闭和切换来源不会接纳迟到结果。

## Word 布局与依据

附录从新页开始，标题、公式、向量与矩阵均为原生可编辑 Word 内容。正文与附录共用段落、表格及表题排版规则，表头跨页重复、行不拆分。矩阵按最多六个数值列分块，保留所有行与真实行列索引；单元矩阵使用单元位置，组装贡献使用整体索引，Kff 使用对应的自由整体索引。完整 K 和 Kff 必须分别勾选，组装贡献明确不是完整 K。

单位与自由度顺序随数据说明：ux、uy、uz 为 m，rx、ry、rz 为 rad；力和力矩为 kN 与 kN·m，刚度按平移或转动行列解释混合单位。附录引用既有 `ANALYSIS_PROCESS_BASIS`，同时列教材印刷页、PDF 页序、公式以及坐标转换方向和约束消元的实现约定，不生成新的规范结论。

验证与三份样本见 [T29 验收记录](../evidence/T29-validation.md)。正式应用导出继续使用本地 docx，不依赖 Microsoft Word；开发阶段的 Word 只读分页检查不增加产品运行依赖。
