# ADR-0080：反向设计固定输入与受控截面候选

日期：2026-10-10（Asia/Taipei）

P25-09 交付固定两层钢架的输入确认与隔离候选生成。几何、材料、刚接、底层支座、重力、外荷载、组合、截面转角、杆件数量和 15 mm 水平合位移限值均依 PRD2.5 第 7 节冻结。梁、柱各一组，只接收现有 T2-23 已核验库的条目编号：IPE100、IPE200、HEA200。全部组合最多 9 种；当前入口允许用户明确选择一个不同于父快照的组合，不宣称自动搜索、遍历或全局最优。

主进程以 `reverse-design-fixture.ts` 的归档场景与截面行作为权威。该文件通过 `npm run fixture:plan2:p2509` 从现有领域接口与资源库生成，保留目录 A/Iy/Iz/J、圆角、参考几何、表格位置和核对日期。静态归档让 Electron 主进程无需引用求解/UI 模块或读取运行时外部文件；目录更新时须明确重建、审查和复验，不能让已有候选自动跟随新目录变化。

空项目先预览；确认后记录 `confirmation-before/after`，保存目标、限制、预算、库来源和质量证据。非空项目只有工程输入与冻结场景完全匹配时才能重新确认；不自动替换其他模型。项目、修订、历史、会话或恢复变化使确认失效。主进程的发布前/发布后守卫与 Git 比较更新防止旧窗口覆盖新状态，UI 应用前再校验父快照。恢复、重开必须重新确认。

生成接口只允许确认身份、梁库编号、柱库编号，不接收候选模型、命令、路径或自定义门槛。候选经 P25-08 在 `candidate/task_<uuid>` 分支保存，任务携带 `reverse-design-v1` 输入策略；通用 submit 和 retry 也必须保留策略并核对全部工程输入。正式模型和 `.framemind` 文件在候选生成时保留父截面。候选轮 checkpoint 可以推进项目 main 的父快照索引，候选截面只进入隔离分支；应用源码仓库不受工具操作。

每根杆件的质量按冻结输入 `ρ A L` 计算。柱总长度 24 m，梁总长度 40 m；初始质量 `7850 × (24 × 0.00538 + 40 × 0.00285) = 1908.492 kg`。梁改为 IPE100 时为 `1337.012 kg`。自重保持原重力规则，每米力为 `ρ A g / 1000` kN/m；不将生成的自重再作为额外均布荷载写入项目，以免求解时重复计入。

生成证据记录父/候选身份与提交、规范化输入 SHA-256、候选内容哈希、目录哈希、前后截面、来源、质量和逐杆自重。报告状态为 `blocked`，实际位移尚未求解。P25-10 负责真实 main/work/inspect 编排，P25-11 负责本地求解与数值门槛，P25-12 负责预算执行和搜索停止。P25-09 不接受生成报告为可行性信号，现有合并门禁继续拒绝未经 inspect 的候选。

验证边界已由用户确认：公开候选接口和桌面入口。单元/真实 Git 测试覆盖固定模型、独立质量参考、禁止修改固定字段、确认与恢复、分支隔离、策略重试和拒绝合并；Electron 端到端证据覆盖菜单预览、确认、库内候选、保存和重开。离线复验运行 `node scripts/verify-p25-09.mjs`，新的完整运行使用 `npm run evidence:plan2:p2509`。
