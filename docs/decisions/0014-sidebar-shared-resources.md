# 左侧模块与共用资源库

本次是 T14 开发前的 UI 调整，范围来自已确认的界面讨论。

- 选中左侧模块时移除最左白色竖线，保留选中背景、图标颜色、悬停和键盘焦点样式。
- 最左模块栏按项目、搜索、资源库排列；搜索仅提供占位界面。
- 资源库分材料、截面，复用 T13 已核对的常用目录与来源信息。
- 自定义材料、截面可新增、编辑和删除，使用现有工程参数校验。
- 所有项目共用同一本地资源库，自定义数据通过应用源的 localStorage 保存，带版本号，切换项目或重启应用后保留。资源库不写入单个项目文件，也不跨设备同步。
- 加入当前项目时复制参数；内置条目同时复制来源。库的编辑、删除不改变已导入的项目实例，导入可通过原有项目撤销操作撤回。
- 切换左侧模块保留项目属性草稿和资源库编辑草稿；点击当前模块可收起，顶部左侧面板按钮可恢复当前模块。
- 本地数据读取失败时提示错误并禁止覆盖；保存失败时保留内存中原有条目。
