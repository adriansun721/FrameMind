# ADR-0012：T12 用户自定义荷载组合

## 定义与来源

项目保存 `loadCombinations`、可选的 `activeLoadCombinationId` 和 `nextLoadCombinationNumber`。组合由稳定 ID（CB1、CB2 等）、用户名称、工况 ID 与有限无量纲系数组成。至少一个工况，禁止重复工况；零、负系数和全零组合有效。名称与系数可修改，删除后的编号不复用。缺少新增字段的 v1 文件迁移为空组合列表，已有工况与结果保留。

沿用 T03/T11 的 Euler–Bernoulli 小变形线弹性空间刚架、刚接、m/kN/kN·m 单位与六自由度约定。组合没有规范类别、自动系数或合规结论，界面持续标记“用户定义”。

## 计算方案

选择组合后，`captureAnalysisInput(project)` 捕获一次公共结构，并保存每个工况的原始节点力/矩、均布力、工况元数据和自重设置。原始工况只保存荷载，整个组合只有一份节点、杆件、材料截面、朝向、约束、单位、求解配置与模型版本，表达上不能引入第二套结构基础。

按系数缩放节点力/矩及均布力，保留局部或全局坐标定义；按系数加权重力向量，在共享密度/截面上恢复自重。有效荷载经过已有空间刚架求解器，位移、反力、杆端及沿杆六分量均由同一有效输入恢复。内部有效荷载使用首个工况 ID 作为单工况求解容器，并重新编号避免身份碰撞；外部结果身份与显示来源始终使用 CB ID 和冻结组合定义。

这是线弹性范围内 `K u = Σ γᵢ fᵢ` 的一次求解。与叠加历史工况结果相比，它不依赖用户先计算所有工况，也不会混合历史结构版本；与逐工况重算后加权相比，避免重复求解同一刚度矩阵。没有更换已验证的单元公式或数值求解器，继续使用 `framemind-frame/3`。

求解和文件打开都校验工况、有限系数、原始荷载归属与完整性；组合快照不得在工况来源中携带另一套结构字段。文件解码重建有效荷载并检查与冻结荷载一致，不接受系数和数值输入相矛盾的结果。加权溢出明确失败。

## 编辑、持久化与界面

每个 LC 或 CB 分别保存一份最近成功结果，使用独立来源 ID 避免组合覆盖工况结果；失败保留已有成功结果。组合结果有效性比较完整冻结结构、组合定义和各工况原始荷载，忽略项目修订号。任一引用工况或公共结构变化使相应组合过期；无关工况编辑不使组合过期。

切换 LC/CB 同步结果表、沿杆查询、三维荷载箭头与来源标记，清除旧选择/诊断并取消任务，运行编号阻止迟到消息应用。组合模式隐藏工况专用荷载树，列出系数与可定位工况；荷载编辑回到明确工况后进行。组合结果面板始终显示冻结工况名称、系数及模型版本。

组合编辑、删除和工况引用清理沿用会话内成组撤销重做。删除工况前列出荷载、结果与受影响组合，确认后一并删除当前依赖组合及其结果；即使某组合定义已改，仍引用被删工况的历史组合结果也要清理。文件不得留下孤立工况/组合引用。

## 验证

公开分析入口的独立悬臂解析基准与误差规则事先登记在 [T12 验证记录](../evidence/T12-validation.md)。真实 Electron 覆盖编辑、两个组合计算/切换、保存重开、失效和撤销、引用删除、迟到结果隔离，以及两种窗口尺寸的截图、文字尺寸和画布像素检查。
