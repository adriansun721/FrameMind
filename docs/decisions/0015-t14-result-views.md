# T14 结果视图与联动

本决策覆盖 PLAN.md T14、US-041 至 US-045 和 AC-09。

## 结果来源

结果视图只接受当前选定工况或组合返回的 `AnalysisResult`。节点、杆端内力、沿杆采样、变形线和内力图均从同一个冻结输入恢复；视图不会从当前编辑模型重新计算或插值旧结果。来源工况/组合、模型版本、理论、单位和当前/过期状态在结果面板中持续可见。

## 沿杆恢复

`getMemberResponseSamples` 在沿杆均匀站点调用既有 `getMemberSectionForces`，并用三维 Euler-Bernoulli 杆的 Hermite 三次场恢复局部横向位移，轴向位移线性恢复，再按冻结局部轴转换到全局坐标。查询和图形共享同一站点公式；不使用端点连线代替均布荷载下的分布结果。

## 图形约定

- 变形图以实际全局位移乘以面板中的明确放大比例显示，默认 `100x`，原模型坐标仍保留在同一视图中。
- 内力图可切换 `N、Vy、Vz、T、My、Mz`，沿杆值来自正局部 x 面截面作用；每次只显示所选分量，单位和当前极值显示在图例中。
- 所有分量的极值低于 `1e-9` 时显示“近零”，不通过自动缩放制造异常视觉放大。
- 结果表行、沿杆查询的“定位”按钮与三维定位标记使用稳定杆件/节点 ID；切换工况或组合后由同一活动结果接口刷新。

## 边界

兼容的历史求解结果可以继续在结果表中查看；不支持沿杆恢复版本的历史结果不会伪造图形数据。图形层只保存 Three.js 显示对象，不改变项目文件格式或分析结果持久化结构。
