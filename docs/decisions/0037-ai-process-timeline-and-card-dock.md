# ADR-0037：处理时间线与输入框上方的参数卡片

- 日期：2026-10-03
- 状态：已接受
- 来源：本次用户对话中的输出与界面要求

发送消息后立即显示“思考中”，圆点呼吸和省略号提供交互反馈。开始回复后展示已验证的正文；任务处理过程竖向排列，以真实请求、工具调用、本地求解和卡片确认结果为依据，不预设或编造步骤。读取不同模型集合时分别显示节点、杆件、支座、荷载、材料、截面或工况检查。暂停停止动效，取消或失败结束活动节点；系统减少动态效果的偏好关闭动画。

用户消息与正式回复在深色主题中使用白色，在浅色主题中使用黑色。处理过程和辅助状态使用灰色，节点通过图标区分活动、完成、等待、问题及取消。正常完成后处理过程支持收起。根据后续界面要求，删除回复下方的“查看详情”入口及上下文、请求恢复记录和工具输入输出的详情展示；任务记录仍保留在会话状态中，供处理时间线和重试使用。

建模、分析条件和截面修改卡片集中放在底部消息输入框上方，位于消息滚动区域之外。卡片使用普通表面和中性边框，移除参数变化的背景动画以及 AI 草案的彩色三维叠加预览。独立编辑和详情侧栏沿用既有行为；未保存或不完整的编辑仍阻止确认。

填写并明确确认提交成功后，卡片消失，对应等待节点变为完成，已确认参数可从该节点展开。确认失败保留卡片。确认、本地计算和后续自动对话归入同一条处理时间线，不显示系统续接提示为用户消息。只有原请求已经包含计算意图时才自动准备后续条件或计算，不新增计算授权。已完成节点和确认参数随当前应用会话的历史保留。

文字修改同一卡片时，旧版本节点标记为“已更新”，只保留当前版本的等待节点。确认以实际生成卡片的任务为归属来源；无关聊天不会改变确认或后续计算的归属，旧计算的显式重试也归入原任务。分析条件节点保存确认时的可读参数，包括具体对象、约束、力与力矩、均布荷载、工况、组合系数、自重和计算来源。

后续视觉调整：移除步骤之间的连接线和完成标记的外圈，完成状态改为圆润的手写曲线对号，等待和活动状态使用小实心点。处理过程及详情的展开箭头放在文字左侧，收起时朝左、展开时朝下；灰色过程文字与原有状态动效保持一致。

验证采用现有任务层和卡片测试，以及 Electron 固定 HTTP 回放；覆盖立即思考、暂停继续、灰色过程与黑白正文、减少动效、窄面板布局、卡片编辑确认、阶段续接、缺参、拒绝和网络失败。测试不调用真实模型服务。

验证结果：类型检查和生产构建通过；全部 40 个单元测试文件的 284 项测试通过，相关 Electron 回归 32 项通过。已人工检查深浅主题、窄面板卡片停靠和确认后参数展开截图。代码规范与需求符合性两项审查发现的问题均已修正并复查关闭。
