# ADR-0054：近重合检查与成组节点合并

日期：2026-10-05（Asia/Taipei）。范围：PLAN2.0 T2-21；沿用 ADR-0051—0053 的工程单位、显式身份和事务边界。

## 容差与目标

近重合采用规范 m 的欧氏距离，默认 1e-6 m，用户可显式设置非负有限长度；0 只查精确重复。显示单位转换和相机缩放不进入判据，不使用相对坐标尺度门槛。仍受现有 IEEE double 输入精度约束，大坐标平移后的值按实际存储坐标检查，不承诺恢复浮点表示已经丢失的位数。

检查返回成对节点身份、距离、单位与工程修订，不改变模型。选定 2—100 个不同节点及其中一个目标节点后，每个源节点到目标的距离都须在容差内；不把近重合链的连通分量自动合并。目标保留原身份和精确坐标，源节点删除；合并以后的连接仍由节点身份决定。

## 冲突决策

`inspect_node_merge` 与手动界面共用 `inspectNodeMerge`，给出节点距离、原／新端点、材料／截面／转角、杆长和局部朝向、支座及六自由度、节点力和力矩及工况、杆件均布荷载及坐标系、重复杆组、零长杆和已保存任务引用。

`merge_nodes` 提案必须提供完整 resolution：`keepSupportIds`、`keepNodalLoadIds`、`keepMemberIds`、`removeUniformLoadIds`、`acceptGeometryChange=true`。界面中的冲突选项初始为空，不能用默认值代替工程选择。

- 支座明确选一个保留或全部移除。当前不提供自动合并约束；若需要新的六自由度组合，先使用既有支座编辑能力准备明确条件。
- 节点荷载逐条明确保留或移除；保留身份、工况、全局力和力矩分量。多个保留荷载表示用户明确选择叠加，记录不合并，工况不跨界累计。
- 零长杆必须移除。重复端点的杆件可以明确删除、保留一个或保留多个作为并联构件；不同属性和反向端点均在预览中可核查。非冲突杆件保留。
- 删除杆件的每条均布荷载必须单独登记移除，不能自动复制到保留杆件；保留杆件的荷载身份、工况、坐标系和强度保留，局部方向按合并后端点计算。
- 坐标移动可改变杆长、局部朝向、均布荷载合力与自重，用户必须明确接受。未登记节点／杆端／支座／荷载字段阻止提交，未来附加质量、端释放等由引入任务登记规则。

## 确认、保存和任务

手动入口、单独工具和 `propose_model_edits.operations` 共用 `applyProjectEdits`、`ModelEditConfirmation` 和对象差异回执；不增加工具专用写入口。预览和确认均完整验证，任何一步失败保留原工程；成组提交一次修订，现有历史记录一次撤销恢复拓扑、条件和计数器。

回执 `nodeMerges` 保留目标身份、移除节点、所有冲突选择和影响；readback 读取正式变化对象。已确认回执持久幂等，保存重开或撤销后的旧重试不会重新应用。待确认草案重开按操作重建预览，仍须用户确认。

任务引用属于动态元数据：保存草案本身可能新增引用，确认比较忽略 `taskReferences`，实际应用回执重新记录最新引用。工程输入、预览冲突选项和对象变更继续逐项比较。相关人工编辑（包括受影响杆件两端坐标、所引用材料与截面）和关联对象增加触发冲突；无关新增节点与未使用资源编辑允许新版本重建预览。任务原引用保持原含义，已删除目标通过既有目标检查要求重读，不静默改绑。

历史结果与进行中分析继续使用冻结输入，合并不重写其身份；当前结果按既有输入依赖过期。无新库、数值方法、项目格式版本或自动修复通路。
