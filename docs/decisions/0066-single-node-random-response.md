# ADR-0066：单节点随机外力响应

日期：2026-10-06（Asia/Taipei）；范围：T2-33；实现前登记。

使用已核对身份、质量、细分收敛和阻尼的模态结果。一个节点、一个全局 XYZ 单位方向、一个无量纲有符号空间系数，绑定力自谱（规范单边 Hz、kN²/Hz）。输出仅为指定节点 x/y/z 平移分量，m²/Hz 与 m RMS。随机均值为零；RMS 是统计量，不是瞬时峰值、确定性位移或可显示的变形形态。不同模态共享同一输入，复传递函数先相加，再取模平方，保留模态间相干项。

单位广义质量下 H(f)=Σ φ_response φ_force scale / (ω_r²−ω²+i 2 ζ_r ω_r ω)，S_response=|H|² S_force。质量单位 kN·s²/m，与规范力一致。冻结整个模态结果、阻尼身份/逐阶来源、输入谱及随机设置；重算模态、修改阻尼/谱/结构/质量/约束均使结果过期，无关静力荷载不影响随机结果。

分析频段必须完整等于输入谱有效频段，禁止以截取频段得到的 RMS 宣称完整输入结果。频段外为零的有限带输入是用户模型，不推断物理宽带尾部。模态最高频率覆盖上限仅为筛查，不能替代响应收敛。模态检查在同一冻结基础、阻尼、谱、输出和积分网格上比较最高两组阶数（全阶及减去登记增阶数）；检查 PSD 最大绝对变化相对于曲线最大值以及 RMS 相对/绝对变化。完整方程基底另行标明，无截断时允许单自由度参考。

频点初始均匀网格加入谱折点、固有频率和阻尼半带宽附近 ±1/2/4/8 倍位置。逐次二分全部区间，比较实际中点与端点线性插值，PSD 最大误差按曲线最大值归一化；这是独立于积分误差的曲线检查。每轮梯形积分，比较相邻网格的均方值与 RMS。至少两轮，频点数与加密轮数均设显式预算；超过预算、数值溢出/下溢、零能模态、模态细分未收敛、阻尼未核对或响应模态截断不满足目标，明确失败，不发布末轮为成功。

误差默认建议为 0.005 相对、PSD 1e-18 m²/Hz、均方值 1e-18 m²、RMS 1e-12 m；全部可编辑并冻结。最大 50 模态、20001 频点、12 轮，沿用原生 120 s、512 MiB、16/64 MiB 传输限制。收敛是登记比较的数值证据，不能保证未提取模态的所有贡献为零。

独立验证采用弯曲悬臂的连续解析频响及主导单自由度振子参考（M=ρAL/4、K=Mω₁²），独立 Simpson 积分核查 RMS；分别改变阻尼、逐阶覆盖、空间系数、模态数、频点/积分预算，包含窄峰、反共振、零输入/受约束输出、无效频段、保存篡改和过期依赖。初始登记的轴向杆参考未执行，不作为通过证据；实际采用的参考、频段和误差限见 numerics.json。
