# ADR-0059：内部计算细分、工程映射与静力加密检查

- 日期：2026-10-06（Asia/Taipei）；状态：Accepted
- 范围：PLAN2.0 T2-26；US2-052—054；AC2-15、20、22 的本任务子集。

## 方法与冻结身份

正式静力使用 `framemind-native/4`。每杆等长细分为 1、2、4…，默认最多 8，允许最高 16。所有候选节点／单元 ID、工程杆 ID 和沿杆位置在请求发送前冻结。内部 ID 使用独立 `__mesh_` 命名空间，解码只允许在校验继承的计算运行内出现；项目建模拓扑、树、选择、节点结果与杆件结果保留工程对象。

C++ 内部运行复用 `/3` 的局部轴、Euler-Bernoulli 刚度、一致节点荷载、释放凝聚、稀疏 LDLT、残差检查与均布荷载特解。材料截面和转角继承；节点集中荷载留在工程节点，均布荷载按相同坐标系和强度施于每段，自重按每段密度和截面计入一次；组合分项与有效荷载同时映射。释放仅作用于原工程两端，内部连接刚接。未来质量与几何刚度须复用相同映射，此任务尚未实现这些分析。

每轮保留实际输入、完整单元恢复、组装贡献、自由度分区和受 72 阶采集上限约束的整体矩阵。工程端力取首段起端／末段终端；任意位置响应在对应段内用冻结荷载和实际端位移恢复，不能插值工程端力或伪造整体工程矩阵。工程杆件过程中的 12×12 系数明确标为冻结输入重建，实际组装见内部计算过程；释放后的工程梁端恢复也是重建记录，不标记为原生采集。

## 精度与预算（验证前登记）

工程杆件完整局部轴组冻结于 `meshPlan.frames`，每个内部单元继承同一组轴，不从舍入后的端点重新选择参考轴。原生独立校验冻结轴组，内部输入记录 `calculationFrames`；该字段仅能在受校验的内部运行解码。TS 与 C++ 统一使用 `abs(localX.z) < 0.9 - 1e-12` 选择 global-z，其余选择 global-y，边界带避免不同归一化实现的浮点舍入改变参考轴。补充起点偏移 1／10／100／1000、临界值两侧、非等惯性截面与局部均布荷载参考；各轮轴组及工程荷载合量须一致。

加密误差对每一分量计算 `abs(new-old)/(absolute + relative*max(abs(new),abs(old)))`，每类记录最大值。比较工程节点平移／转角、反力／反力矩、每杆 17 个固定站点的平移及六分量截面内力。相对阈值默认 1e-6，位移／转角绝对阈值 1e-12 m／rad，力／弯矩绝对阈值 1e-8 kN／kN·m。所有指标 ≤ 1，且至少两个网格，才标记 `converged`。不采用比较值整体范数掩盖小分量。

默认方程预算 12000，每轮组装前以计算自由度减去唯一支座约束数保守检查，完全脱开转动的参考消元尚未扣除；实际方程数另记录。超出后保留已完成网格，标记 `budget-exhausted` 与原因；初始网格也无法运行则结构化失败。1 个网格、到达最大细分数、或方程预算阻止下一轮时不得伪报收敛。预算可在分析工况保存；更改后旧结果过期。继承现有 120 秒、512 MiB 内存、16 MiB 输入、64 MiB 输出与进程取消限制；资源失败不发布部分结果。

此处的收敛只证明所登记响应的静力加密稳定，不是连续极值保证，也不证明模态、屈曲或二阶精度。常截面均布力直梁采用精确特解，单段与多段响应理论相同；这不会被伪装为“误差随网格单调下降”。

## 独立参考与验收口径

理论依据：[TU Delft Euler-Bernoulli 教材](https://teachbooks.tudelft.nl/computational-modelling/structural_linear/euler_bernouilli.html) 给出梁平衡、Hermite 插值和一致荷载；[OpenSees elasticBeamColumn](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/elements/elasticBeamColumn.html) 给出两弯曲方向及原端部释放语义。两者支持方法边界，不替代数值证据。

沿用 ADR-0058 的独立解析梁和框架参考：L=4 m、E=200 GPa、qz=-2 kN/m。刚／刚端反力各 4、端矩绝对 8/3；刚／铰端反力 5／3、端矩 4／0；双铰端反力各 4、跨中挠度 `-5qL^4/(384EI)`。两方向覆盖 16 种释放组合；补充斜向局部轴、框架、轴向荷载、自重和正负组合。力／弯矩误差 `max(1e-8,abs(reference)*1e-9)`；位移／转角 `max(1e-12,abs(reference)*1e-9)`。核查荷载合量、反力平衡、内部接口、静力残差与工程拓扑不变。

专项固定预算：本机 Windows x64，每个小型参考案例 ≤ 30 秒；原生内存使用继承 512 MiB 进程限制。记录实际耗时和网格规模；不宣称 T2-42 目标规模性能、真实 AI 联测或干净 Windows 安装验收完成。
