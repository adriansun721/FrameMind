# ADR-0035：T34 Windows 候选安装交付与离线回归

日期：2026-10-03。状态：采用；干净 Windows 环境及 T33 真人首次使用未验收。

## 交付与运行边界

采用 electron-builder 26.17.0 的 NSIS 离线完整安装器，Windows x64、当前用户安装，可选择目录，不要求管理员提权、不自动启动。随包分发 Electron 44.5.1、Chromium、Node 运行时、前端资源、求解/报告 Worker、主进程 PDF 依赖与交付资料。最终用户无需 Node.js/npm、Python、Word 或 LaTeX。Vite、Electron 和打包器属于开发依赖；生产 Electron 不读取 VITE_DEV_SERVER_URL。

相比 portable zip，NSIS 提供实际安装/卸载及开始菜单入口；不采用依赖联网下载运行时的 nsis-web。安装器不注册文件关联，用户通过应用打开项目。卸载不移除用户数据或外部项目；凭据可在应用设置移除。未提供代码签名证书，此候选包不声明可信签名发布者身份。

配置依据为 electron-builder 官方 [NSIS 文档](https://www.electron.build/v26/docs/nsis/) 和 [Windows 文档](https://www.electron.build/v26/docs/win/)。构建锁定运行/构建工具版本，复现使用 package-lock.json 和 npm ci。

## 数据清单与质量材料

打包只允许 dist、dist-electron 的生产 JS、package.json 及生产依赖；资料来自明确清单，不扫描用户目录、密钥或整个工作区。固定两层模型、前后结果与报告来自 T33 已通过的固定回放，复制前核对验证记录的 SHA-256；安装后再次核对文件清单与哈希。保留 T31 数值与 T32 性能原始记录、62 项故事/20 项 AC 索引、启动及限制说明。

安装器/归档哈希随实测记录，不承诺不同时间或工具环境构建逐字节一致。复用 T33 公开完整演示函数，增加安装版 executablePath、app.isPackaged 断言及 exe/app.asar 哈希。解释和比较仍核对冻结输入、真实引用和独立总体力平衡。真实 DeepSeek 复用当前用户已配置的加密凭据，仅复制到临时隔离目录，测试后移除；证据不读取或记录明文凭据。

## 预登记验收入口与判定

沿用 PLAN 第 7 节真实桌面公开操作及输出文件边界。界面创建/编辑、保存、打开、计算、取消和导出；测试用临时目录绕过原生文件选择，实际文件系统、DPAPI、Worker、报告生成均真实执行。单杆输入 L=4 m、E=200 GPa、A=0.01 m²、Iy=0.0002 m⁴、Iz=0.0001 m⁴、J=0.00015 m⁴、起点全固定、终点 Fy=6 kN。独立 Euler-Bernoulli 参考 Uy=0.0064 m、Ry=-6 kN，绝对误差不超过 1e-10。初始无效模型不产出成功结果，修正后求解成功；取消 1,120 杆真实 Worker 后无新成功结果，重算后只增加一份结果。

未配置、配置后移除、配置但连接失败三种模式均从空模型到保存/完整重启和双格式导出。应用进程在临时工作目录启动，PATH 仅有 Windows/System32，清除开发环境变量。Chromium 设置 offline，主进程 HTTPS 在网络边界拒绝；这是可重复断网行为验证，**不是操作系统物理断网**。本机有开发工具，不将隔离配置记作干净机器。

安装验证器拒绝覆盖已有 FrameMind 注册安装，只在自行创建的临时中文目录安装。成功或失败后均用卸载器清理注册状态，之后才删除经校验的临时目录。卸载失败保留目录和原因，不直接删除注册应用。

本机没有 Windows Sandbox。`new-t34-sandbox.ps1` 生成禁网 WSB、只读安装资料和可写 Evidence 映射。沙箱脚本安装、启动并登记环境及哈希；清单须由实际验证者填写，不将启动自动记为验收通过。

## 首版判定

依用户明确指令提前实施 T34；保留 PLAN 原依赖及 T33 未完成的事实。候选安装包和本机技术证据不能替代真人 AC-20 或没有开发工具的 Windows 安装验收。两项缺口解决前，T34 与首版均不能标记全部完成。
