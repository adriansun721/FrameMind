# ADR-0044：Agent 基础可靠性联测与工具前置错误恢复

- 日期：2026-10-05（Asia/Taipei）
- 状态：Accepted
- 范围：PLAN2.0 T2-11；AC2-01—AC2-11

## 决定

使用版本化的 [protocol.json](../evidence/plan2/T2-11/protocol.json) 固定场景、两次重复、指标分母、分析位移参考与通过门槛。验收程序在执行前复制协议并记录 SHA-256、源码指纹、Git 基点与 Windows/Node/Electron 版本；每次执行使用独立时间目录，不覆盖旧失败。确定性契约、真实 Electron 回放与实际 DeepSeek HTTPS 的结果分开记录，不以回放代替真实模型选择工具的能力。

六类主指标按事先指定的检查点计数。失败和没有测到的检查点均保留在分母，不能通过跳过、重试或删样本改善完成率。AC 覆盖报告统计契约用例通过情况，与真实 AI 指标不同；同一契约可以覆盖多个 AC，因此不可把覆盖表的计数相加当作独立样本数。真实联测为三种流程各两次的小样本基线，不推断总体完成率。

真实模型使用现有应用加密保存的连接配置，在临时资料夹中由正常主进程解密；不读取、输出或归档明文凭据，不修改日常连接配置。聊天和工程证据使用既有持久化脱敏函数；无本机加密配置时记录 blocked 并返回非零退出码。应用内仍可独立运行本地建模、求解、结果查看与保存。

首轮真实联测暴露两处工具契约问题。分析意图的领域校验要求来源，但提供给模型的 JSON Schema 原先只要求 requested；现把 source 也列为必填，不自动把未知来源改成用户提供。诊断试算缺少副本属于工具调用次序错误；工具现在返回 requiredTool=create_diagnostic_copy，Agent 把这条实际回执继续交给模型，由模型选择下一步。程序不自行创建副本，不改正式模型。重复无视同一前置条件受既有重复失败、无进展及轮次预算限制；真正缺少工程输入、过期副本、目标冲突与待确认草案仍停下来等待用户。

## 验证边界

固定契约覆盖撤销后旧重试、无关编辑、目标删除、浏览、队列、预算、中断、跨项目迟到响应、确认事务异常退出和跨重启恢复。三条新增桌面流程同时用于回放与真实联测：手动编辑／重开读取；整体草案重启后双击确认并续算；候选副本试算和正式来源隔离。既有 T20 保存状态选择器改为页脚；项目 v2 允许保存任务目标，因此只要求助手全文留在本机。卡片布局检查滚动容器的可见边界，保留不覆盖输入栏的要求。

本任务不替代 T2-41 的新增分析工具验收、真人试用、性能规模验收或干净 Windows 安装。
