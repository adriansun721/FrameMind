# ADR-0021：T20 只读 AI 工具与对象上下文

- 日期：2026-10-02
- 状态：已接受
- 范围：DeepSeek 对话、已应用模型读取、执行状态与上下文失效；不包含模型修改、求解或结果解释工具

## 同一模型与稳定身份

每次发送消息从工作台当前 `FrameProject` 捕获不可变快照，携带项目 ID、项目名称、模型 revision 和选中节点/杆件的稳定 ID、显示编号及存在状态。项目树、三维和数据表的单选与混合多选均通过同一选择入口生成上下文。工具读取正式项目模型，属性和数据表中未保存的草稿不进入快照。

`read_model` 读取摘要或分页集合（节点、杆件、材料、截面、支座、荷载、工况与组合）；`read_selection` 读取明确选中对象；`read_objects` 使用稳定身份读取指定对象。对象输出包含单位，杆件还包含实际端点、材料、截面及由现有几何契约计算的局部轴和长度。工具不提供分析历史，结果解释与追溯由 T25 负责。

分页默认 50 项、最多 100 项；指定对象最多 100 个。对象未选中或身份不存在返回 `missing-input`，不猜测引用。快照深复制后冻结，只读工具没有任何项目更新入口。

## 工具协议与凭据边界

沿用 T19 主进程凭据服务与受信 IPC，在固定官方 HTTPS 地址发送 `tools`、`tool_choice=auto`、`thinking.type=disabled`、`stream=false`，每轮最多 2048 输出 token。只有预定义的三个读取工具作为可调用函数发送给 DeepSeek。收到 assistant 工具调用后，任务层执行本地读取，将原 assistant 调用和带对应 `tool_call_id` 的实际结果发送到下一轮。

官方资料于实施时核对：[Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。非思考模式避免引入需要逐轮回传 `reasoning_content` 的思考协议；未采用 beta strict 模式，本地仍独立校验输入。

主进程校验消息角色、调用 ID/类型、工具输出匹配、消息数和字节数。请求/响应正文上限 1 MiB，每轮至多 16 个调用，单个参数字符串至多 16 KiB。响应增量读取且超时覆盖整个正文；密钥原文或 JSON 解码后的完整密钥出现在返回内容时拒绝响应。底层异常和服务错误正文不传给渲染进程。凭据始终由 T19 服务读取，不进入工具上下文、项目或对话记录。

本地执行入口严格校验 JSON 对象、已定义字段、分页值和对象引用。未知工具、脚本和命令失败；识别到模型修改名称时只返回 `awaiting-confirmation`，说明当前只读并引导手动编辑，不保存或应用修改，也不提供伪造的确认按钮。

## 任务与界面

任务区分 `completed`、`missing-input`、`awaiting-confirmation`、`failed`、`cancelled`。界面显示请求/读取/整理阶段，以及可展开的输入、输出和错误原因；失败可打开设置或基于当前模型重试。单任务最多 8 轮网络请求、64 条读取记录，超过上限停止并建议缩小范围；不自动重试，避免无界循环。

每次发送具有独立任务 ID。用户取消立即完成本地取消并中止网络；项目、模型对象、选择或会话变化后取消旧任务。任务层在请求前、响应后和工具执行前复核上下文，迟到回复不执行工具或覆盖有效状态。保存/移除凭据会中止主进程全部待处理聊天。

面板暂存最多 20 次对话，向模型发送最多最近 4 次同一模型对象、同一选择下的成功问答。切换项目或重新打开工程销毁对话；不同模型或选择下的问答不作为新消息历史。每条记录保留原上下文，当前项目快照身份不同时标记历史版本，不仅比较 revision：撤销分支可能使不同模型内容复用版本号。没有工具调用的普通回复明确显示“未读取模型工具”。对话和工具记录不写入工程文件，也不承诺重启恢复。

## 验证与后续

公共工具入口、任务入口、主进程连接入口以及真实 Electron 工作台均有固定回放验证，见 [T20 验收记录](../evidence/T20-validation.md)。固定回放与真实 DeepSeek 在线对话分别记录；有真实 Key 时只通过应用设置配置，不在聊天或仓库收集密钥。

后续 T21—T24 添加预览/确认/写入工具时需延续独立任务身份与模型事务边界，不能把本次只读快照误用为已授权写入。T25 扩展结果读取与可追溯引用，T27 扩展恢复流程。
