# ADR-0009：T09 杆件均布荷载

- 日期：2026-10-01
- 状态：已接受
- 范围：小变形 Euler-Bernoulli 空间刚架，整根杆件的均布力

## 荷载与持久化

`FrameUniformLoad` 保存稳定 ID、Q 显示编号、杆件 ID、`kind: uniform`、`coordinateSystem: global | local`、工况 `loadCaseId: LC1` 和三个 `intensity` 分量，单位均为 kN/m。这是沿实际杆长计量的均布力，不是向某坐标平面投影后的强度。全局荷载方向不随截面转角改变；局部荷载随杆件朝向和截面转角改变。多条均布荷载线性叠加。LC1 是当前单工况，工况管理由 T11 接入。

添加、更新、删除沿用项目不可变修改与 T08 历史入口；删除杆件或其端节点时级联删除所附均布荷载，撤销同时恢复引用。复制杆件沿用 T08 的几何/属性复制语义，不自动复制附属荷载。操作历史仍只保存在本次会话中。

项目格式保持 v1 的向后读取约定：旧项目缺少均布荷载和计数器时读取为空列表与 1。新文件保存模型荷载与独立冻结的原分析荷载，修改当前荷载不改变历史结果。旧版程序尚未理解均布荷载，不能用旧版重算 T09 文件。记录中的非均匀、分段、中间集中力、分布力矩和未知附加字段明确拒绝；未知工况和坐标系、非有限强度、失效引用及冲突计数器也拒绝。

## 一致荷载与内力恢复

沿用局部轴和自由度顺序 `[ux,uy,uz,rx,ry,rz]`。全局 q 通过杆件正交轴转换为局部 q。局部一致等效节点向量采用轴向线性和弯曲 Hermite 形函数的精确积分，起/终点分别为：

```text
f_start = [qx L/2, qy L/2, qz L/2, 0, -qz L²/12, +qy L²/12]
f_end   = [qx L/2, qy L/2, qz L/2, 0, +qz L²/12, -qy L²/12]
```

用 `Tᵀ f` 组装全局作用；反力为 `K u - F`。杆端作用是 `k_local u_local - f_local`，必须扣除均布荷载的一致向量。把均布荷载只替换成节点力而不扣除该项，会造成错误的杆端作用和内力分布。

`getMemberSectionForces(result, memberId, x)` 使用该次冻结输入，查询从起点量取的任意位置 `0 <= x <= L`，返回 N、Vy、Vz、T、My、Mz。前三者为 kN，后三者为 kN·m；它们是正局部 x 面上的截面作用，正 N 为拉力，其余按正局部轴及右手定则。与杆端节点作用的关系为 `section(0) = -start`、`section(L) = end`。设起端作用为 s：

```text
N  = -sFx - qx x
Vy = -sFy - qy x
Vz = -sFz - qz x
T  = -sMx
My = -sMy - sFz x - qz x²/2
Mz = -sMz + sFy x + qy x²/2
```

因此剪力为一次函数，弯矩为二次函数，供 T14 查询真实图形数据。结果面板可输入实际位置，不使用端值线性插值。按需杆件记录也返回局部/全局一致向量，便于核对恢复项。

求解实现标识升级为 `framemind-frame/3`，算法、约束法和主元阈值沿用 T04。v2 的无均布荷载结果仍可重建；缺失版本或不兼容版本的结果可显示已存数据，但不能伪称可恢复均布荷载内力。

## 实现前的参考与阈值

沿用 T04 阈值：每个标量误差不超过 `max(1e-9, 1e-8*abs(reference))`；近零量按绝对阈值验证。使用静力平衡与梁理论解析解，不使用本实现的刚度矩阵生成参考。

L=4 m，E=200 GPa，A=0.01 m²，Iy=0.0002 m⁴，Iz=0.0001 m⁴，局部 q=(2,-3,4) kN/m 的悬臂：自由端位移 `(0.000008,-0.0048,0.0032)` m，转角 `(0,-0.0010666666667,-0.0016)` rad；固定端反力 `(-8,12,-16)` kN、反力矩 `(0,32,24)` kN·m。独立公式为轴向 `u=qx L²/(2EA)`、弯曲 `v=q L⁴/(8EI)`、端转角 `theta=q L³/(6EI)`。x=2 m 的截面作用为 `(4,-6,8,0,-8,-6)`。

8 m 两端固定梁，分为两根 4 m 杆，qy=-3 kN/m：中央位移 `qL⁴/(384EIz)=-0.0016` m；两端竖向反力各 12 kN，反力矩分别 16、-16 kN·m。整体位置 x=0、2、4、8 m 的 Mz 分别为 -16、2、8、-16 kN·m。

空间斜杆的端点 `(2.4,3.2,0)` m，局部轴分别为 `(.6,.8,0)`、`(-.8,.6,0)`、`(0,0,1)`，全局 q=(3.6,-.2,4)。将上述解析位移变换到全局得到 `(0.0038448,-0.0028736,0.0032)` m；总作用 F=(14.4,-.8,16) kN，作用中心 r=(1.2,1.6,0) m，固定端反力矩 `-r×F=(-25.6,19.2,24)` kN·m。

## 显示边界
