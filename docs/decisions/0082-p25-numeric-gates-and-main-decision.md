# ADR-0082：反向设计数值门禁、可行比较与 main 合并请求

日期：2026-10-10（Asia/Taipei）

P25-11 复用 P25-08 的候选分支与版本确认接口、P25-10 的真实并发 work 和只读 inspect。`ReverseDesignInspector` 注入桌面候选服务，只接受 `reverse-design-v1` 的真实原生求解证据；通用项目仍可编辑、恢复和保存，其他候选不能借该 inspector 冒充反向设计通过。

只读 inspect 与合并门禁共用 `inspectReverseEvidence`，分别重新读取不可变候选与结果。绑定任务、候选、父提交、父输入、候选内容、冻结输入和原生结果哈希；新建冻结请求与被检请求逐值一致。原生 wire 必须完整完成，节点和杆件 ID 必须完整且唯一。目录材料与截面、几何、支座和题目荷载继续由固定输入验证器约束。

真实解算仍来自 C++ sparse LDLT，遵守现有正主元、相对 `1e-12` 主元阈值、有限回代和解算残差检查。针对固定的 12 节点场景，TypeScript 独立参考额外检查自己的主元阈值，并重新组装冻结自重、工况组合、均布与节点荷载；其等效荷载向量与原生记录的逐分量差不超过 `1e-9`。参考结果不替换原生结果。整体平衡使用重新组装的冻结荷载和原生反力、反力矩，在全局坐标、共同参考点 `(0,0,0) m` 求合力和合矩的欧氏范数；阈值分别为 `1e-7 kN`、`1e-7 kN·m`。最大水平合位移由原生节点结果计算，阈值为 15 mm。

候选质量和求解冻结输入质量分别按 `ΣρAL` 计算，必须正且有限。`mass` 检查记录两来源绝对差 kg，阈值 `1e-9 kg`，不再把它解释为布尔值 1。固定资源的 source/resources/stiffness 保持二值程序检查。所有七项检查拥有值、阈值、结论和具体结果证据 SHA-256；有效失败报告也保存为候选 `inspect.json`。错来源、损坏、缺项和无法完成求解的候选标为 blocked，其余值明确未验证，不能用占位数值进行可行比较。

inspect AI 只能读取同轮证据并提交准确引用，不能修改数值、阈值或模型。host 在结构化引用完成后独立运行门禁并推进 passed/blocked 状态。一个受损候选不会消除其他候选的检查报告；取消或父状态变化仍立即中止。普通文字、伪造 passed、错误证据或 main 工具参数不能成为通过信号。

`compareReverseDesignCandidates` 只纳入七项程序门槛全通过的候选，先按质量排序。同质量先比较截面组数，再比较种类数，最后按稳定任务身份排序。候选质量相对最低质量差严格小于 0.5% 时优先更简单方案；已有可行前轮方案的改善小于 0.5% 且前轮至少同样简单时保留前轮。当前一轮入口没有伪造前轮可行证明；跨轮反馈状态接入仍由 P25-12 负责。

main 的 `propose_merge` 只接受程序选中的 taskId、具体 commit、输入和结果哈希，并重新核对 passed 状态。保存 `comparison.json` 与 `main-decision.json`。无可行候选时形成 no-feasible 决策；未完成或过期时为 blocked，并移除执行用合并请求。merge-proposed 只表示等待用户确认，不立即修改模型。桌面显示比较表、失败证据和请求版本，用户通过既有“候选与差异”查看字段并确认该提交；实际合并再次验证父状态与检查证据。

P25-11 不保证比初始模型更轻，不实现跨轮反馈、全局最优、强度、屈曲或规范验算。在线证据的三个候选均超位移，已验证拒绝合并；另一本地证据通过真实 C++ 求解验证通过候选的受控合并，AI 明确为回放，不据此声称在线减重成功。

复验：`npm run test:plan2:p2511`；`npm run evidence:plan2:p2511`；`npm run evidence:plan2:p2511:online`。归档证据复验：`node scripts/verify-p25-11.mjs`，在线归档为 `npx cross-env FRAMEMIND_P2511=1 node scripts/verify-p25-10.mjs`。源码或构建变化后必须生成新 run ID。
