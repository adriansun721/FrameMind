# ADR-0002：T02 杆件、材料、截面与局部轴

- 状态：已接受
- 日期：2026-09-30
- 适用范围：T02 手动单杆与材料截面编辑；T03 将核定单元理论和求解参数

## 决策

项目统一模型新增材料、截面和杆件集合。三类对象分别使用 `material_0001`、`section_0001`、`member_0001` 形式的稳定 ID；显示编号分别为 `M1`、`S1`、`M1`。杆件只保存起终点、材料和截面的稳定 ID，不复制被引用对象的属性。

当前材料参数及存储单位为：

- 名称；
- 弹性模量 `E`，GPa；
- 泊松比 `ν`，无量纲；
- 密度 `ρ`，kg/m³。

当前截面参数及存储单位为：

- 名称；
- 面积 `A`，m²；
- 绕局部 y 轴的截面二次矩 `Iy`，m⁴；
- 绕局部 z 轴的截面二次矩 `Iz`，m⁴；
- 圣维南扭转常数 `J`，m⁴。

这些字段以物理名称和量纲保存，不使用含义不明的通用参数。T02 不据此生成分析结果；剪切模量关系、梁理论、剪切变形和内力符号等在 T03 结合单元理论与基准算例核定。

## 局部轴与截面朝向

局部 x 轴由杆件起点指向终点。默认参考轴按以下确定：

1. 当局部 x 与全局 Z 的方向余弦绝对值小于 `0.9` 时，使用全局 Z；
2. 否则使用全局 Y，避免竖直或近竖直杆件出现叉积退化；
3. 未旋转局部 y 为“参考轴 × 局部 x”的单位向量，局部 z 为“局部 x × 局部 y”；
4. 用户输入的截面转角按右手定则绕局部 x 轴旋转局部 y、z，单位为度。

因此水平、倾斜、竖直杆件均得到确定的右手坐标系。三维视图在选中杆件时用绿色和蓝色箭头分别显示局部 y、z；属性面板显示三个单位向量、参考轴、长度和截面转角。杆件轮廓半径按截面面积换算为等效圆面积，并在视图浮层实时显示材料、`E`、截面、`A` 与转角；该轮廓只用于当前尚无截面形状字段时的可视核对，不表示实际截面形状。

## 校验与编辑边界

- 节点坐标和截面转角必须为有限数值；杆件长度必须大于 `1e-12 m`。
- `E`、`ρ`、`A`、`Iy`、`Iz`、`J` 必须为正有限数值；`ν` 必须满足 `-1 < ν < 0.5`。
- 新建和编辑杆件时，端点、材料、截面引用必须存在。
- 移动已连接节点若会产生零长度杆件，整次修改被拒绝，正式模型保持不变。
- 属性面板的节点、材料、截面和杆件编辑均通过领域模型命令更新同一模型；三维视图、项目树和保存文件不维护独立副本。

## 文件兼容

项目格式继续使用 `formatVersion: 1`。T02 新增字段属于可选的向后兼容扩展：打开 T01 文件时，缺失的材料、截面、杆件集合按空集合解释，缺失的相应下一编号按 `1` 解释；任何已出现但格式错误、身份重复、计数器冲突或引用失效的数据都会被拒绝，不会静默改写。
