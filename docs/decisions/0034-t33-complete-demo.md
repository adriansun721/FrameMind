# ADR-0034：T33 完整演示与首次使用验收

日期：2026-10-03。状态：采用；真人首次试用待完成。

## 演示输入与公开验证边界

固定输入为 [t33-demo.json](../fixtures/t33-demo.json)，版本 `T33-two-storey-v1`。全部几何、荷载、组合与加大截面均为教学演示假设，不声称满足设计规范。材料和原截面的来源沿用 T13 目录及项目内 provenance；演示不新增外部参数来源。

验证通过真实 Electron 界面操作、保存项目、可点击结果引用和实际导出文件进行。固定工具回放只替代主进程 HTTPS 响应，本地 Worker 求解、成组应用和 Word/PDF 生成均真实执行。另用完全相同流程、隔离用户目录和已有本机加密凭据运行真实 DeepSeek；在线路径不替换 fetch。保存配置仅包含模型名、运行版本、网络模式，不读取或输出密钥。

每次运行先将 `validation.json` 置为 running，失败置为 failed；只有整条流程通过才记录 passed。通过记录包含独立 runId、起止时间、固定输入和构建索引哈希，以及项目、报告和所有阶段截图的 SHA-256。文档 QA 必须读取本次 passed 记录并核对全部文件哈希，防止失败重跑使用旧报告。故障取证失败不能覆盖原异常。自动解释先定位该轮消息，再等待终态，不能把本地计算完成或尚在请求误记为解释完成/中断。

固定输入与保存项目的 SHA-256 按原始字节计算；`.gitattributes` 对这两类 T33 文件禁用换行转换，确保 Windows 的 `core.autocrlf` 不改变提交后重开的证据。

从空项目发送自然语言，刻意留空 Y 跨长；用户通过卡片填 4 m，更新预览后才能确认。两个阶段确认前分别保存项目，检查几何和条件未泄漏到正式输入。检查 12 节点、16 杆、所有固定几何、目录来源、约束与荷载；两次计算均独立检查总体力平衡：Rx=-7.5 kN，Ry=0，Rz=ρgΣAL/1000+18 kN，绝对误差不超过预登记 1e-7 kN。

AI 解释和比较中的三个数值，逐项对照保存项目的实际分析结果和冻结分析 ID。核对选柱修改只影响 M1、M2，其他成员、原共享截面及前次结果保留。导出明确选择后次分析，并检查 Word 内容与报告 ID；另以逐页渲染检查 PDF 与 Word 内容、页面边界及可读性。保存重开后保留两次结果、清空会话。离线回放额外注入网络失败，验证失败提示、本地计算入口及已确认模型、结果保留。

三项引用同时检查真实渲染的按钮，含指定对象、分量、数值、单位和差值，不能仅因工具读过数据就声称用户看到正确引用。线上若缺少 LC1 名称更新，明确发送保留工况别名和其他条件的补充请求，并保留确认后计算意图；组合或新截面名称差异通过可编辑卡片纠正。确认荷载前核对节点、杆件选择器是否对应固定坐标，必要时按用户指定演示输入纠正目标，记录原/新身份及原因。全部工具原始输出、补充消息和卡片修改均保留。计算后的实际数值不能修改，确认后的对象范围、荷载和结果仍严格核对；通过不代表 AI 无需人工检查即可正确分配全部条件。

## 完整流程暴露的身份缺陷

AI 新增自定义/目录柱截面时，预览 `FrameSection` 携带 `id`、`label`；旧 `validateSection` 将整个对象展开返回，覆盖 `addSection` 分配的正式身份，导致重算可完成而报告导出及重开失败。材料校验存在同形问题。修复为校验函数仅返回声明的物理参数，身份和来源由正式创建入口管理。最小回归通过截面阶段确认后项目往返验证复现，修复前报“截面 待确认自定义截面 的稳定标识格式无效”；自定义与目录两条路径修复后通过，完整演示再验证导出与重开。

## 首次使用界面与验收边界

空对话增加简短起步说明、填写两层刚架任务按钮和连接设置入口。按钮仅填入草稿，不发送联网请求、不创建模型；用户仍可编辑并主动发送。已有草稿时禁用模板按钮，避免覆盖输入。有模型时使用继续当前模型的提示。引导沿用主题变量和现有面板，不新增向导或持久化字段。

自动化与视觉核验覆盖深浅主题、1440×900 和 1080×680。真人首次试用独立记录于 [T33-first-use.md](../evidence/T33-first-use.md)，只有未读手册的真实试用者实际完成、卡点修复并复验后，才能勾选 PLAN 的最后一项和 PRD AC-20。开发者、AI、脚本或截图均不替代真人。缺少参与者时交付可执行材料与明确待验收状态，不将整个 T33 标为已完成。
