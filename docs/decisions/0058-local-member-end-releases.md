# ADR-0058：局部杆端弯矩释放与静力恢复

- 日期：2026-10-06（Asia/Taipei）
- 状态：Accepted
- 范围：PLAN2.0 T2-25；延续 ADR-0047—0050 的分析、来源和单位契约

## 工程表达与支持矩阵

`MemberProperties.endReleases?: {start:{my:boolean,mz:boolean},end:{my:boolean,mz:boolean}}`。每端支持刚接、仅 My、仅 Mz、My+Mz，共 16 种两端组合。缺省是刚接，旧文件不补造释放；提供字段时必须完整指定两端四个布尔值，拒绝其他分量和额外字段。My 对局部 y 轴转动释放，Mz 对局部 z 轴转动释放；随杆件方向和截面转角变化。轴向、剪切、扭转连接保持，支座仍独立约束全局六自由度。

手动新建／属性、共享事务、工具 create/update_member(s) 与整体任务 operations 使用同一领域校验。工具只产生待确认草案，读回包括释放字段。复制保留释放，明确分割只把释放放到原工程起终点，新增连接端刚接；不实现 T2-26 内部计算细分。释放是结构输入依赖，修改令使用该结构的结果过期，撤销恢复原输入。坐标单位转换不改变布尔释放和局部轴定义。

界面用独立端部选择器和局部轴说明。空心环位于杆长 6%／94% 处，13 px，关闭深度遮挡，实体与分析线共用标记；选中后显示端别及分量，完整信息见属性。节点支座图形不改为铰接图形。

## 数值方法与求解版本

有实际释放的正式任务选择 `framemind-native/3`，仍用 Eigen 3.4.0 稀疏 LDLᵀ；刚接正式任务保留 `/2`，历史 `/1`、`/2` 继续读取。冻结假设 `rigidJoints` 与实际释放一致。旧原生和 TypeScript 参考求解入口拒绝释放，不能静默按刚接计算或回退。释放分量的边界与 [OpenSees 三维 elasticBeamColumn 官方文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/elements/elasticBeamColumn.html) 的 releasey/releasez 一致；该文档不作为本实现数值结果的替代证据。

每根杆原始刚度 K 按保留自由度 c、释放转角 r 分块。释放端弯矩为零，故 `ur = Krr⁻¹(fr − Krc uc)`。构造恢复映射 H，得到 `Kc = Hᵀ K H`、`fc = Hᵀ f`，再做局部到整体转换及组装。等效荷载与刚度一起凝聚；局部均布力、全局均布力、自重、组合合量共用同一路径。恢复使用原始刚度、原始荷载与恢复转角；不能把节点支座转角当作释放后的梁端转角。

实际原生记录保存原始／凝聚刚度、H、T、原始／凝聚荷载和梁端局部位移，杆件过程标为本次运行采集。TypeScript 只为既有报告的系数一致性检查重建 Schur 补，不参与正式求解。新版本沿杆位移加上均布荷载的零端值／零端坡度特解：弯曲 `q x²(L−x)²/(24EI)`、轴向 `q x(L−x)/(2EA)`；任意显示采样使用同一冻结输入派生关系。内力仍从杆端力与均布荷载的精确平衡多项式恢复。

原生记录的每项矩阵和荷载都与冻结输入重建系数核对。凝聚／整体刚度的近零项可能经历大数消减，系数核对容差取 `max(1e-9 × max(1, abs(reference)), 128 × Number.EPSILON × absoluteProductSum)`；局部尺度是 HᵀKH 各乘积绝对值之和，整体尺度再按 Tᵀ·scale·T 的绝对值乘积传播，均只由冻结输入计算。原始刚度、H、T 不使用该消减项。此容差只用于记录一致性，不改变下述反力、内力、位移与残差验收阈值。大截面双端释放回归覆盖宽 2／4 m、长 3.1／4 m、局部轴转角 0／37°，并要求向理论零刚度项注入 0.01 仍被拒绝。

## 脱开节点转动与真实机构

释放系数的消减尺度与比较函数由解码和报告附录共用；报告的杆件组装贡献使用对应全局尺度，整体／约束后矩阵按相同自由度映射累加尺度，保留真实采集矩阵。仅 `/3` 的实际释放杆件启用此尺度，历史／刚接记录仍按既有校验读取。大截面回归同时要求报告完整、无缺失提示，篡改组装贡献或整体近零矩阵项 0.01 时报告必须拒绝。

显式释放可使某节点转动方向与所有杆端完全脱开。按每个相邻杆端仍连接的局部 x／y／z 方向及已有全局转动支座建立无量纲几何 Gram 矩阵，识别零空间；阈值为最大特征值的 1e-12。该检查不基于刚度大小，不能把很柔的实际连接当作释放。每次选择该零方向绝对分量最大的全局转角作为坐标参考 0，消去其自由度并记录方向、节点及索引，独立于真实支座分区。旋转局部轴导致的斜向零空间也适用。

脱开方向上的有效节点力矩绝对值超过 1e-9 kN·m 时失败，定位节点及 endReleases。脱开转动不是可确定的物理节点转角，界面和报告明确标为参考值；梁端坡度由恢复得到。没有给任何自由度增加隐式刚度。其余平移或耦合机构仍按原 LDLᵀ 主元规则失败，记录工程节点、自由度和主元证据。保留原残差规则，并对恢复释放端弯矩要求 `abs(Mr) <= max(1e-9, max(abs(endForces))*1e-10)` 后才写出零值。

## 独立验证登记

正式数值记录生成前登记下列口径，不随实测结果放宽：力／弯矩 `max(1e-8, abs(reference)*1e-9)`（kN／kN·m）；位移／转角 `max(1e-12, abs(reference)*1e-9)`（m／rad）。近零使用相同绝对项；释放端弯矩另检查为零。整体平衡及自由自由度残差阈值保持 ADR-0047，不以旧新实现相近替代解析参考。

固定 L=4 m、E=200 GPa，截面沿用明确几何的矩形。均布力各弯曲平面的参考由独立梁方程与平衡给出：

| 两端条件 | 起点／终点反力 | 端弯矩绝对值 |
| --- | --- | --- |
| 刚接／刚接 | qL/2、qL/2 | qL²/12、qL²/12 |
| 刚接／释放 | 5qL/8、3qL/8 | qL²/8、0 |
| 释放／刚接 | 3qL/8、5qL/8 | 0、qL²/8 |
| 释放／释放 | qL/2、qL/2 | 0、0 |

分别核查全部 16 种 My/Mz 组合。简支梁坡度为 ±qL³/(24EI)，跨中挠度为 5qL⁴/(384EI)；固定端／自由端的释放机构必须失败。两根固定底柱承托双端释放梁的竖向荷载框架，柱底反力各 qL/2，柱轴力同值、柱弯矩为零，梁端弯矩为零。另验证旋转局部轴、有效节点力矩冲突、正负组合与自重、分割前后原工程端部和保存往返。桌面回放和截图不替代这些数值判据，未宣称新增能力真实 AI 或干净 Windows 安装验收完成。
