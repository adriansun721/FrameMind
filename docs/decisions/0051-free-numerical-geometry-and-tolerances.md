# ADR-0051：自由数值建模与独立几何容差

日期：2026-10-05（Asia/Taipei）。范围：PLAN2.0 T2-18。

## 工程坐标和拓扑

数值节点输入、属性修改、批量操作、工具草案、确认回读、项目文件及原生静力沿用规范单位 m 的有限 IEEE-754 双精度 XYZ。负值、小数和可见网格外坐标不裁剪、不取整、不吸附。节点身份由计数器分配；完全同坐标的节点仍是不同对象。连接仅取决于杆件的 startNodeId/endNodeId。交叉杆件不会生成交点、分割、合并节点或转移荷载；显式连接、捕捉与合并分别留给 T2-19—T2-21。

`propose_frame` 和 `propose_task.frame` 的正交参数化生成限制仍存在，但不限制基础节点／杆件编辑。自由建模使用现有创建和修改工具；节点创建经确认后，重读正式身份再准备引用这些节点的杆件。新增只读工具 `read_geometry_contract` 返回固定规范单位的契约，显示单位不会转换契约里的容差。

## 分开的容差

`src/domain/geometry-policy.ts` 登记当前口径，不改变既有原生方法或数值门槛：

| 用途 | 当前规则 | 对拓扑的作用 |
| --- | --- | --- |
| 可见网格 | 世界原点的 30 m 参考网格 | 无边界限制 |
| 视觉拾取 | 节点隐藏球半径 0.22 m；杆件隐藏圆柱半径 clamp(杆长×0.02, 0.08, 0.16) m；线阈值 0.04 m；拖动超过 4 CSS px 不作为点击 | 仅选中已有身份，不修改坐标 |
| 捕捉 | 当前未启用；T2-19 实现可控捕捉 | 无自动复用或创建 |
| 几何判重 | 精确 XYZ 相同可视为坐标重复；当前不执行扫描或自动合并 | 同坐标不同身份也不连接 |
| 杆长有效性 | 长度必须有限且严格大于 1e-12 m | 拒绝零长和不足最小长度对象，不合并节点 |
| 静力求解 | 相对主元 1e-12；原生残差绝对下限 1e-9、相对 1e-10，参见 ADR-0047 | 诊断数值条件，不变更连接 |

以上几何阈值固定在规范单位，不随绝对坐标、项目外包尺寸、显示单位或相机缩放扩大。双精度无法表示的间距会成为相同数值；不能保证任意有限坐标间的所有数学差值均可表示。差值或杆长溢出、零长和极端刚度量级继续明确失败，不静默截断成可求解模型。领域错误保留节点／杆件标签和原因，分析诊断另含稳定对象身份与字段。

## 批量提交

`updateNodes` 先在不可变项目中形成所有最终节点坐标，再校验受影响杆件。手动批量入口与工具草案相同。连续 `update_node` 操作视为一个坐标组，允许交换端点、整体平移和部分坐标补丁，重复身份补丁按输入次序合成；其他操作保持原先顺序，分隔坐标组。最终无效几何拒绝整组操作，原模型不改变。确认只产生一次修订和一份回执，撤销仍恢复整组快照。

## 三维精度

视图以首个正式节点为显示原点（空正式模型采用首个预览节点），在 JavaScript 双精度中先减去原点，再写入 Three.js 的 Float32 几何缓冲。模型、支座、荷载、草案、历史结果和结果定位共享原点。原点变化时平移相机与 OrbitControls 目标以保持世界视角；网格和世界轴作同样的平移。结果图幅按局部坐标尺度生成。选择信息仍显示正式世界坐标；显示副本不会进入工程文件、冻结结果或工具回执。

首个节点的 1e9 m 平移不再抹去 0.0001220703125 m 的杆件间距。屏幕分辨率和全模型尺度仍限制肉眼可分辨程度；隐藏点击几何重叠不会导致节点合并。
