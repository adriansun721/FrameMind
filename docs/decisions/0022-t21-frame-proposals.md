# ADR-0022：T21 参数卡片与隔离模型预览

- 日期：2026-10-02
- 状态：已接受
- 范围：自然语言建模参数、可编辑卡片、批量几何预览与拒绝；阶段确认写入由 T22 接续

## 方案契约

沿用 T20 的公开工具与任务边界。新增 `propose_frame({parameters})`，每个字段携带 `value`、`source`（`user` / `suggestion`）和可选 `replace`。参数包括层数、X/Y 向逐跨长度、各层层高、XYZ 原点、钢材、柱/梁截面及截面转角。长度单位 m，转角单位 °；资源引用当前项目稳定 ID 或 T13 已核查的目录 ID，不由 AI 捏造材料截面数值。卡片显示已知、建议和缺失状态；层数与层高项数不一致也属于待澄清输入。

工具生成沿全局 XYZ 正交网格、Z 向分层的空间梁柱框架：每层所有网格交点设节点，相邻层交点设柱，楼层相邻 X/Y 交点设梁，地面不自动设梁。所有杆端刚接，不自动加入支座、荷载或求解条件。非正交或其他不能由此参数集表达的结构由助手说明并澄清，不能悄悄替换用户意图。现有手动建模能力继续支持任意空间坐标。

每份草稿具有独立方案 ID 和版本，预览节点、杆件与资源使用方案域内身份；不占用项目编号。缺失、冲突、无效资源、过大预览或坐标精度导致重合时不生成部分几何。单次 AI 预览最多 20,000 节点，是分配保护，不是正式模型数量上限或性能承诺。对象清单每页 100 项，全部对象均可翻页核对。

## 修改、冲突和生命周期

工具补充合并当前卡片，不用旧聊天内容重建草稿。已有用户字段收到不同值时保留原值并显示候选冲突；用户明确改正/澄清时 `replace:true` + `source:user` 可以替换。建议不能借 `replace:true` 覆盖用户值，同值建议也不能抹去用户来源；重复当前冲突值不能未经明确替换消除冲突。卡片编辑后通过“更新参数预览”统一更新参数与几何，编辑未提交或校验失败期间暂停旧三维预览，避免展示和输入不一致；未编辑的建议保持建议来源。可重新生成或通过按钮拒绝；自然语言拒绝使用 `discard_frame_proposal({})`，本地拒绝为终止操作，无需依赖下一轮联网回复。

方案和对话仅保留在当前会话，不保存到项目、历史事务或分析输入。正式模型对象变化后预览失效，需要更新或重新生成。普通只读回复不能重新激活失效方案。项目切换/重开清除方案；选择变化、取消对话、模型变化沿用 T20 任务失效规则。拒绝同步更新方案身份引用并取消在途任务，迟到工具响应不得重新出现为可用预览。

## 三维和确认边界

三维工作台保持正式模型的节点、杆件、条件和结果，独立图层显示 `--model-preview` 语义色的虚线梁柱与节点，图例明确“未应用预览”。预览不参与正式对象拾取，正式节点/杆件计数和树保持原模型。适合模型时同时包含正式模型和预览；切换主题重新使用对应语义色，并释放旧图形资源。

完整草稿返回 `awaiting-confirmation`，不提供伪造的“应用”入口；缺失/冲突返回 `missing-input`。本任务列出创建对象与本次参数变化，原子应用、绑定基础模型版本和撤销重做属于 T22。

## 联网协议与证据

继续采用既有非思考 Tool Calls 与主进程凭据隔离边界，新增工具由固定 schema 声明并由本地独立校验。实施时核对 [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)；未采用 beta strict 或任意脚本。真实联测发现首轮误读空选择使任务提前结束，已明确新建请求首先生成卡片、无需已有节点或选择的规则；随后四轮真实 HTTPS 验证通过。

验证见 [T21 验收记录](../evidence/T21-validation.md)，包括固定工具回放、真实 Electron、双主题像素/布局与真实 DeepSeek 输入输出记录。
