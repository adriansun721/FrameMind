# ADR-0011：T11 多荷载工况

## 决策

项目保存 `loadCases`、`activeLoadCaseId`、`nextLoadCaseNumber` 和 `analysisResults`。工况包含稳定 ID（LC1、LC2 等）、名称和说明；名称修改和删除不改变其他编号，删除后的编号不复用。新项目只有默认 LC1。

节点力/力矩、杆件均布力和项目级自重共用 `loadCaseId`。自重继续保持 T10 的一份项目级设置，可指定任一工况；它只进入所属工况，不复制到其他工况。公共结构（节点、杆件、材料、截面、支座）供所有工况共享。

`captureAnalysisInput(project, loadCaseId)` 只捕获指定工况的荷载，同时冻结工况 ID、名称、说明和公共结构。`solveFrame(project)` 使用当前工况；传入快照时只接受快照所属工况的荷载。编辑、文件解码和求解均拒绝不存在的工况引用。输入过滤不改变单元刚度、均布力和自重计算公式，沿用求解器版本 `framemind-frame/3`。

## 结果与界面

每个工况保留一份最近成功结果，失败不覆盖它。`latestAnalysis` 保留为最后一次成功结果的兼容字段，界面从 `analysisResults` 按当前工况取结果，不能回退显示其他工况结果。所有结果仍携带各自冻结输入；工况名称修改后可核查原来源名称。

结果有效性比较当前工况的完整输入与冻结输入，忽略项目修订号递增。因此运行其他工况、新建其他工况或编辑其他工况荷载不会误标本工况过期；公共结构修改使全部相应结果过期。没有工况元数据的旧结果仍采用原修订号规则，保守标记有效性。

切换工况同步过滤项目树及三维均布荷载箭头，清除旧选择和诊断，取消当前分析任务。任务取消标记和运行编号共同阻止迟到结果进入另一工况。视图注明当前工况，结果面板注明冻结来源；管理对话框按节点比较各工况位移和反力，并标注来源版本及过期状态。

## 删除与兼容

至少保留一个工况。默认删除接口拒绝荷载或结果引用；用户在管理对话框确认具体引用数量后，可在一次可撤销事务内删除所属节点荷载、均布荷载和工况结果，关闭并重新归属被删除工况的自重设置。工况删除后的当前选择回退到剩余工况。T12 尚未接入组合表达；接入时必须把组合依赖加入引用检查，禁止静默留下组合引用。

项目格式继续使用 v1 的可选字段迁移：缺少工况列表时创建默认 LC1，缺少节点荷载归属时归入 LC1；缺少 `analysisResults` 时从旧 `latestAnalysis` 建立默认工况结果。解码检查工况身份、递增编号、当前工况、荷载引用、结果项目及版本，以及冻结输入工况一致性。

## 验证

`src/domain/analysis-t11.test.ts` 核对两个独立悬臂工况解析响应、冻结来源、局部与公共输入的失效规则、引用清理、编号不复用和旧项目迁移。`e2e/t11-load-cases.spec.ts` 验证真实 Electron 创建、修改、切换、求解、比较、保存重开、荷载重新归属、删除撤销，以及取消时迟到消息隔离。
