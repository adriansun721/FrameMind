# ADR-0007：T07 属性、数据表与三维同步编辑

- 日期：2026-10-01
- 状态：已接受
- 范围：PLAN.md T07；US-011、US-013、AC-04 的本地模型部分

## 模型与提交

沿用 `App` 中唯一的 `FrameProject` 及领域公开命令 `updateNode`、`updateMember`。数据表是这一模型的另一种展示，不持有项目副本。属性面板和数据表使用相同的节点或杆件草稿，以及相同的保存处理函数；保存处理函数解析数值、调用领域校验，全部通过后才通过 `activateProject` 更新项目和修订号。三维几何、局部轴、项目树和已应用属性均从提交后的项目读取。

选择沿用 `{ kind, id }`，不会用行号或显示编号替代稳定身份。数据表的定位按钮同步项目树和属性面板选择并适合当前模型；三维或项目树选择节点或杆件时，表格切到相应类型。保存和重开沿用既有项目格式，不增加表格专属持久化数据。

## 草稿与反馈

同一对象在两种编辑入口中只有一份草稿。草稿输入实时出现在另一入口，提交前几何及已应用值保持当前模型状态。无效数值、空值、无效引用或零长度几何均拒绝提交，并显示字段名称或关联杆件的错误；数据表的对应数值字段具有无效标记。还原按钮和重新选择对象从已应用值重新载入草稿；切换对象会丢弃此前未提交草稿，关闭数据表则保留当前对象草稿供属性面板继续编辑。

创建节点和杆件的对话框使用独立草稿，取消创建不会覆盖当前对象的待提交修改。创建成功后将新对象设为当前选择，并同步其编辑草稿。

## 界面与范围

数据表以可关闭的底部区域与三维视图同时显示，使用既有主题和控件风格。节点和杆件分别提供表格，选中行允许编辑；引用通过模型中的真实节点、材料和截面选项选择。保存按钮和 Enter 均提交当前行，输入不会自动修改正式模型。此任务采用单对象编辑，不提前实现 T08 的批量、复制删除或撤销重做。

选择和草稿不持久化；已提交几何、材料截面引用、朝向及稳定身份随项目保存。AI 工具读取同一模型的集成由 T20 完成。本应用是 Windows 桌面产品，界面验证覆盖默认窗口和 1080 × 720 紧凑窗口，沿用 1080 × 680 最小窗口约束，不宣称移动端支持。
