# ADR-0064 初应力弹性二阶响应与同条件线性比较

日期：2026-10-06（Asia/Taipei）；PLAN2.0 T2-31，US2-057/058/072/076，AC2-16。

本轮选用小位移、材料弹性、未变形参考轴下的初应力二阶近似：先对完整有效死荷载做线性静力，取得各内部单元的轴力 N(x)，再求 (K + αG[N])u = αF。G = ∫N(x)H′ᵀH′dx，拉力为正，两个横向 Hermite 平面均参与，三点 Gauss 积分。覆盖杆系侧移 P-Δ 与杆内弯曲 P-δ；不更新参考轴，不包含轴力再分配、弯曲导致的轴向伸长、随动力、扭转预应力、塑性、局部屈曲、大转动或后屈曲。本模型不是通用几何非线性求解器。轴力来自同一次冻结线性运行，不能将另一荷载工况的预应力借给本次响应。

全部节点力／矩、均布荷载与自重（含输入组合）按 α = 1/n … 1 等比例加载，每步用该步真实矩阵作平衡校正。初应力模型在每步内矩阵固定；因此通常两次校正完成，不把这个过程宣传为非线性轴力更新的 Newton 迭代。每轮保存校正前残差、校正向量、校正后残差与位移向量。力残差采用对角均衡坐标的范数，除以 max(1, ||均衡 αF||)；增量除以 max(1e-12, ||均衡位移||)。两者均满足冻结容差才进入下一步。每步要求对角均衡 K+αG 的 Cholesky 成功且最小平方主元 > 1e-12；奇异／非正定、非有限、迭代耗尽、范围超限和运行资源耗尽均失败，绝不发布最后一轮作为成功。

使用独立梁端释放坐标，与屈曲一致，仅去除几何确定的脱开节点转角。逐杆 1/2/4/8/16 加密；在工程节点与 17 个沿杆站点比较真实位移、反力和截面力，绝对加相对误差归一化全部 ≤1 才成功；预算终止不收敛必须失败。默认相对细分门槛 .005，位移绝对门槛 1e-9 m/rad、力绝对门槛 1e-6 kN/kN·m，可配置。最多 1200 个计算坐标，沿用独立进程、120 秒、内存与传输预算、取消。

结果保存实际计算向量、单元局部位移、弹性／几何刚度、荷载向量、完整加载校正记录、线性原生运行与冻结工程映射。截面弯矩按广义端力加 ∫N(x)v′dx 恢复，表示初应力平衡模型；均布横向荷载用等效节点力与 Hermite 位移，不借用线性横向精确特解伪造二阶位移。轴向方程在本方法中保持线性，均布轴力位移按其真实方程加 qx·x(l−x)/(2EA) 解析项。每个网格的线性比较使用完全相同的结构、荷载、约束、释放和内部网格，只去掉 G。UI 可显示两条沿杆曲线、节点位移与杆端力差值，工具 summary/mesh 可核查方法与过程；异输入结果不能被称为二阶效应。二阶响应禁止静力式叠加，计算书由 T2-37 接入。

限制校正解的沿杆横向斜率 ≤ .05 rad 和轴向应变 ≤ .01，以明确排除小位移近似超限（这不是材料强度或规范判据）。不计算承载极限、安全系数或规范结论。

## 独立验证预登记

E=200 GPa，L=3 m，矩形 .1×.2 m，悬臂压杆顶端横力 H=.1 kN。压缩 P=0/200/500 kN：k=√(P/EI)，连续解 δ=H/(Pk)·[tan(kL)-kL]，根部弯矩 HL+Pδ；P=0 取 HL³/(3EI)。拉伸用 tanh 对应解析解。位移与根部弯矩相对误差 ≤ .005，均衡平衡残差 ≤1e-8。最终网格误差须低于初始值；两柱铰接顶梁对称侧移框架分别核对每柱悬臂解、全局力平衡与对象映射。覆盖均布轴力／横力、自重、旋转轴、端释放、组合、荷载缩放非线性、加载步数一致性、零压线性一致、输入与过程篡改、上限一轮失败、过临界非正定、单网格不收敛及方程预算不足。

理论边界参考 [OpenSees P-Delta 小位移变换](https://opensees.berkeley.edu/OpenSees/manuals/usermanual/241.htm) 与 [Abaqus 梁初应力刚度原理](https://docs.software.vt.edu/abaqusv2025/English/SIMACAETHERefMap/simathe-c-beamform.htm)。本实现采用上述明示的 Hermite 初应力能量模型，不声明与这些软件的一般梁模型等价。
