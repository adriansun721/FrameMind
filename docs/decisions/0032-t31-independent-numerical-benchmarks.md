## 参考独立性与输入

`scripts/generate-t31-references.py` 仅使用 Python/SymPy，对连续 Euler-Bernoulli 杆件截面作静力平衡，再积分 `N*n/EA + T*t/GJ + My*my/EIy + Mz*mz/EIz`。它不读取产品代码，不调用产品刚度、局部轴、组装或求解程序。各杆局部基向量显式登记，包含竖直杆和 90° 各向异性截面。解析参考、节点、约束、材料截面、荷载和符号分别保存在 `src/validation/t31-references.json`。

定端/闭环结构在自由悬臂基础上引入末端六个力/力矩冗余量，对连续应变能求偏导并令其为零，以末端位移与转角兼容求反力。参考仅解六阶柔度方程，产品仍使用完整空间刚架刚度法；没有以成熟求解器替换产品后端。虚功方法可参考作者教材 [Structural Analysis, Udoeyo, §1.8](https://eng.libretexts.org/Bookshelves/Civil_Engineering/Structural_Analysis_%28Udoeyo%29/01%3A_Chapters/1.08%3A_Deflections_of_Structures-_Work-Energy_Methods)。

基准覆盖六种独立端荷载、六分量共同作用、竖直与偏斜杆/截面转角、局部/全局三分量均布力、自重、两个独立工况、正负与零系数组合、定端均布梁、静定空间折线、闭环空间超静定结构和教材例 2-1（原图与书中等效荷载分别登记）。无效输入覆盖缺失参数、零杆长、失效引用、孤立节点、断开无约束部分、无支座与转动机构。教材荷载在加载处细分节点，不引入首版范围外的杆内集中力。

## 首次测量前固定的比较规则

所有节点的六个位移/转角、六个反力/反力矩、所有杆件的两端六分量及起点/中点/终点截面六分量逐项比较。判据为 `abs(actual-reference) <= max(absTolerance[unit], 1e-8*abs(reference))`：m 与 rad 的绝对容差均为 `1e-11`，kN 与 kN·m 均为 `1e-9`。参考为零或绝对值低于绝对容差时仅用绝对误差，相对误差报告为 null，不用总百分比。非有限数、缺失对象、异常和错误成功均失败。

整体平衡独立累计实际输入的节点力/力矩、连续均布力合力及关于原点的力矩、自重和结果反力，不用产品等效节点荷载代替外力。六分量残差分别要求 `1e-9 kN` / `1e-9 kN·m`。过程入口核对运行来源、自由度编号和 `K*u-F=R` 各分量，并核对荷载向量外力合量；它是实际过程一致性证据，不被当作独立数值参考。

## 教材核查及限定

《计算结构力学》，阎军、杨春秋，科学出版社，2014，例 2-1（印刷 42–46 页 / PDF 51–55 页）逐页查看。EA=3.3×10^6 kN，EJ=13.5×10^7 kN·cm²；转换为 EI=13500 kN·m²。支座为两端固定，斜杆中部水平 40 kN，折点荷载 (20,-20) kN，水平杆中部逆时针 1800 kN·cm 转换为 +18 kN·m（放大原图后校正初次方向转录，未调整容差或产品实现）。弯曲只在 XY 平面发生，三维补充的 Iy/J 不影响此平面解。

教材位移以 cm 给出，转角为 rad；杆端力矩从 kN·cm 除以 100，反向定义按本软件正局部 x 截面换算。教材显示值经过舍入，不作为高精度准则；由上述连续力法重新生成完整精度参考，并另记录舍入值/图示的疑点。不得为匹配教材印刷舍入值修改产品求解器。

### 例 2-1 的可复现疑点

书中第 43 页 FA=(40,-26,-1200) 使用 kN / kN·cm；这不是原图荷载直接施加在折点的等价模型。保留原图五节点输入和书中三节点等效荷载输入，分别以连续力法核查，不能将三节点模型的支座反力冒充原图反力。

第 44 页印刷刚度矩阵的 y–θ 系数为 -5818.0195 kN；按斜杆在 A 的端2方向，左斜杆应贡献 -3181.9805，右梁在 A 的端1贡献 +9000，总计 +5818.0195 kN。相应 x–θ 系数应为 +3181.9805，书中为负号；平面刚度矩阵的转角耦合列/行与本软件的 +rz 正号相反。独立的三阶平面端部刚度推导及连续力法复核一致，不能将教材转角正号未统一的结果直接作为通过准则。

正确节点 A 的平面子矩阵（行列 ux/uy/rz；长度 m、力 kN、力矩 kN·m）精确式为 `[[1100000+275750√2, 274250√2, 2250√2], [274250√2, 6000+275750√2, 9000−2250√2], [2250√2, 9000−2250√2, 18000+9000√2]]`。独立推导与公开实际过程入口的矩阵一致。转角取反时，可转换教材耦合符号，但 FA 的力矩也必须同时取反；教材显示值没有明确提供这一完整换算，故保留差异说明。
