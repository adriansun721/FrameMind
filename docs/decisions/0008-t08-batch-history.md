# ADR-0008：批量变更、复制删除与撤销重做

- 日期：2026-10-01
- 状态：已接受
- 范围：PLAN.md T08；US-012、US-018、AC-05 的本地模型部分

## 事务边界

`applyProjectTransaction` 接收一组公开领域命令，在不可变 `FrameProject` 上顺序执行。任一命令抛出异常时，调用者只得到异常，原项目引用和内容保持不变；全部成功后只增加一个项目修订号。节点批量移动和杆件批量转角都使用该入口，后续荷载和 AI 操作可复用同一边界。

## 复制与删除

复制节点或杆件重新分配编号和稳定身份。复制杆件保留原起止节点、材料、截面和朝向引用。删除节点采用级联规则，同时删除连接杆件、该节点上的支座和节点荷载；删除杆件只删除杆件本身。材料和截面存在杆件引用时拒绝删除并列出依赖杆件，避免悬空引用。

## 历史范围

`ProjectHistory` 只存储当前会话内的项目快照，不进入 `.framemind` 文件。每个成功的 `activateProject` 变更形成一个历史项；撤销和重做恢复完整项目快照（包括几何、属性和引用），撤销后产生新编辑会清空 redo 分支。打开或新建项目时清空历史。保存与重开只依赖项目模型和已保存分析结果，不依赖历史存在。

当前数据表的多选批量 UI 明确覆盖节点和杆件；材料、截面、支座和节点荷载仍通过现有单对象入口维护。领域层已对材料和截面引用提供拒绝删除策略，新增对象类型接入批量 UI 或历史时必须补充对应验证。
