# ADR-0010：T10 自重闭环

## 决策

自重作为项目级输入保存为 `selfWeight`，当前只接入公共工况 `LC1`。输入包含 `enabled` 和全局坐标系重力加速度 `gravity`（m/s²），新项目默认关闭并预填 `g=(0,0,-9.81)`。启用时，杆件线密度由引用材料的 `densityKgM3` 与截面 `areaM2` 相乘得到，重力体力换算为 kN/m 后投影到杆件局部轴，和均布荷载共用一致荷载向量、组装、内力恢复及结果查询路径。

## 理由与边界

- 密度（kg/m³）、面积（m²）、重力加速度（m/s²）和结果力（kN）分别标示，避免把质量密度当作重度保存。
- `selfWeight` 每次随分析输入快照冻结；修改材料或截面只改变后续分析，不修改旧结果，也不会把自重追加到项目均布荷载数组。
- 缺少或无效材料、截面参数由已有模型检查定位；启用自重时零重力被拒绝。当前不支持自定义工况，后续工况任务扩展公共字段。
- 旧 v1 项目缺少 `selfWeight` 时按关闭处理；旧分析缺少自重输入时仍可读取。

## 验证

`src/domain/analysis-t10.test.ts` 使用 4 m 悬臂独立核对总质量、总重量、支座反力和端位移，验证截面修改后重量翻倍、重复求解不累加、结果输入冻结并可保存重开。`e2e/t10-self-weight.spec.ts` 从真实 Electron 入口设置 LC1 自重、计算、修改截面、重算、保存和重开。
