# ADR-0027：底部横向属性栏

- 日期：2026-10-02
- 状态：已采用
- 范围：T26 前的工作台布局微调

## 用户要求

删除模型区底部的节点／杆件表格，将右侧属性栏移到其位置横向展示。将原工具栏的数据表按钮移到右上角三个布局按钮的中间，替换原属性按钮，用于开关新的属性栏。左侧项目树和右侧 AI 对话保留原位置；属性栏只占中间模型工作区，可拖动上边缘调整高度，内部属性按横向分组排布。

## 实现

工作台改为侧边导航、项目资源、中间模型区和 AI 对话四列。属性栏作为模型区底部的子区域，与视图共享左右边界；关闭后模型视图向下扩展。右上角中间按钮沿用原数据表的 `Table2` 图标，显示状态和栏内关闭按钮共享 `propertyPanelOpen`。

`BottomProperties` 负责容器、开关和高度调整。默认高度为 260 CSS px，上限为模型区高度的一半；窗口变小时重新限制实际高度。指针捕获支持拖动，分隔条也支持方向键与 Home／End。容器持续挂载，收起时保留未保存草稿、滚动位置和本次会话的高度。

对象标识、已应用值和编辑表单使用横向分组；分析视图控制与输入摘要横向排列，较长的杆件／整体过程继续在栏内滚动查看。删除旧 `ModelDataTable` 组件、开关状态和专属样式。

原表格的多选入口移到项目树节点／杆件旁的复选框，批量修改、复制、删除入口位于底部属性栏，并复用原领域命令、事务与撤销重做。批量修改和复制后从更新后的模型载入选中对象草稿；级联删除同步清理不存在的杆件多选身份。

此决策替代 ADR-0007、ADR-0008 中有关数据表展示和操作入口的位置约定。模型身份、属性提交规则、领域校验与项目文件格式沿用原实现。

## 验证

真实 Electron 回归覆盖属性栏与视图的边界关系、1080／1440 窗口、布局开关组合、三维重绘、草稿保留、指针与键盘调整高度、项目树多选、批量编辑、复制删除、撤销重做、保存重开和 AI 读取正式模型。
