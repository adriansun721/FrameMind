# T15 分析历史与前后对比

本决策覆盖 PLAN.md T15、US-003、US-046、US-047 和 AC-10、AC-17。

## 历史结果契约

`AnalysisResult` 的 `id` 是一次完整求解的稳定身份，`input` 是该次运行的不可变快照。项目的 `analysisResults` 按完成顺序追加保存；同一工况或组合再次求解时保留旧记录，只在重放完全相同的结果 ID 时替换该记录。`latestAnalysis` 继续作为最近完成结果的兼容字段，按来源查询则从结果历史中取最后一份匹配记录。

模型或荷载编辑只增加项目修订号，不改写任何历史结果。`isAnalysisResultCurrent` 重新捕获当前输入，与冻结快照比较，因此旧结果明确显示“已过期”，且三维图、表格和来源标签不会把旧数值冒充当前模型结果。撤销和重做恢复完整项目快照，历史结果随快照恢复，不通过重新计算或按来源覆盖来重建。

## 对比规则

用户从保存的已完成分析中明确选择前后两份记录。对比首先检查项目身份、来源工况或组合、组合定义、单位约定、自由度顺序和稳定对象 ID；任一条件不满足时列出原因并停止数值比较。匹配对象使用节点和杆件稳定 ID，不使用当前选择状态或显示编号。

兼容比较展示：

- 节点位移与支座反力的后一份减前一份差值，单位分别为 m 和 kN；
- 杆件局部轴起点和终点六分量内力差值，分量顺序为 N、Vy、Vz、T、My、Mz，单位为 kN / kN·m；
- 节点、杆件、材料、截面、支座和荷载的参数变化，包含新增、删除和字段名。

结果表中的定位按钮仍使用稳定对象 ID，关闭对比后回到当前项目对象。对比不生成新的分析结果，也不改变模型、当前结果或撤销边界。

## 持久化与边界

项目格式 v1 继续兼容只有 `latestAnalysis` 的旧文件；含 `analysisResults` 的新文件允许同一来源存在多份记录，但拒绝重复结果 ID。每份记录的冻结结构、工况或组合、单位、求解配置和结果都独立校验。删除工况或组合时按来源清理所有历史记录。不同项目、单位、来源或无法匹配对象的结果不会被强行合并或计算差值。
