# ADR-0036：AI 对话首页、输入框与暂停继续

- 日期：2026-10-03
- 状态：已接受
- 来源：用户在本次会话提供的参考截图与交互要求

对话前显示最近三条历史记录，超过三条可展开查看全部；点击历史恢复该对话，发送消息后进入原有消息、参数卡片与结果界面。删除首次使用说明与示例按钮。输入框文字在上，按钮在下；根据用户后续反馈缩为两行，并将 AI 面板默认宽度从桌面 260 px 收窄为 220 px，仍支持拖动调整。左侧加号提供文件与插件入口，右侧为发送箭头。

输出中显示方块，点击暂停；暂停后显示三角形，点击继续；继续后恢复方块，完成后恢复发送箭头。任务层保留已经完成的工具调用与待处理消息。暂停在途请求时中止对应网络请求，继续以独立网络身份重新请求当前未完成轮次；不重放已完成工具，也不新增聊天条目。当前 DeepSeek 接口返回完整回答，继续不能恢复供应商内部生成状态，但会延续同一条本地任务及其工具上下文。迟到响应不得发布回复或执行工具。模型、选择、分析或项目变化仍使暂停任务失效。

历史按项目身份保留最近三十个对话，每个对话沿用最多二十条记录；恢复其阶段草案和未完成的计算意图，草案仍接受模型与选择有效性检查。切换会话时禁止丢弃尚未更新的卡片编辑。切换项目导致的未完成请求恢复为中断记录。历史只保留在当前应用会话内，不写入工程文件或凭据存储；完整重启后仍从空对话开始。

文件入口支持 TXT、Markdown、CSV、JSON 与 FrameMind 文本附件，单文件最多 64 KB，消息与附件总计最多 8000 字；发送时附带实际文本，明确其为参考资料。文件不会自动导入或修改正式模型。插件入口接入现有 DeepSeek 连接设置，不新增通用插件执行器。

验证：任务层覆盖暂停、重复暂停继续、已完成工具保留、迟到回复抑制、上下文失效；Electron 回放覆盖首页历史展开与续聊、紧凑输入框布局、文件与插件入口、发送/暂停/继续/完成按钮状态，并回归既有 T27 恢复流程。

结果见 [AI 对话交互修改验收](../evidence/UI-AI-conversation-validation.md)。
