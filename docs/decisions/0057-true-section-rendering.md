# ADR-0057：真实截面与分析线视图

日期：2026-10-06（Asia/Taipei）。状态：接受。范围：PLAN2.0 T2-24；US2-079—081、AC2-21 的构件视图子集。

## 尺寸、朝向与分析边界

正式视图默认实体模式。已定义 `geometry` 的构件按保存的规范单位 m 生成实心矩形、实心圆、矩形管、圆管和对称 I/H。宽沿局部 y、高沿局部 z，局部 x 沿起点至终点；变换复用正式求解的 `calculateMemberGeometry`，含竖直杆参考轴和右手转角。圆截面用 64 段圆周离散，外径不放大；管截面保留贯通孔，I/H 保留开口。目录几何复用同一路径，忽略圆角，选中信息明确简化。只含 A/I/J 的截面继续画中心线并标记“几何未定义”，不从名称或力学属性猜形状。

实体仍对应 Euler–Bernoulli 梁单元，不引入三维实体求解。显示模式是组件会话状态：切换不调用工程命令，不修改项目、身份、选择、历史输入、结果有效性或撤销栈。项目保存仍保存已确认几何，重开默认实体；没有给未确认草案增加实体覆盖。Agent 沿用真实工程读取及几何查询，展示模式不影响工具读取的工程事实。

## Three.js 与密集场景

使用仓库现有 Three.js 0.186.1 的 `Shape` 孔洞及 `ExtrudeGeometry`，截面只沿局部 x 挤出单位长度，以实例变换设置实际长度。实现前核查安装源代码和 [ExtrudeGeometry 文档](https://threejs.org/docs/pages/ExtrudeGeometry.html)、[InstancedMesh 文档](https://threejs.org/docs/pages/InstancedMesh.html)。不增加库。替代方案是逐杆网格或合并全部网格：前者绘制调用较多，后者交互颜色与依赖更新复杂，故沿用旧视图的密集阈值（节点＋杆件超过 100）并按相同截面实例化实体，旧属性分析线和节点继续批量绘制。所有工程构件都有对应可见绘制实例，不通过隐藏结构减少负载。

显示指纹包含端点、旋转、截面几何和模式，共享截面编辑及撤销能更新所有引用对象。密集实例保留工程杆件的拾取目标和逐实例高亮，资源释放包含实例 GPU 数据。适合模型纳入真实截面外包范围。局部中心线高亮只覆盖选中、悬停和当前结果目标，不增粗实体。固定 120 杆验收核对完整实例数、尺寸、拾取身份、高亮及释放；1000 节点／3000 杆全流程耗时、峰值内存及取消性能仍属 T2-42。

## 拾取、标记与标签策略

不可见球／圆柱拾取范围继续采用 ADR-0051 的交互容差，杆件范围至少包住截面外径；不改变几何、连接或传力。支座、荷载符号在独立覆盖层显示，先拾取可见条件符号再拾取工程对象。节点保留 4.5 px，小型选中点为 6.5 px。局部 y/z 轴移至截面外侧；均布荷载箭头移到截面外缘。实体、节点、轴和条件覆盖使用各自图层，不把选择色应用为全模型草案覆盖。

标签按优先级排序：选中条件 110、选中工程对象 100、当前结果目标 90、悬停 80、普通支座 30／节点荷载 20／均布荷载 10。投影至屏幕，排除视锥外及边缘位置，以实际文字宽度、6 px 水平间距和 32 px 垂直间距避免标签重叠。屏幕面积预算为 `clamp(floor(width × height / 18000), 3, 32)`；缩放改变投影间距和可显示密度。条件数量超过 100 时先限制为选中条件标签。仅标签可隐藏，实际结构、条件标记及拾取范围保持完整；完整对象及数值在项目树、底部属性及选中浮层查询。

## 验证门槛与限制

几何误差以 Three.js Float32 渲染属性为边界：外包尺寸绝对误差小于 5e-7 m；独立字面值检查水平、竖直、倾斜、30°／90° 矩形。五类截面沿杆射线验证孔洞和开口。几何切换核对节点、杆件、截面、工程修订和冻结分析结果完全相同；不以截图代替几何检验。标签固定 600×600 相机算例验证缩放和优先级。

Electron 固定七杆／十四节点（五类尺寸截面、一个目录、一个旧属性）、七支座、节点荷载和均布荷载场景；深／浅主题及 1440×900、1080×900，各实体／分析线模式截图验收，真实鼠标拾取和原生静力结果保存一致性验证。AC2-21 的全部工作台文字／窄面板综合修正仍由 T2-39 负责；新分析的端部释放标记由 T2-25 接入。此处没有宣称全规模性能、真实 AI 联测或干净 Windows 安装验收完成。
