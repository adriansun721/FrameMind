# ADR-0053：显式连接与工程杆件分割

日期：2026-10-05（Asia/Taipei）。范围：PLAN2.0 T2-20；基于 ADR-0051、0052。

## 操作与身份

`split_member` 接受一根正式杆件、规范单位 m 的 XYZ 内部点和可选 nodeId；`connect_members` 接受 2—100 根不同杆件，在同一点共享节点。工具、手动入口及批量 `propose_model_edits` 通过同一 `applyProjectEdits` 领域事务执行。所有操作先生成确认草案，原模型保持，确认校验工程输入及修订，失败无部分修改。

直线点归属采用固定 1e-9 m 垂距，不随坐标尺度、相机缩放或显示单位改变；最小杆长沿用 > 1e-12 m。共享节点精确位置匹配且必须明确提供身份。已有同位置节点时不自动选择；多个同位置节点不会自动合并。连接中的已有端点只有其身份等于明确 nodeId 才允许参与；其他端点身份、支座或节点荷载不会转移，冲突交由 T2-21 处理。单杆分割拒绝端点。选择一组已连接端点拒绝无意义提交。

旧杆件删除，按原起点→终点方向生成两个新稳定身份；回执记录 sourceMemberId、两个子段及其原杆归一化范围、旧均布荷载→新荷载身份。未分割的共享端点杆件保持原身份。预览列出共享节点、替换杆件、荷载映射、受影响边界节点的支座和节点荷载，说明当前结果过期与任务重读。

另核对两段局部 X/Y/Z 方向向量的每分量变化不超过 1e-9（无量纲）。垂距阈值不能放行端点附近显著折弯的小段，也不能跨越局部参考轴切换而改变均布荷载方向；无法保持朝向时要求精确直线点，不投影或移动用户坐标。非有限杆长、投影和垂距均明确失败。

## 工程继承

两段继承材料、截面与绕局部 x 轴转角。相同直线和方向使局部朝向相同。当前模型只有六自由度刚接端，外端条件不改，内端为共享刚接；未登记的端部字段（例如未来释放、偏心）阻止提交，不将外端释放复制到内端。当前仅支持全杆均布力：保留工况、全局／局部坐标系和强度，分别施加于互不重叠子段，合力与原作用范围保持；节点集中力、节点力矩和支座保持原节点身份，自重按各子段长度计算，不重复总质量。

分割前对源荷载调用现有 `validateUniformLoad`，拒绝分段／非均匀／未知字段，不通过构造新属性丢失原作用范围。两个拓扑工具失败时返回实际失败原因，不使用旧编辑工具的通用“等待确认”兼容回执。人工改变目标、端点、边界条件、均布荷载、材料或截面时显示冲突并重新核对；无关新增节点允许重建新版本预览。

预览和确认都保留原历史结果及其冻结输入。一次修订和一次历史操作恢复整个模型、荷载及计数器。旧目标身份不存在时既有任务协调会要求重新明确目标；拓扑草案显式登记所有成员和共享节点目标，禁止后续任务以旧杆件身份继续。工具回执提供新身份回读。

## 与计算细分区分

工程分割产生可编辑、可保存的正式节点和杆件，并改变后续输入；内部求解细分只服务计算，不改变工程对象。建模工具栏、对话框、`read_geometry_contract` 和两个工具定义均明确此区别。绘杆、拾取、缩放和交叉仍不会触发拓扑操作。
