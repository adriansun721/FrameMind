# ADR-0073：高级 Agent 操作与整体任务联测

状态：接受。日期：2026-10-07。

T2-41 需要既有手动高级建模与分析能力进入 Agent，同时保持一次任务确认、稳定对象身份、参数来源、隔离试算和真实结果引用。另建一份工具工程状态会使预览、手动操作和正式求解分离。

整体任务通过 `edits` 承载现有严格操作数组，并调用同一 `applyProjectEdits`。默认批次来源可由等长 `sources` 数组逐操作覆盖；不同来源字段拆操作。未知来源不能确认。框架使用草案身份，预览预留实际创建所需编号，确认映射身份并比较真实变化与已核对差异。实际回执与最终对象读回随项目保存。

材料目录导入保留出处，荷载工况删除遵守 ADR-0049 的级联清理及冻结历史保留。手动编辑后的失效目标通过协调冲突路径处理，不能在渲染时先应用失效操作。任务基础和工具快照仅包含工程输入，防止历史递归嵌套；完整持久化项目仍保留确认回执与恢复信息。

Agent 验证分开记录固定协议故障回放与真实 HTTPS 联测。输入、检查、预算和重复次数先登记，任何失败或缺失都计入统计并保留。修复需要新时间戳运行，不能覆盖旧运行或放宽门槛。版本 3 在原检查上增加确认后实际屈曲求解、新结果引用和用户指定二阶恢复。

两次七类样本仅证明这些具体能力，不推断总体 Agent 成功率，也不代替 T2-40 数值验收、T2-42 规模实测或 T2-44 用户评测。
