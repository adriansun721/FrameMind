# ADR-0027：T26 选柱改截面与 AI 重算对比

- 日期：2026-10-02
- 状态：已接受
- 范围：选中柱截面阶段、既有本地求解、确定分析对的读取与引用

## 对象、预览与确认

`propose_section_change` 的对象范围只来自本轮捕获的选择。可选 memberIds 必须与选择完全一致，无选择、删除对象、节点混选或非 Z 向柱均要求重新明确选择，不推测或扩大修改范围。首版通过端点全局 X/Y 相同、Z 不同识别竖直柱；斜柱仍可在既有手动入口修改。

目标截面可来自已有项目资源、已核对截面库或显式自定义名称及 A/Iy/Iz/J。参数来源为 user/suggestion，所有值复用领域截面校验；库资源保留来源，自定义值不冒充库参数。参数前后表逐一列出稳定对象、资源名称与单位，影响说明区分直接修改的柱与重算后的全结构响应。三维预览仅标记待修改柱，独立虚线图层不进入正式模型、保存或求解。卡片编辑未更新、模型或选择变化时预览暂停，确认按钮停用；重新生成会重新核对当前对象范围。

`SectionStageConfirmation` 绑定冻结方案、基础项目对象和选中对象集合，并保存按项目/方案/版本的确认回执。相同确认重复提交（包括撤销后重试）不重新应用。修改复用事务及 updateMember，仅重新指定选中柱的 sectionId；绝不原地修改共享截面。新资源仅在确认事务中创建，失败返回原项目，一次阶段对应一次编辑历史。

## 重算、分析历史和撤销

自然语言明确请求重算时，确认阶段后复用 T23 的本地 Worker 求解。未确认阶段阻止续算；拒绝或取消后续计算保留已确认模型。启用自重时，求解器从新成员资源的实际面积和密度重新生成荷载，不保存另一份手算的等效荷载。

确认前若所选分析与当前完整输入一致，捕获该分析 ID 作为基线；确认重算成功后，仅以实际新结果 ID 建立分析对。不用“最新两份”替代该绑定，也不把旧输入结果作为当前基线。无成功基线仍可修改和计算，卡片说明需另选历史分析，不能补造前值。

成功求解只增加分析历史，不增加模型编辑撤销步骤。撤销直接恢复整组截面修改；ProjectHistory 保留来源在恢复模型中仍存在的成功结果，并确保保存版本晚于保留结果的输入版本。恢复已删除工况/组合的结果仍遵守项目文件引用校验，不把失效来源带回文件。结果始终保存自身冻结输入，历史对比在撤销、重做和保存重开后可复核；操作历史本身仍不持久化。

## 两次确定分析与数值引用

应用层分析对为 `{beforeId,afterId}`；对比选择器、AI 快照及可点击引用使用同一身份。对比选择变化使在途 AI 请求失效。快照只复制实际结果与输入，省略大型过程矩阵。

`read_comparison` 复用 `compareAnalysisResults` 输出来源、输入变化、节点/杆端差值及实际自重摘要，支持 summary/nodes/members 和最多100项分页，摘要提供标签到稳定ID的映射。pairMatchesCurrentInput只描述这两份中是否有与当前输入一致的结果，两份都为历史时也可能另有第三份当前结果，不能据此推断当前模型需重算。不同项目、工况/组合、组合定义、单位、自由度或稳定对象无法匹配时，摘要说明不兼容，数值引用拒绝。

`read_comparison_result` 复用 T25 的真实结果读取，输出两次完整来源、对象、分量、单位、前值、后值与“后减前”差值。对比表支持的位移、反力、杆端力差值直接取共享对比行；转角、反力矩及沿杆截面量使用相同后减前约定。`[[comparison:调用身份]]` 只能引用本轮真实工具输出，未知或缺失差值引用使回复失败并隐藏；按钮数值来自本地对象，不使用 AI 自写数值。点击打开准确的同一分析对，完整分析 ID 可见。

仅截面引用/资源变化且原组合荷载未变时，工具标记 sectionAndSelfWeightOnly；启用自重时说明差异同时包含刚度与面积引起的荷载影响。其他输入变化、不同来源或组合系数不得归因于截面单独作用。原因解释仍是有依据的推断，不作安全或规范合规结论；引用对话不携带到后续回合。
