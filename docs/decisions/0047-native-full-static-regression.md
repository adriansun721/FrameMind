# ADR-0047：C++ 完整静力与稀疏求解

- 日期：2026-10-05（Asia/Taipei）
- 状态：Accepted
- 范围：PLAN2.0 T2-14；延续 ADR-0045/0046 的冻结输入、单位、对象身份和进程协议

完整静力新增显式 `native-static` 后端与“C++ 静力试算”入口，使用 `framemind-native/2` / `sparse-ldlt`。原 `native-single-member` 和 `framemind-native/1` 仍可运行和读取，以保留 T2-13 回归证据。手动“计算”、agent 调度及诊断副本正式计算继续沿用既有入口；正式切换、运行中 IPC 推送、调度及资源预算由 T2-15 交付。原生失败没有 TypeScript 回退。

## 矩阵与数值职责

C++ 根据工程输入独立生成三维 Euler–Bernoulli 12 自由度单元、局部轴与转角、坐标变换及荷载。以 Eigen 3.4.0 `SparseMatrix` / triplet 组装整体与自由自由度子矩阵，重复项求和。零位移支座通过自由度消元处理，不引入人为刚度。没有把 TypeScript 计算出的单元矩阵或求解数值传入原生核心。

选择 Eigen `SimplicialLDLT`，适用本任务具有足够约束、刚接、正材料与截面参数的对称正定线弹性静力矩阵。[Eigen 3.4 官方说明](https://libeigen.gitlab.io/eigen/docs-3.4/classEigen_1_1SimplicialLDLT.html)明确这一适用边界。通用 SparseLU 可处理更广矩阵但本任务不需要非对称或不定系统；继续稠密高斯消元不能满足整体矩阵存储扩展要求。保留 12×12 稠密单元，整体及约化系统使用稀疏存储。

采用 NaturalOrdering，使失败的 D 主元直接映射自由度和工程节点；AMD 可降低某些拓扑的填充，但本次优先保留可直接核查的诊断映射。此选择没有宣称达到 T2-42 的规模、时间或内存指标。没有刚度平移或正则化；非正 D 或 D 不超过 `max(abs(Kff))*1e-12` 判失败，并记录节点、自由度、全局索引、主元、尺度和阈值。1e-12 延续既有注册阈值；求解自由度残差另要求 `||Kff*uf-Ff||∞ <= max(1e-9, 1e-10*(max(abs(Kff))*||uf||∞ + ||Ff||∞))`。异常、非有限组装或恢复均不给出成功结果。

## 荷载与来源

支持节点三向力／力矩、局部与全局三向均布力、自重（`densityKgM3*areaM2*gravity/1000`）、多工况及正／负／零组合系数。均布力通过一致节点荷载组装，杆端恢复减去等效局部荷载。组合逐工况验证引用与原荷载，将原工况权重合量和冻结有效节点力及各杆局部均布强度对照，再仅计算一次有效荷载；不再次加权。组合对照绝对差阈值为 1e-9。

校验对象唯一性、引用、有限坐标、材料／截面、支座自由度、荷载坐标系、工况及来源依赖。连接图分别识别孤立节点和无任何约束的断开部分；部分约束机构由数值主元诊断。全约束模型允许零阶自由系统并恢复反力。

## 同源结果与过程

原生返回所有节点与杆件结果、17 个沿杆实际站位、单元实际贡献、等效荷载、自由度编号与约束、真实执行阶段。整体与约化稠密过程仅在各自不超过 72 阶时采集；更大矩阵返回 null，既有过程页／计算书明确缺失，不填充伪造的整体记录。没有记录 LDLᵀ 的逐步分解轨迹。

图形默认使用原生站位。任意位置截面内力由原生杆端力与同一冻结均布强度的精确平衡多项式计算，避免在二次弯矩场上作线性插值；这属于冻结结果派生查询，不是原生额外采样。其他采样数量及杆件过程沿用明确标注的冻结输入重建。沿杆位移显示保留首版 Hermite 插值，不额外承诺均布荷载的连续位移泡函数或沿杆极值。

保存、历史比较、agent 引用及计算书沿用同一结果契约；新增求解器配置参与当前性与保存校验。修复计算书配置对照依赖 JSON 字段顺序的问题，以值相等判断，不放松数值／映射校验。所有结果来源与错误处理仍通过既有 service facade。

## 验证

沿用 ADR-0032 已确认的公开边界与原 22 个连续力法／虚功法独立算例、7 个无效模型。没有修改 `t31-references.json`、参考生成器或 `numerical-benchmarks.ts` 的门槛。逐项实测误差、量纲容差、整体平衡及过程残差在 [T2-14 数值记录](../evidence/plan2/T2-14/numerical-results.json)。新增对原生 wire 直接注入的 13 个非法输入、全约束反力及 41 节点／40 杆件稀疏存储验证。旧新数值对照只是补充回归，独立参考仍是正确性依据。

Windows 原生构建与桌面试算、保存重开、历史比较、agent 结果引用、计算书导出均有验收记录。没有重做 T2-13 安装候选或干净 Windows 安装验收；安装故障和完整资源调度仍由后续任务承接。
