# ADR-0013: T13 常用钢材与型钢库

## Context

材料和截面原先只能作为无来源的自定义参数创建。T13 需要首批可核查的常用条目，同时保留课程分析所需的完整物理字段，并确保项目文件不会随库更新发生隐式变化。

## Decision

- 首批材料采用 EN 10025-2:2019 的 S235JR、S275JR、S355JR；弹性模量、泊松比和密度明确以 GPa、无量纲和 kg/m³ 保存。
- 首批型钢采用 ArcelorMittal 官方 Sections and Merchant Bars V2026-1 EN sections 表的 IPE 100、IPE 200、HEA 200。面积 `A` 使用 m²，`Iy`、`Iz` 和 Saint-Venant 扭转常数 `It` 使用 m⁴；目录中由 cm²/cm⁴ 转换的值在代码中以 SI 数值保存。
- 每个目录条目带有发布者、文档标题、版本、URL、核对日期和单位说明。选择条目时把参数和来源复制进项目对象；项目不保存对运行时目录对象的引用。
- 编辑库条目会变为 `custom`，但保存 `derivedFrom` 及原始来源，便于解释实际分析参数。没有来源的旧项目按自定义资源兼容读取。
- `Iy`/`Iz` 表示绕局部 y/z 轴的二次面积矩，项目字段 `J` 对应目录列 `It`（Saint-Venant 扭转常数）；这些含义在截面选择器和属性面板中可见。

## Consequences

库条目的后续修订不会改写已保存项目或历史分析输入。项目文件体积增加了来源元数据，旧版本文件仍按自定义资源读取。目录不声称提供规范合规结论，工程师仍可检查来源并修改实际参数。
