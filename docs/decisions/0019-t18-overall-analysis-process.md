# ADR-0019：T18 整体求解过程与教材关联

- 日期：2026-10-02
- 状态：已接受
- 范围：已完成分析的整体自由度、单元组装、约束子系统和教材来源

## 决策

整体过程面板优先使用分析运行时保存的轻量过程快照，通过 `getOverallAnalysisProcessRecord(result)` 展示稳定节点 ID、六自由度顺序、从 0 起的整体索引、每根杆件的整体刚度贡献和等效整体荷载、整体荷载向量、约束自由度与自由自由度集合，以及规模允许时的整体刚度和约束后刚度子矩阵。快照与结果使用同一分析 ID；旧项目没有快照时才从冻结输入重建，并明确标记为重建。

矩阵不默认展开。总自由度超过 72 时不返回完整整体矩阵，界面保留自由度索引和成员贡献以定位条目；成员贡献始终按 12 个整体索引查看。这样过程数据可复用于报告，也不会在查看过程中为大模型持久化或默认渲染高成本矩阵。记录来源分析 ID、项目修订号、求解器版本和 `reconstructed-from-frozen-input` 标记保持可见。

旧结果缺少支持的求解器配置时，面板拒绝把重建内容冒充原始过程，并提供基于冻结输入、使用当前验证配置的补算。补算记录新分析 ID、原来源分析 ID 和 `supplemental-reconstruction` 标记，不修改原结果。

## 教材核查与差异

项目扫描版《计算结构力学》（阎军、杨春秋，科学出版社，2014）按书内页脚核查；界面和可复用数据同时保留书内印刷页与 PDF 页序。扫描版前置页使 PDF 页序与印刷页不同：第 5 章 117 / PDF 126，5.2 节 118 / 127，5.3 节 122 / 131，5.4—5.5 节 127 / 136，5.6 节 129 / 138，附录 IV 180 / 189。

实现将局部轴作为转换矩阵 `T` 的行向量，使用 `u_local = T · u_global` 和 `K_global = Tᵀ · K_local · T`；教材 5.2 节采用相反的转置记法。这是正交转换的矩阵存储方向差异，已用 T17 斜向杆件转换矩阵与局部/总体刚度数值核对。过程面板的公式列将 `K · u = F`、`u_local = T · u_global`、`EA/l`、`12EJ/l³`、`K = Σ kᵢ` 和 `F = F_node + F_equivalent` 分别映射到第 5 章、5.2、5.3、5.4—5.5 和 5.6 的页码记录。约束处理按支座自由度消除整体刚度阵的行列，再以自由自由度子系统进行部分主元高斯消元；这是首版零位移支座假设下的实现选择，T04 的约束尺度回归与整体平衡测试作为验证证据。

## 替代方案

不把完整整体矩阵写入项目文件，不从当前编辑模型重算历史结果，也不显示未核对的教材公式编号。过程入口和报告后续复用同一分析 ID 与冻结输入，避免出现脱离实际求解的第二套推导数据。
