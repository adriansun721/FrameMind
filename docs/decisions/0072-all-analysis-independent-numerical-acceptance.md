# ADR-0072：全分析独立数值验收

日期：2026-10-07（Asia/Taipei）。范围：PLAN2.0 T2-40；AC2-12、AC2-14—18 的独立数值部分。

统一验收入口为 `npm run evidence:plan2:t240`。沿用 ADR-0032、0055、0056、0058—0064、0066—0068 已登记的参考与门槛，完整运行 13 个既有数值基准，再核查五类结果的 30 个异常场景。不重新生成参考，不修改求解器、不引入新力学算法，也不把原生与 TypeScript 的相近作为独立正确性证明。

运行前冻结 [t240-protocol.json](../../src/validation/t240-protocol.json)、参考文件、独立推导脚本、数值脚本、相关 ADR 和原生可执行文件的 SHA-256。每轮创建唯一输出目录；各功能脚本通过 `FRAMEMIND_NUMERICAL_EVIDENCE_ROOT` 写入本轮暂存区，仍保留单独运行的默认路径。T2-26 只读取同轮 T2-14 生成的轴向模型。缺失、空报告、子进程错误或超时均失败，不读取旧任务证据替代。

数值报告重算绝对与相对误差，保留原检查的 `max(abs, rel·reference)` 或 `abs + rel·reference` 判据；近零参考按已登记绝对尺度报告，相对误差为 null。力与力矩残差按实际自由度分别记 kN 与 kN·m。频率为 Hz，质量为 kg，几何参数为 m²/m⁴，RMS 为 m，响应 PSD 为 m²/Hz，归一化残差／相关系数／子空间／屈曲因子为无量纲。PSD 最大绝对误差使用独立参考峰值归一化，避免零谱附近相对误差失真。任何非有限量均失败；上游 `passed:true` 不能覆盖误差超限。

同时保留四类证据：静力、模态、附加质量、屈曲及二阶的实际网格历史和连续参考误差；随机响应减阶／全阶比较及 6→8 模态提取比较；实际频点数量及曲线加密误差；梯形积分方差／RMS 历史及独立 Simpson 的两种区间数、方差和变化率。四类各有独立门槛，不能只报一次结果接近。静力／模态允许保存预算耗尽的明确未收敛记录，这些记录不算收敛样本；屈曲、二阶、随机不收敛仍必须失败。

形态比较沿用绝对相关系数和投影子空间，允许符号和归一化差异；模态对称双臂四重根与屈曲横向二重根分别验证整个空间。独立特征方程残差与质量正交性复核实际捕获矩阵，属于过程一致性证据；频率／因子／连续形态的独立参考仍来自连续解析解。

新增异常检查通过真实原生请求与保存解码入口运行。每种分析均拒绝 NaN、Infinity、序列化后的 null、不完整但标记成功的记录，以及原生非法／溢出输入；原生拒绝须有诊断、退出码 1 且没有 result 消息。机构、非正定、不收敛、细分／方程／频点／积分／模态预算耗尽沿用完整基准。个别失败仍继续其他独立组并生成失败报告，最终退出非零。

原始报告及逐量结果以 gzip JSON 归档，保留解压内容哈希；概要、失败记录和四类收敛记录使用可读 JSON，另生成 Markdown 汇总。压缩只控制证据体积，不删数值。后续修正参考或门槛必须单独记录依据并产生新一轮证据；本任务未调整任何参考或验收限。

本验收限于已经声明的线弹性 Euler–Bernoulli、初应力二阶、正因子屈曲、无预应力模态和平稳线性随机节点平移响应，不扩展理论范围。制造截面扭转近似、有限模态尾部及单自由度极限误差仍按各基准边界解释。结果不代表真实 AI 联测、目标规模性能、真人试用或干净 Windows 安装已通过。
