# FrameMind

T16 完整工作台：左侧可折叠项目树、模型右缘可独立收起的属性、最右 AI 对话区；设置中可选择深色/浅色主题并在重启后保留。主题同时更新三维标记和原生标题栏。验收与双主题截图见 [T16 验收记录](docs/evidence/T16-validation.md)。T21—T24 已接入自然语言参数卡片、三维预览、阶段确认、成组撤销重做和确认后自动续算，报告入口仍待实现。

面向空间刚架课程分析的 Windows 桌面工作台。当前完成 T01—T25：可手动建立多杆空间刚架，设置节点六自由度支座及集中力/力矩，本地计算位移、转角、反力和杆端内力，保存并重开带原始计算输入的项目。分析失败可查看阶段、定位对象并编辑修正，历史成功结果保持可用。求解在独立 Worker 中运行，界面显示阶段并支持取消；迟到结果不会覆盖已编辑或已切换的项目。属性面板和数据表共享节点、杆件的编辑草稿与提交入口，三维视图和项目树同步已应用模型；数据表支持多选批量移动/转角、复制删除，以及成组撤销重做。杆件均布力支持全局/局部坐标、三维方向箭头、编辑保存与撤销，并可按沿杆位置查询实际截面内力。节点荷载、均布荷载及结构自重可明确归属不同工况；工况支持创建、修改、删除、独立求解、保存重开和响应比较。用户可自定义工况组合与无量纲系数（包括零和负系数），计算、切换并保存基于同一结构及完整原始工况输入的组合响应。选中已计算杆件可展开真实过程记录，查看冻结输入重建的局部/整体矩阵与教材依据；整体过程面板可查看节点自由度编号、成员组装索引、约束后系统和教材印刷页/PDF 页映射。

T25 支持 AI 读取所选分析的真实结果，用可点击引用核对对象、分量、数值、单位、工况或用户组合及冻结输入。点击可定位模型并查看原始结果项；历史结果明确需重算，切换所选分析使旧请求失效。解释区分计算事实和原因推断，不提供规范验算结论。见 [T25 验收记录](docs/evidence/T25-validation.md)。`npm run evidence:t25:online` 可重验真实问答。

## 本地运行

T19 已实现 DeepSeek 连接设置：填写、更新和移除本机 API Key，保存后测试连接。默认使用 DeepSeek-V4.1-Flash（官方请求标识 `deepseek-flash`），凭据通过 Windows DPAPI 加密，独立于项目文件。认证、限流、超时和网络失败提供脱敏反馈，不影响本地编辑与求解。真实连接已使用用户配置的凭据验证成功，记录见 [T19 验收记录](docs/evidence/T19-validation.md)。

T20 已实现只读 AI 对话：选中节点、杆件或混合对象组后，使用稳定 ID 读取当前已应用模型，展示工具输入、输出、执行状态和错误原因。模型草稿不进入读取；取消、模型或选择变化使旧请求失效，未知工具和脚本不会执行，修改请求保持未应用。对话保留在当前会话中，不随项目保存。固定回放与三次真实 DeepSeek 工具对话均通过，见 [T20 验收记录](docs/evidence/T20-validation.md)。

T21 支持描述两层空间钢刚架，由预定义工具整理层数、两向跨长、各层层高、原点、钢材、梁柱截面及转角。卡片标明用户输入、建议与缺失，直接编辑或自然语言补充使用同一方案；冲突需澄清，完整方案以独立虚线图层预览，可重新生成或拒绝。方案不会进入保存文件或正式分析输入。T22 支持按方案内容和基础模型版本确认后原子应用，过期预览需刷新，重复提交不会再次创建对象；一次确认可整组撤销和重做。确认失败保留原模型，后续变更再次预览确认。见 [T21 验收记录](docs/evidence/T21-validation.md) 与 [T22 验收记录](docs/evidence/T22-validation.md)。

T23 支持 AI 支座与节点荷载卡片：核对六自由度约束、全局力/力矩及现有工况，预览后整组确认。已请求“建模并计算”时，建模确认后自动准备必要条件，条件确认后继续本地求解并展示结果；计算来源随卡片确认，失败和取消保留已确认模型。见 [T23 验收记录](docs/evidence/T23-validation.md)。`npm run evidence:t23:online` 可重验真实 DeepSeek 的两阶段确认与自动本地求解。

T24 支持通过自然语言或同一条件卡片创建和修改多工况、全局/局部均布力、自重及用户自定义组合（含零和负系数），确认后计算所选 LC/CB。自重以模型旁的单一标记显示工况与重力向量，预览标明待确认；密度和面积可在卡片核对。整个条件阶段可整组撤销重做，结果保留原始工况荷载及组合系数。见 [T24 验收记录](docs/evidence/T24-validation.md)。`npm run evidence:t24:online` 可重验真实 DeepSeek 的完整多工况组合流程。

```powershell
npm install
npm run dev
```

桌面测试通过临时隔离的 Electron 用户目录运行，避免与正在使用的应用争用配置；单独运行可使用 `node scripts/run-e2e-isolated.cjs e2e/t21-frame-proposal.spec.ts`。
