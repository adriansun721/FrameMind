面向空间刚架课程分析的 Windows 桌面工作台。当前完成 T01—T21：可手动建立多杆空间刚架，设置节点六自由度支座及集中力/力矩，本地计算位移、转角、反力和杆端内力，保存并重开带原始计算输入的项目。分析失败可查看阶段、定位对象并编辑修正，历史成功结果保持可用。求解在独立 Worker 中运行，界面显示阶段并支持取消；迟到结果不会覆盖已编辑或已切换的项目。属性面板和数据表共享节点、杆件的编辑草稿与提交入口，三维视图和项目树同步已应用模型；数据表支持多选批量移动/转角、复制删除，以及成组撤销重做。杆件均布力支持全局/局部坐标、三维方向箭头、编辑保存与撤销，并可按沿杆位置查询实际截面内力。节点荷载、均布荷载及结构自重可明确归属不同工况；工况支持创建、修改、删除、独立求解、保存重开和响应比较。用户可自定义工况组合与无量纲系数（包括零和负系数），计算、切换并保存基于同一结构及完整原始工况输入的组合响应。选中已计算杆件可展开真实过程记录，查看冻结输入重建的局部/整体矩阵与教材依据；整体过程面板可查看节点自由度编号、成员组装索引、约束后系统和教材印刷页/PDF 页映射。

## 本地运行

T19 已实现 DeepSeek 连接设置：填写、更新和移除本机 API Key，保存后测试连接。默认使用 DeepSeek-V4.1-Flash（官方请求标识 `deepseek-flash`），凭据通过 Windows DPAPI 加密，独立于项目文件。认证、限流、超时和网络失败提供脱敏反馈，不影响本地编辑与求解。真实连接已使用用户配置的凭据验证成功，记录见 [T19 验收记录](docs/evidence/T19-validation.md)。

T20 已实现只读 AI 对话：选中节点、杆件或混合对象组后，使用稳定 ID 读取当前已应用模型，展示工具输入、输出、执行状态和错误原因。模型草稿不进入读取；取消、模型或选择变化使旧请求失效，未知工具和脚本不会执行，修改请求保持未应用。对话保留在当前会话中，不随项目保存。固定回放与三次真实 DeepSeek 工具对话均通过，见 [T20 验收记录](docs/evidence/T20-validation.md)。

T21 支持描述两层空间钢刚架，由预定义工具整理层数、两向跨长、各层层高、原点、钢材、梁柱截面及转角。卡片标明用户输入、建议与缺失，直接编辑或自然语言补充使用同一方案；冲突需澄清，完整方案以独立虚线图层预览，可重新生成或拒绝。方案不会进入保存文件或正式分析输入。阶段确认应用将在 T22 实现，见 [T21 验收记录](docs/evidence/T21-validation.md)。

## 验证

```powershell
npm run typecheck
npm test
npm run test:e2e
```

桌面测试通过临时隔离的 Electron 用户目录运行，避免与正在使用的应用争用配置；单独运行可使用 `node scripts/run-e2e-isolated.cjs e2e/t21-frame-proposal.spec.ts`。

配置真实 Key 后，可运行 `npm run evidence:t20:online` 重验连接、选中节点/杆件及提交修改后的重新读取。该命令会产生 DeepSeek API 用量；使用临时目录和本机加密配置，证据只保存示例模型、工具输出和回复。

项目文件使用 `.framemind` 扩展名和带版本号的 UTF-8 JSON 格式。架构及兼容规则见 `docs/decisions/`。
